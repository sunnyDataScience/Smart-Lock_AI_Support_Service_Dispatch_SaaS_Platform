# 安裝與派工判斷指南

## 必須收集的資訊

根據場景收集不同資訊：

### 故障維修派工
| 欄位 | 追問話術 | 必要性 |
|------|---------|--------|
| 品牌型號 | 「請問品牌和型號？」 | ✅ 必要 |
| 故障描述 | 「目前遇到什麼問題？」 | ✅ 必要 |
| 地址 | 「請問您的地址是？」 | ✅ 必要 |
| 急迫程度 | 「您目前能正常進出門嗎？」 | ✅ 必要 |

### 安裝評估
| 欄位 | 追問話術 | 必要性 |
|------|---------|--------|
| 新門/既有門 | 「是新門要安裝，還是現有門要更換電子鎖？」 | ✅ 必要 |
| 門的照片 | 「可以拍一張門正面和鎖匣部分的照片嗎？」 | ✅ 必要 |
| 地址 | 「請問安裝地址？」 | ✅ 必要 |

## 一、「電話可解決」vs「需派工」判斷

### ✅ 電話可解決（引導客戶自行操作）

| 情境 | 處理方式 |
|------|---------|
| 門扇卡死但有馬達聲 | 推緊門板法 → 呼叫 load_skill("ts-door-stuck") |
| 電池品牌錯誤導致異常 | 更換正確電池 → 呼叫 load_skill("ts-power-drain") |
| 雙重認證誤觸 | 引導關閉 → 呼叫 load_skill("ts-dual-auth") |
| 驗證失敗（單一方式） | 重新設定或清潔感應器 → 呼叫 load_skill("ts-verification") |
| 關鎖失敗（受口片輕微偏移） | 客戶有工具可自行微調 |
| APP 操作問題 | 遠端指導 → 呼叫 load_skill("app-guide") |
| 系統設定問題 | 遠端指導 → 呼叫 load_skill("system-settings") |

### ❌ 需派工（文字/語音無法處理）

| 情境 | 原因 |
|------|------|
| 鎖栓無法伸縮（鎖匣故障） | 需更換零件 |
| Dormakaba 紅燈閃 4 次 | 馬達異常 |
| 門扇反弓 | 結構問題需專業調整 |
| 受口片嚴重偏位 | 需專業工具 |
| 管理者密碼遺失（Dormakaba） | 需技師初始化 |
| 所有方式+鑰匙都開不了 | 機械故障 |
| 電池槽腐蝕 | 需現場處理 |
| 門扇下沉需校準 | 結構問題 |

## 二、安裝前評估

### 新門安裝（兩種方式）

**方式 A：門廠預裝歐規鎖**
1. 門廠預先安裝歐規傳統連體鎖
2. 預先開好鎖匣及受口孔位
3. 電子鎖廠進行更換

**方式 B：門廠開孔**
1. 門廠提供電子鎖開孔服務
2. 需提供詳細開孔圖
3. 廠商派員安裝

### 既有門更換評估

**需要客戶提供：**
- 現有電子鎖正面照片
- 鎖匣部分照片
- 側板寬度與長度

**評估項目：**
- 側板規格相容性（歐規/美規/義大利規/日規/韓規）
- Chainlock 做法：確認現有側板 → 提供相符側板替換 → 避免切割

> ⚠️ 砂輪機切割副作用：毛邊、敲打痕跡、高熱可能導致門板油漆起泡（須事先告知客戶）

### 新成屋/預售屋
預先提供側板規格 → 提供相應側板 → 安排安裝

## 三、安裝流程

1. **諮詢** → 了解需求
2. **門扇評估** → 照片評估或現場勘查
3. **選擇方案** → 預算/外觀/功能
4. **決定與支付訂金**
5. **安排安裝時間**
6. **完工教學** → 管理者設定、用戶新增、緊急供電操作教學

### 完工後注意事項
- **舊鎖處理**：技師通常會將舊鎖交還客戶保存，不負責回收
- **施工時段建議**：建議早上 10:30 或下午 1:30 施工，以遵守社區大樓的噪音管制規定
- **代工保固說明**：代工服務（客戶自備鎖）僅保障安裝品質，產品本身故障需洽原購買商

## 四、派工優先順序

| 優先級 | 類型 | 說明 |
|--------|------|------|
| 🔴 最高 | 維修（緊急） | 客戶被鎖在門外、門無法關閉 |
| 🟡 中等 | 安裝 | 新機安裝 |
| 🟢 一般 | 教學 | 功能教學、設定協助 |

---

## 五、報價邏輯

### 一般案件
> 報價 = 工資 + 車馬費 + 零件費

### ⚠️ 建案/保固期案件
> **禁止 AI 報價！** 需查詢建案資料庫（涉及完工日與點交日爭議）
> 請轉接人工客服處理

### 金流
- 現狀：師傅收現金 → 公司月結 → 扣材料費後撥款
- 未來規劃：串接虛擬帳戶
