# 語音留言（Chatlock AI-99）

📹 教學影片：https://www.youtube.com/watch?v=nA2w58yyeZM

## 錄製留言

1. 觸碰螢幕 → 待機畫面
2. 找到語音留言圖示 → 按住錄音
3. 放開結束錄音 → 留言儲存成功

## 播放留言

1. 觸碰螢幕 → 語音留言
2. 需管理者密碼驗證
3. 選擇留言播放

> 適用場景：出門前留言給家人、提醒訪客等
