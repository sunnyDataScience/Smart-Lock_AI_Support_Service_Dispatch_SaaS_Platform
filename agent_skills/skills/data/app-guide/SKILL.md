# 電子鎖 APP 設定與操作指南

本指南主要適用 **Chainlock / Chatlock**（AI99、A90、AI88）的 APP 操作。

> **其他品牌**（AS701、Philips、Milre 等）的 APP 或面板操作步驟，請引導客戶參考對應型號的操作手冊，可呼叫 load_skill("product-knowledge") 取得手冊連結。

> ⚠️ 追問原則：若客戶未說明型號或要操作的功能，務必先確認再提供指引。

## 必須收集的資訊

| 欄位 | 追問話術 |
|------|---------|
| 型號 | 「請問您的 Chatlock 型號是？AI99、A90 還是 AI88？」 |

## 一、APP 初始配對

**前置條件：**
- 手機已安裝 Chatlock APP（App Store / Google Play）
- 手機 Wi-Fi + 藍牙已開啟
- Wi-Fi 為 **2.4G 頻段**（❌ 不支援 5G）
- 站在電子鎖旁邊

**步驟：**
1. 電子鎖：系統設定 → 網路設定 → 網路配對
2. APP：「+」→ 添加設備 → 輸入 Wi-Fi 密碼（注意大小寫）→ 等待配對
3. 雙方顯示「配對成功」即完成

**配對失敗？** 檢查：Wi-Fi 密碼大小寫、2.4G/5G 分開設定、藍牙已開啟、重啟後重試

## 二、用戶管理

**入口：** 觸碰螢幕 → 齒輪 → 管理者驗證 → 用戶管理

### 新增用戶
新增用戶 → 選角色（爸爸/媽媽/自訂）→ 選擇解鎖方式：

| 方式 | 操作要點 |
|------|---------|
| **指紋** | 手指感應 5 次，調整角度確保完整。老人/小孩指紋較淺建議多設幾根手指，若仍困難建議改用**人臉辨識**或**掌靜脈**作為主要解鎖方式 |
| **人臉** | 距鏡頭 60 公分，正對鏡頭，光線充足。可摘眼鏡/帽子提高辨識率 |
| **掌靜脈** | 手掌距 15-30 公分，保持穩定 |
| **感應卡** | 卡片貼上方 NFC 感應區，等「註冊成功」 |
| **密碼** | 6-12 位數字，輸入兩次確認 |

> 💡 **特殊指紋/掌靜脈**：可設定脅迫警報功能，被迫開門時使用特定手指觸發靜默警報

### 刪除用戶
用戶管理 → 點擊用戶 → 刪單一方式（紅色垃圾桶）→ 刪完後可刪整個用戶

## 三、遠端開鎖

**條件：** APP 已配對 + 電子鎖已連 Wi-Fi + 手機有網路

**操作：** APP 設備頁面 → **長按**中央鎖頭圖示 → 顯示「已成功」→ 紀錄中可確認

---

## 四、臨時密碼

**操作：** APP → 臨時密碼 → 設定密碼

- 密碼規範：**7 位數字，第一位必須是 1**
- 可手動輸入或「隨機生成」
- 設定失效時間（精確到年月日時分）
- 命名（選填，如「清潔阿姨」）
- 儲存後「密碼已複製」→ 透過 LINE/簡訊傳給對方

> 臨時密碼在有效期間內可重複使用，到期自動失效

---

## 五、即時影像監控

**僅限 AI99 型號**（A90/AI88 無攝影鏡頭）

**操作：** APP → 影片監控 → 建立加密連線

功能：
- 前鏡頭（門外）/ 後鏡頭（門內）切換
- 語音對講、音量調整
- 拍照、錄影
- 長按開鎖（影像畫面中直接遠端開門）

---

## 六、家庭成員管理

**新增成員：**
1. 主畫面左上角「房子」→ 我的家 → 家庭管理
2. 選擇家庭 → 添加成員
3. 填寫名稱、帳號、角色（管理員/普通成員）→ 保存

**被邀請人接受：**
指紋圖示 → 我的家 → 家庭管理 → 待加入 → 接受邀請

> 管理員 = 完全權限；普通成員 = 基本使用。被邀請人也需安裝 APP

---

## 七、設備解除綁定

**操作：** APP → 設備卡片 → 右上角鉛筆 → 移除裝置

| 選項 | 說明 |
|------|------|
| 解除綁定 | 僅解除 APP 連結，保留鎖上的設定 |
| 解綁並清除數據 | 解除連結 + 清除 APP 端數據（不影響鎖上的指紋/密碼） |

**後續：** 換手機 → 重新配對；轉讓 → 建議鎖上也恢復出廠

---

## 八、清理緩存

**操作：** APP → 「我」→ 齒輪 → 清理緩存 → 完成
