Caller v1 Endpoint 為何留 v1

v1 docstring 已明示：api/routers/technicians.py:8 「只允許登入技師讀寫自己的 profile；admin list/get 僅需 tenant 隔離」— 確認 me/availability 為設計上的 v1。
