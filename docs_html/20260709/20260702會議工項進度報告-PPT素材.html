  • 修法(從通道層接通視覺管線):LINE 通道新增圖片訊息分支 —— 收到照片即透過 LINE 官方 API 下載圖檔,存入該次對話的媒體附件,交給 AI 的視覺理解管線;AI 看懂鎖具照片後照常回覆(如辨識型號、判斷安裝狀況、給對應說明)。
  • 不支援型別的友善處理:貼圖/影片/語音等尚不支援的訊息型別,回覆固定友善話術(請改用文字或照片描述問題),不再已讀不回。
  • 與客服流程整合:照片與 AI 的理解結果一併進對話紀錄,真人接管時客服看得到完整上下文。

驗證方式
