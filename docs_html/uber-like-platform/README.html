重要提醒

  • 純業務決策-code無關 + 法務題（ML-001/002、FM-011~020 多數）：code 只能告訴你「現況與可行性」，最終仍須業主/法務拍板（尤其 merchant of record、escrow、退款責任、平台抽成、法律責任 matrix）。
