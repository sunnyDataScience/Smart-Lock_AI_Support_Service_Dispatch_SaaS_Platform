6.3 治理規則

  • 新增業務元件： PR 必須同步更新本表一列（Context / 用途 / 被引用 pipeline）
  • 刪除業務元件： PR 必須先確認本表「被引用 pipeline」皆已改用替代方案
  • 重新命名： 新舊名並列一個 release 後刪除舊名列
  • 跨 Context 重用：提升至 components/shared/ 後在本表「所屬 Context」標 shared
