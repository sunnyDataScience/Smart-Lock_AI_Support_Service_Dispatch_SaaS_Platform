# BF-0003 — 月結帳務與撥款

> **Business Flow 性質**：E2E 業務能力 — 從完工到撥款的月結整體流程。
> 涉及多 actor (技師 / 客服 / 財務) 與多 sub-flow (對帳 / 雙簽 / 撥款)。


## 一、帳務處理流程

```
完工確認（師傅 APP 回報）
    │
    ▼
師傅現場收款（現金/轉帳）
    │
    ▼
師傅填報代墊款項（材料費等）
    │
    ▼
客服確認完工 + 照片審核
    │
    ▼
系統產生帳務明細
    │
    ▼
財務人員月底對帳
    │
    ▼
扣除材料費/代墊款 → 計算師傅應領金額
    │
    ▼
撥款至師傅帳戶
    │
    ▼
產生會計傳票
```

## 二、結算週期

| 項目 | 規則 |
|------|------|
| 結算週期 | 每月 1 日結算上月帳務 |
| 對帳期間 | 每月 1–5 日 |
| 師傅確認期限 | 每月 7 日前確認對帳單 |
| 撥款日 | 每月 10 日 |
| 爭議申訴期限 | 撥款後 7 個工作日內 |

## 三、費用結構

| 費用項目 | 說明 | 負擔方 |
|---------|------|-------|
| 安裝/維修工資 | 依代工價目表 | 客戶支付 |
| 車馬費 | 依地區定額 | 客戶支付 |
| 材料費（公司提供） | 公司庫存零件 | 月結扣除 |
| 材料費（師傅代墊） | 師傅自行採購 | 憑單據核銷 |
| 門扇加工費 | 依加工類型 | 客戶支付 |
| 急件加價 | 依加價規則 | 客戶支付 |
| 夜間/假日加價 | 依加價規則 | 客戶支付 |
