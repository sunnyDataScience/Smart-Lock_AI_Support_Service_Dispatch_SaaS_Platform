# 家庭成員管理（Chatlock AI-99）

📹 教學影片：https://www.youtube.com/watch?v=wVtdQLNlmro

## 新增成員

1. 主畫面左上角「房子」→ 我的家 → 家庭管理
2. 選擇家庭 → 添加成員
3. 填寫名稱、帳號、角色 → 保存

## 被邀請人接受

指紋圖示 → 我的家 → 家庭管理 → 待加入 → 接受邀請

## 權限角色

| 角色 | 權限 |
|------|------|
| 管理員 | 完全權限（新增/刪除用戶、系統設定、遠端開鎖等） |
| 普通成員 | 基本使用（開鎖、查看紀錄） |

> 被邀請人也需安裝 Chatlock APP 並註冊帳號
