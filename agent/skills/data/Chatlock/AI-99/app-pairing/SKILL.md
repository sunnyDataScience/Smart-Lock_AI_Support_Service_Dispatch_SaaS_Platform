# APP 初始配對（Chatlock AI-99）

📹 教學影片：https://www.youtube.com/watch?v=3RUF3tzF9FY

## 前置條件

- 手機已安裝 Chatlock APP（App Store / Google Play）
- 手機 Wi-Fi + 藍牙已開啟
- Wi-Fi 為 **2.4G 頻段**（❌ 不支援 5G）
- 站在電子鎖旁邊

## 配對步驟

1. **電子鎖端**：觸碰螢幕 → 齒輪（系統設定）→ 網路設定 → 網路配對 → 點擊「開始配對」按鈕
2. **手機端**：開啟 Chatlock APP →「+」→ 添加設備 → APP搜尋到「chatlock AI99」後點擊「添加」→ 核對並輸入正確的Wi-Fi名稱與密碼（注意大小寫）→ 點擊「下一步」→ 等待配對
3. 雙方顯示「配對成功」，且APP同步顯示設備添加成功即完成

## 配對失敗排查

| 問題 | 解法 |
|------|------|
| 連不上 Wi-Fi | 確認是 2.4G 頻段，非 5G。部分路由器需分開設定。若Wi-Fi名稱未明確標示，請確認手機連接的是2.4G頻段（例如「YourWiFiName_2.4G」）。 |
| 密碼錯誤 | 注意大小寫，建議手動輸入而非貼上 |
| 藍牙找不到 | 確認手機藍牙已開啟，站在鎖旁邊 1 公尺內。一般電子鎖藍牙僅支援一台手機連線，若有多台手機嘗試連線，請確保其他手機的藍牙功能已關閉。 |
| 持續失敗 | 鎖端重新進入網路配對模式，APP 重啟後重試 |
