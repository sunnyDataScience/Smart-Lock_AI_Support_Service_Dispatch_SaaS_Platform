# 臨時密碼（Chatlock AI-99）

📹 教學影片：https://www.youtube.com/watch?v=cCtNR325TAQ

## 操作步驟

1. 開啟 Chatlock APP → 臨時密碼
2. 設定密碼（可手動輸入或「隨機生成」）
3. 設定失效時間（精確到年月日時分）
4. 命名（選填，如「清潔阿姨」）
5. 儲存後「密碼已複製」→ 透過 LINE/簡訊傳給對方

## 密碼規範

- **7 位數字，第一位必須是 1**
- 可重複使用，到期自動失效
- 一次可設定多組不同的臨時密碼
