# 掌靜脈錄入（Chatlock A90）

📹 教學影片：https://www.youtube.com/watch?v=Hj72ZvKt5IA

## 操作步驟

1. 開啟 Chatlock APP → 齒輪（設定）→ 用戶管理
2. 選擇要新增掌靜脈的用戶（或新增用戶）
3. 點選「**新增掌靜脈辨識**」
4. 門鎖鏡頭啟動，螢幕顯示「正在檢測」
5. **將手掌置於鏡頭正前方，距離約 15 至 30 公分**
6. 保持手掌張開、穩定不動，等待掃描完成
7. 螢幕顯示「註冊成功」即完成

## 使用技巧

- 錄入時手掌不要太近或太遠，**15-30cm 是最佳距離**
- 手掌需自然張開，手指不要併攏
- 避免在強光或極暗環境下錄入
- 建議錄入時手掌保持乾淨、乾燥
- 同一用戶可錄入多組掌靜脈（如左右手）

## 日常使用

- 開鎖時，將手掌對準鏡頭（距離 15-30cm），鏡頭兩側紅燈亮起表示正在感應
- 感應成功後門鎖顯示「已開鎖」
