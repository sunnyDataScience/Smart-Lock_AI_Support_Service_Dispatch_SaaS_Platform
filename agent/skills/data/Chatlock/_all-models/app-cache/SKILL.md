# 清理緩存（Chatlock APP）

📹 教學影片：https://www.youtube.com/watch?v=Bg3hu2shcVo

## 操作步驟

1. 開啟 Chatlock APP
2. 底部「我」→ 右上角齒輪（設定）
3. 向下滑找到「清理緩存」（會顯示目前緩存大小，如 15.59M）
4. 點擊清理 → 完成

> 建議在 APP 運作變慢、畫面異常、或配對問題排查時執行
