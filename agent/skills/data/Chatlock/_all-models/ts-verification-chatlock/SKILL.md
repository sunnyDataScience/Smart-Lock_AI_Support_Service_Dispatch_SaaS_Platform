# 驗證失敗與錯誤碼 — Chatlock 故障排除 SOP

**嚴重度：3** ｜ **分類：驗證故障**

## 必須收集的資訊

| 欄位 | 追問話術 | 必要性 |
|------|---------|--------|
| 型號 | 「請問型號是什麼？（AI-99、A90、AI88 等）」 | ✅ 必要 |
| 解鎖方式 | 「您是用什麼方式解鎖的？指紋、密碼、卡片、人臉、掌靜脈？」 | ✅ 必要 |
| 錯誤顯示 | 「螢幕或面板有顯示什麼嗎？」 | 建議收集 |
| 其他方式是否可用 | 「其他開鎖方式也都無法使用嗎？」 | ✅ 必要 |

## SOP 步驟

### Step 1：判斷失敗範圍

- **單一方式失敗** → Step 2
- **所有方式都失敗** → Step 5（系統層級問題）

### Step 2：指紋辨識失敗

依序確認：
1. 手指太乾或太濕 →「搓搓手」或「擦乾後重試」
2. 手指有傷口或脫皮 → 建議使用其他手指或替代方式
3. 老人/小孩指紋較淺 → 建議多設定幾根手指或改用其他方式
4. 設定時偏差 → 重新設定，確保面積完整
5. 感應區髒污 → 用乾布擦拭
6. **指紋辨識靈敏度因人而異：**
   - 小孩：建議指紋區域足夠覆蓋時再設定，並定期更新。
   - 中年人：建議常用手指重複設定至少2-3次。
   - 老年人及長輩：建議常用手指設定至少3次以上。
   - 家庭主婦及勞力工作者：建議同一隻手指設定3次以上。

### Step 3：密碼失敗

確認：
1. **是否混淆「管理者密碼」與「一般開門密碼」**
2. 密碼長度是否正確（通常 6-12 位）
3. 是否連續輸錯觸發防盜鎖定

### Step 4：卡片 / 人臉 / 掌靜脈失敗

- **卡片**：確認是已登記的卡片、NFC 感應位置正確
- **人臉**：距離鏡頭約 60 公分，正對鏡頭，兩側紅燈亮起 = 辨識中
- **掌靜脈**：手掌距離 15-30 公分，保持穩定
- **貓眼鏡頭旁紅燈含義**：
  - 鏡頭兩側亮起紅燈 = **人臉或掌靜脈辨識正在啟動中，屬於正常工作狀態**，不是故障
  - 感應成功後，電子鎖會顯示「已開鎖」
  - 紅燈亮起但辨識失敗 → 調整距離/角度重試
- **防回頭機制**：
  - 電子鎖上鎖後，紅燈不會立即亮起，約 **20 秒內不會主動感應**，這是「防回頭機制」
  - 防回頭期間若有人經過（如鄰居、快遞），會被計為感應失敗，延長不亮燈時間
  - **若紅燈遲遲不亮**：可能是短時間內經過的人太多，導致感應失敗次數過多。此時可用手觸摸螢幕喚醒，或改用其他方式（密碼/指紋/卡片）開門

### Step 5：所有方式都失敗

1. 是否有人執行過恢復出廠設定（會清除所有使用者）
2. 嘗試**實體鑰匙**開門
   - 實體鑰匙切勿放在家中，建議放置於車內、信任的親友家或常用隨身包中。
3. 連鑰匙都無法使用 → 機械故障 → **需緊急派工**
4. **AI-99 緊急開鎖與供電**：
   - 緊急開啟位置：外門中間偏下方，由一個圓形蓋子隱藏。
   - 開啟圓形蓋子：向下按壓並向右旋轉。
   - 蓋子開啟後：內部左側為 Type-C 充電孔，右側為備用鑰匙孔。
   - 機械開鎖：將備用專屬鑰匙插入右側鑰匙孔並轉動，門鎖發出「嗶」聲即解鎖。
   - 緊急供電：Type-C 行動電源插入左側充電孔，門鎖「嗶」聲後可用指紋/密碼開門。

### Step 6：成功進門後重新設定

齒輪圖示 → 管理者驗證（支援指紋/密碼/卡片/人臉/掌靜脈）→ 用戶管理 → 重新登記

### 電池使用建議

- 電子門鎖務必使用鹼性電池，以避免電池漏液損壞內部面板零組件。建議使用P牌鹼性電池。

## 需派工的條件

- ❌ 所有驗證方式 + 實體鑰匙都無法開門
- ❌ 面板無任何反應（疑似主板故障）
- ❌ 感應器硬體損壞
