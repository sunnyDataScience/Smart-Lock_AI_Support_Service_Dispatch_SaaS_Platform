## 入口

觸碰螢幕 → 齒輪 → 管理者驗證 → 用戶管理

## 新增用戶

新增用戶 → 選角色（爸爸/媽媽/自訂）→ 選擇解鎖方式：

| 方式 | 操作要點 |
|------|---------|
| **指紋** | 手指感應 5 次，調整角度確保完整。老人/小孩指紋較淺建議多設幾根手指，若仍困難建議改用人臉或掌靜脈 |
| **人臉** | 距鏡頭 60 公分，正對鏡頭，光線充足。可摘眼鏡/帽子提高辨識率 |
| **掌靜脈** | 手掌距 15-30 公分，保持穩定 |
| **感應卡** | 卡片貼上方 NFC 感應區，等「註冊成功」 |
| **密碼** | 6-12 位數字，輸入兩次確認 |

> 💡 特殊指紋/掌靜脈可設定脅迫警報功能，被迫開門時使用特定手指觸發靜默警報

## 刪除用戶

用戶管理 → 點擊用戶 → 刪單一方式（紅色垃圾桶）→ 刪完後可刪整個用戶
