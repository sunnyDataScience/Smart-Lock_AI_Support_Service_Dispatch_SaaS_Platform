# 人臉辨識 / 掌靜脈感應問題 — Chatlock 故障排除 SOP

**嚴重度：2** ｜ **分類：辨識感應問題**

## 貓眼鏡頭旁紅燈含義

> ⚠️ **這是最常被問的問題：鏡頭兩側紅燈亮起 = 人臉或掌靜脈辨識正在啟動中，屬於正常工作狀態，不是故障。**

- 紅燈亮起 → 感應成功 → 電子鎖顯示「已開鎖」
- 紅燈亮起 → 感應失敗 → 調整距離/角度重試

## 防回頭機制（紅燈不亮的最常見原因）

電子鎖上鎖後，紅燈**不會立即亮起**，約 **20 秒內不會主動啟動人臉感應**。這是「防回頭機制」，防止剛離開的人又被辨識開門。

**紅燈遲遲不亮的原因：**
- 防回頭期間若有人經過門前（鄰居、快遞、寵物），每次都會重新計算 20 秒
- 短時間內經過的人太多 → 感應失敗次數累積 → 紅外線補光燈暫時不啟動

**解決方法：**
1. 用手**觸摸螢幕**喚醒電子鎖，紅燈會立刻亮起開始感應
2. 或改用其他方式開門（密碼/指紋/卡片）
3. 等待約 20 秒無人經過後，紅燈會自動恢復感應

## 人臉辨識排查步驟

### Step 1：確認紅燈狀態

**首先確認鏡頭兩側紅燈是否亮起：**
- 紅燈亮 → 辨識已啟動，進 Step 2
- 紅燈不亮 → 防回頭機制（見上方），觸摸螢幕喚醒

### Step 2：調整感應距離與角度

- 人臉辨識最佳距離：約 **60 公分**，正對鏡頭
- 掌靜脈最佳距離：**15-30 公分**，手掌張開保持穩定
- 避免強光直射或極暗環境

### Step 3：重新錄入

- 若距離正確仍反覆失敗 → 進入 APP 設定 → 刪除舊的人臉/掌靜脈 → 重新錄入
- 錄入時確保光線充足、正對鏡頭

### Step 4：判定

- 重新錄入後仍無法辨識 → 可能是鏡頭硬體問題 → **需派工**

## 需派工的條件

- ❌ 紅燈亮起但反覆辨識失敗（重新錄入後仍無效）
- ❌ 紅燈完全不亮（觸摸螢幕也無反應）
- ❌ 鏡頭表面損壞或遮擋
