# 驗證失敗與錯誤碼 — 故障排除 SOP

**嚴重度：3** ｜ **分類：驗證故障**

## 必須收集的資訊

| 欄位 | 追問話術 | 必要性 |
|------|---------|--------|
| 品牌 | 「請問您的電子鎖是什麼品牌？」 | ✅ 必要 |
| 解鎖方式 | 「您是用什麼方式解鎖的？指紋、密碼、卡片、人臉、掌靜脈？」 | ✅ 必要 |
| 錯誤顯示 | 「螢幕或面板有顯示什麼嗎？閃爍數字、紅燈？」 | 建議收集 |
| 其他方式是否可用 | 「其他開鎖方式也都無法使用嗎？」 | ✅ 必要 |

## SOP 步驟

### Step 1：判斷失敗範圍

- **單一方式失敗** → Step 2
- **所有方式都失敗** → Step 5（系統層級問題）

### Step 2：指紋辨識失敗

依序確認：
1. 手指太乾或太濕 →「搓搓手」或「擦乾後重試」
2. 手指有傷口或脫皮 → 建議使用其他手指或替代方式
3. 老人/小孩指紋較淺 → 建議多設定幾根手指或改用其他方式
4. 設定時偏差（只掃了部分指紋）→ 重新設定，確保面積完整
5. 感應區髒污 → 用乾布擦拭
6. **指紋辨識靈敏度因人而異，針對不同族群的指紋設定建議：**
   - 小孩：建議指紋區域足夠覆蓋時再設定，並定期更新。
   - 青少年及35歲內成年人：指紋清晰，設定1-2次即可。
   - 中年人：建議常用手指重複設定至少2-3次。
   - 老年人及長輩：建議常用手指設定至少3次以上。
   - 家庭主婦及勞力工作者：因手部狀況，建議同一隻手指設定3次以上。
7. **指紋辨識失效可能原因：**
   - 手指受傷、指頭太小、指紋太少、設定偏差。
   - 手指過於乾燥或脫皮、過濕。
   - 受傷後新皮生長或幾乎無指紋者。

### Step 3：密碼失敗

確認：
1. **是否混淆「管理者密碼」與「一般開門密碼」**
   - 管理者密碼：可進入設定選單，也可用於日常開門（兩者可以是同一組密碼）
   - 一般密碼：僅能開門，無法進入設定選單
   - ⚠️ 管理者密碼與一般密碼可以相同，但功能權限不同
2. 密碼長度是否正確（通常 6-12 位）
3. 是否連續輸錯觸發防盜鎖定
   - Dormakaba（一般解鎖模式）：連續 5 次錯誤 → 3 分鐘鎖定，等待鎖定時間結束後重試
   - Dormakaba（註冊模式）：按下註冊鍵後進入的設定模式，**不受密碼錯誤次數鎖定限制**

### Step 4：卡片 / 人臉 / 掌靜脈失敗

- **卡片**：確認是已登記的卡片、NFC 感應位置正確
- **人臉**：距離鏡頭約 60 公分，正對鏡頭，兩側紅燈亮起 = 辨識中
- **掌靜脈**：手掌距離 15-30 公分，保持穩定
- **人臉 / 掌靜脈辨識與防回頭機制**：
  - 感應啟動時，鏡頭兩側會亮起紅燈；感應成功後，電子鎖會顯示「已開鎖」。
  - 電子鎖上鎖後，紅燈不會立即亮起，此為「防回頭機制」，通常設定為約20秒，旨在防止使用者出門後因感應到自身人臉而再次開鎖。
  - 若有生物（如人、貓狗）經過鎖前，可能觸發感應器使紅燈亮起並嘗試辨識。若辨識失敗，紅燈會熄滅，並重新等待20秒。
  - 若使用者在此期間到達鎖前，發現感應燈未自動亮起，代表在20秒內曾有物體經過，此時需手動觸摸螢幕以啟動紅外線感應，進行開鎖，此為正常現象。
  - AI-99系列電子鎖可透過軟體更新，進入系統設定（管理者驗證）→「功能設定」→ 調整「防回頭時間」，可選擇5秒、10秒、15秒，或關閉（即使關閉仍保留2-3秒以確保門閂上鎖）。

### Dormakaba 面板回饋判讀

- **面板閃兩下就熄滅**：代表輸入了錯誤的管理者密碼或感應了錯誤的管理者卡片，**並非電量不足**
- **電量不足的正確表現**：語音提示或面板上電池圖示閃爍
- **數字 6 閃爍**：使用者資訊未存於鎖內

### Step 5：所有方式都失敗

1. 面板顯示「6」（Dormakaba）→ 使用者資訊未存於鎖內
2. 是否有人執行過恢復出廠設定（會清除所有使用者）
3. 嘗試**實體鑰匙**開門
   - 電子門鎖保留傳統鑰匙功能，主要為應對電子系統非預期故障時的備用解鎖方式。
   - 實體鑰匙切勿放在家中，建議放置於車內、信任的親友家或常用隨身包中作為緊急備用。若因鑰匙遺失或未攜帶導致無法進門，此為人為因素，不在保固範圍內。
   - 若門鎖故障或失效，且設有鑰匙孔，應使用鑰匙進門。若無鑰匙且無法進門，可能需破壞鎖，此情況歸類為人為因素，需檢測是否在保固內及是否為非人為因素導致故障。
4. 連鑰匙都無法使用 → 機械故障 → **需緊急派工**
5. **電力耗盡應變**：
   - 若不幸沒電，可透過９Ｖ電池緊急供電（需購買長方形有兩顆頭的電池）或ＵＳＢ緊急供電（使用行動電源插線）應變，具體方式依門鎖型號而異。
6. **AI-99 緊急開鎖與供電**：
   - 緊急開啟位置：外門中間偏下方，由一個圓形蓋子隱藏。
   - 開啟圓形蓋子：向下按壓並向右旋轉。
   - 蓋子開啟後：內部左側為 Type-C 充電孔，右側為備用鑰匙孔。
   - 機械開鎖：當電力耗盡時，將備用專屬鑰匙插入右側鑰匙孔並轉動，隨後拔出鑰匙，門鎖將發出「嗶」聲，表示已成功解鎖，即可開門。
   - 緊急供電：當電力耗盡時，可利用具備 Type-C 插頭的行動電源，將其充電線插入左側的 Type-C 充電孔，為門鎖進行緊急供電以喚醒電子系統。
   - 供電後開門：門鎖會發出「嗶」聲，表示已通電喚醒。此後，使用者即可透過指紋、密碼等電子驗證方式進行開門操作。

### Step 6：成功進門後重新設定

**Chainlock**：齒輪圖示 → 管理者驗證（支援指紋/密碼/卡片/人臉/掌靜脈）→ 用戶管理 → 重新登記

**Dormakaba**：若管理者密碼遺失 → ⚠️ **必須聯繫技師進行初始化重設**

### 電池使用建議

- 電子門鎖務必使用鹼性電池，以避免電池漏液損壞內部面板零組件，導致門鎖報銷。
- 碳鋅電池適合小功率供電，平均電壓約1.5V；鹼性電池電壓可達1.7V，適合電子門鎖待機及大功率啟動需求。建議使用P牌鹼性電池。

### Waferlock 特定問題

- 若密碼與指紋辨識功能突然失效，但藍牙解鎖仍可正常運作，且鎖體活動紀錄停止更新，同時輸入錯誤密碼時無任何錯誤提示，則可能表示電子鎖系統存在異常。
- 當密碼或指紋解鎖功能異常時，可嘗試使用感應卡片進行解鎖，以判斷問題是否僅限於特定解鎖方式。
- 若遇到應用程式相關問題或設定後無法正常解鎖的狀況，建議直接聯繫原廠官方 Line 帳號 `@waferlock` 尋求技術支援。

## 需派工的條件

- ❌ 所有驗證方式 + 實體鑰匙都無法開門
- ❌ Dormakaba 管理者密碼遺失需初始化
- ❌ 面板無任何反應（疑似主板故障）
- ❌ 感應器硬體損壞
