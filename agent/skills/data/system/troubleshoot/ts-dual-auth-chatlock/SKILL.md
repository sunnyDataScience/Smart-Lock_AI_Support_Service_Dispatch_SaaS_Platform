# 雙重認證誤觸 — Chainlock/Chatlock 故障排除 SOP

**嚴重度：2** ｜ **分類：設定問題**

## 必須收集的資訊

| 欄位 | 追問話術 | 必要性 |
|------|---------|--------|
| 目前行為 | 「目前開門需要什麼步驟？先輸密碼再刷卡？先按指紋再輸密碼？」 | ✅ 必要 |
| 能否進設定 | 「您目前可以進到門鎖的設定選單嗎？」 | ✅ 必要 |

## SOP 步驟

### Step 1：確認雙重認證狀態

請客戶嘗試單一方式解鎖（僅密碼 或 僅指紋），確認是否需要兩種方式才能開門。

### Step 2：關閉雙重認證

操作路徑：**齒輪 → 管理者驗證 → 高級設定 → 雙重認證 → 關閉**

1. 觸碰螢幕喚醒面板
2. 點擊齒輪圖示進入系統設定
3. 管理者驗證（指紋/密碼/卡片/人臉/掌靜脈皆可）
4. 進入「高級設定」
5. 找到「雙重認證模式」
6. 將綠色開關切換為灰色（關閉）
7. 確認顯示「設定成功」

### Step 3：驗證結果

> 「請用單一方式（如只用指紋）試試看能不能正常開門」

- **成功** → 提醒客戶注意此設定的位置，避免再次誤觸
- **失敗** → 請客戶重新操作一次

### Step 4：無法進入設定時

嘗試其他管理者驗證方式（支援 5 種：指紋/密碼/卡片/人臉/掌靜脈），若全部遺忘 → 需聯繫技師

## 需派工的條件

- ❌ 客戶無法取得管理者權限
- ❌ 所有管理者驗證方式都遺忘
- ❌ 遠端指導多次仍無法成功操作
