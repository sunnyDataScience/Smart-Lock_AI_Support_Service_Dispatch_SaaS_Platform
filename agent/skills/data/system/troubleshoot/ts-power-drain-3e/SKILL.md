# 異常耗電 — 3E小島快鎖 故障排除 SOP

**嚴重度：2** ｜ **分類：電力/網路問題**

## 必須收集的資訊

| 欄位 | 追問話術 | 必要性 |
|------|---------|--------|
| 電池品牌 | 「目前用的是什麼牌子的電池？包裝什麼顏色？」 | ✅ 必要 |
| 電池類型 | 「是一般 AA 鹼性電池還是鋰電池（充電式）？」 | ✅ 必要 |
| 是否聯網 | 「您的電子鎖有連接 Wi-Fi 嗎？」 | ✅ 必要 |
| 耗電速度 | 「大約多久會收到低電量提示？」 | ✅ 必要 |

## 異常耗電判斷標準

> 換新電池或鋰電池充飽後，**一個月內**再次收到低電量提示 = 異常耗電
> 正常：8 顆鹼性電池約可撐 **8 個月至 1 年**。

## SOP 步驟

### Step 1：檢查電池品牌（最常見原因）

| 狀態 | 說明 |
|------|------|
| ✅ 正確 | **Panasonic 鹼性電池**（國際牌3號金紅包裝、金藍色包裝）或太元素電池 |
| ❌ 禁止 | 金鼎等非 Panasonic 品牌（極易漏液導致故障） |
| ❌ 禁止 | 碳鋅電池（電壓不穩定） |

> 電池品牌錯誤是最常見的異常耗電原因，確認後請客戶更換正確電池即可。

### 3E 小島快鎖F(T7) 電池更換
- **電池類型：** 務必使用四顆全新的3號（AA）鹼性電池。
- **操作步驟：**
    1. 推開門鎖背面的電池蓋。
    2. 取出電池盒並從中取出舊電池。
    3. 將四顆全新的3號鹼性電池依循正負極方向正確放入電池盒中。
    4. 將裝好電池的電池盒重新插入門鎖，並蓋上電池蓋。
    - 門鎖會發出語音提示「操作成功」，表示更換完成。

### Step 2：檢查 Wi-Fi 設定

若電子鎖有連接 Wi-Fi，確認：
1. **是否連接 2.4G 頻段**（❌ 不支援 5G）
2. **路由器 2.4G 和 5G 是否分開設定**（合併 = 異常耗電！）
3. **是否使用 Wi-Fi 6/7/8 路由器**（協定相容性差，可能異常耗電）

### Step 3：其他排查

若電池和 Wi-Fi 都排除後仍異常：
- 開關門速度是否變慢 → 電壓不足症狀
- 鎖栓伸縮是否異常 → 機械阻力增加耗電

### 緊急供電與開鎖

#### 3E 小島快鎖F(T7)
- **鑰匙緊急解鎖：**
    1. 推開門鎖底部的隱藏式蓋板，露出鑰匙孔。
    2. 將實體鑰匙插入鑰匙孔並轉動，門鎖會發出語音提示「開鎖」。
    3. 若需關鎖，再次轉動鑰匙，門鎖會提示「關鎖」。
    4. 完成後，取出鑰匙並蓋回蓋板。
- **行動電源緊急供電：**
    1. 將Type-C充電線插入門鎖底部的Type-C緊急供電孔（位於機器下方）。
    2. 門鎖螢幕將會亮起並顯示數字鍵盤，並發出語音提示「正在更新本地時間」及「操作成功」。
    3. 螢幕顯示「5」和綠色指示燈，表示啟動完成。
    4. 隨後，使用者可利用已註冊的卡片、指紋或密碼進行解鎖。
    - **重要提示：** 進入室內後務必更換電池。

### Step 4：判定

- 機械問題增加耗電 → 解決鎖舌卡澀
- 仍無法解決 → 可能為主板或馬達問題 → **需派工**

## 需派工的條件

- ❌ 更換正確電池 + 修正 Wi-Fi 設定後仍異常耗電
- ❌ 疑似馬達或主板異常耗電
- ❌ 電池槽或接點腐蝕
