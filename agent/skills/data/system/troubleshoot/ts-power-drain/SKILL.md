# 異常耗電 — 故障排除 SOP

**嚴重度：2** ｜ **分類：電力/網路問題**

## 必須收集的資訊

| 欄位 | 追問話術 | 必要性 |
|------|---------|--------|
| 品牌 | 「請問您的電子鎖是什麼品牌？」 | ✅ 必要 |
| 電池品牌 | 「目前用的是什麼牌子的電池？包裝什麼顏色？」 | ✅ 必要 |
| 電池類型 | 「是一般 AA 鹼性電池還是鋰電池（充電式）？」 | ✅ 必要 |
| 是否聯網 | 「您的電子鎖有連接 Wi-Fi 嗎？」 | ✅ 必要 |
| 耗電速度 | 「大約多久會收到低電量提示？」 | ✅ 必要 |

## 異常耗電判斷標準

> 換新電池或鋰電池充飽後，**一個月內**再次收到低電量提示 = 異常耗電
> 正常：8 顆鹼性電池約可撐 **8 個月至 1 年**

## SOP 步驟

### Step 1：檢查電池品牌（最常見原因 🔴）

| 狀態 | 說明 |
|------|------|
| ✅ 正確 | **Panasonic 鹼性電池**（金紅包裝）或太元素電池 |
| ❌ 禁止 | 金鼎等非 Panasonic 品牌（極易漏液導致故障） |
| ❌ 禁止 | 碳鋅電池（電壓不穩定） |

**鋰電池充電規範：**
- 必須用 **5V1A 或 5V2A** 充電頭
- ❌ 禁止使用任何快充設備
- 充電線：Type-C 轉 Type-A

> 💡 電池品牌錯誤是最常見的異常耗電原因，確認後請客戶更換正確電池即可。

### Step 2：檢查 Wi-Fi 設定

若電子鎖有連接 Wi-Fi，確認：

1. **是否連接 2.4G 頻段**（❌ 不支援 5G）
2. **路由器 2.4G 和 5G 是否分開設定**（合併 = 異常耗電！）
3. **是否使用 Wi-Fi 6/7/8 路由器**（協定相容性差，可能異常耗電）

**解法：**
- 確保路由器 2.4G 和 5G 分開設定
- 若使用新標準路由器 → 購買僅支援 2.4G 的入門級路由器供電子鎖專用

### Step 3：其他排查

若電池和 Wi-Fi 都排除後仍異常：
- 開關門速度是否變慢 → 電壓不足症狀
- 鎖栓伸縮是否異常 → 機械阻力增加耗電 → 呼叫 load_skill("ts-lock-tongue")
- 電量顯示是否異常跳動

### Step 4：判定

- 機械問題增加耗電 → 解決鎖舌卡澀
- 仍無法解決 → 可能為主板或馬達問題 → **需派工**

## 需派工的條件

- ❌ 更換正確電池 + 修正 Wi-Fi 設定後仍異常耗電
- ❌ 疑似馬達或主板異常耗電
- ❌ 電池槽或接點腐蝕（使用錯誤電池導致漏液）
