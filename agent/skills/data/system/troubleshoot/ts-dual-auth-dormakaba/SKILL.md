# 雙重認證誤觸 — Dormakaba 故障排除 SOP

**嚴重度：2** ｜ **分類：設定問題**

## 必須收集的資訊

| 欄位 | 追問話術 | 必要性 |
|------|---------|--------|
| 目前行為 | 「目前開門需要什麼步驟？先輸密碼再刷卡？先按指紋再輸密碼？」 | ✅ 必要 |
| 能否進設定 | 「您目前可以進到門鎖的設定選單嗎？」 | ✅ 必要 |

## SOP 步驟

### Step 1：確認雙重認證狀態

請客戶嘗試單一方式解鎖（僅密碼 或 僅指紋），確認是否需要兩種方式才能開門。

### Step 2：關閉雙重認證

操作口訣：**門開 → Close → 管理者密碼 → * → 8**

1. 確認門是開啟狀態
2. 按下 Close 鍵（上鎖鍵）
3. 輸入管理者密碼
4. 按 `*` 鍵一次
5. 按數字 `8`
6. 完成後測試單一方式解鎖

### Step 3：驗證結果

> 「請用單一方式（如只用指紋）試試看能不能正常開門」

- **成功** → 提醒客戶注意此設定的位置，避免再次誤觸
- **失敗** → 請客戶重新操作一次

### Step 4：無法進入設定時

管理者密碼遺忘 → **必須聯繫技師初始化** → 需派工

## 需派工的條件

- ❌ 客戶無法取得管理者權限
- ❌ Dormakaba 管理者密碼遺失
- ❌ 遠端指導多次仍無法成功操作
