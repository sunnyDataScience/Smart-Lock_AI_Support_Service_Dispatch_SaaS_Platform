# 異常耗電 — Chatlock 故障排除 SOP

**嚴重度：2** ｜ **分類：電力/網路問題**

## 必須收集的資訊

| 欄位 | 追問話術 | 必要性 |
|------|---------|--------|
| 型號 | 「請問型號是什麼？（AI-99、A90 等）」 | ✅ 必要 |
| 電池品牌 | 「目前用的是什麼牌子的電池？包裝什麼顏色？」 | ✅ 必要 |
| 電池類型 | 「是一般 AA 鹼性電池還是鋰電池（充電式）？」 | ✅ 必要 |
| 是否聯網 | 「您的電子鎖有連接 Wi-Fi 嗎？」 | ✅ 必要 |
| 耗電速度 | 「大約多久會收到低電量提示？」 | ✅ 必要 |

## 異常耗電判斷標準

> 換新電池或鋰電池充飽後，**一個月內**再次收到低電量提示、閃爍提示或遠端APP顯示電量低 = 異常耗電
> 正常：8 顆鹼性電池約可撐 **8 個月至 1 年**（此數據以平均每天開關門10次左右計算），聯網型電子鎖設計目標為 **三至六個月以上** 的電池續航力。
- 當電子鎖電池電量不足時，在開關門操作時，可能會出現閃爍提示燈號並伴隨「B B B」的警示音。

## SOP 步驟

### 重要提示

當電子鎖出現密碼輸入異常、指紋感應不良、卡片感應問題、不明警報響起、或異常耗電（電池快速耗盡）等狀況，都應首先檢查電池是否正確。任何電子鎖使用異常，客服應首先確認電池類型。聯網型電子鎖若出現網路連線緩慢或通訊問題，也應先檢查電池。

### Step 1：檢查電池品牌（最常見原因）

| 狀態 | 說明 |
|------|------|
| ✅ 正確 | **Panasonic 鹼性電池**（國際牌3號金紅包裝、金藍色包裝）或太元素電池。此類電池在一般電器行或全國電子等通路均可購得。 |
| ❌ 禁止 | 金鼎等非 Panasonic 品牌（極易漏液導致故障） |
| ❌ 禁止 | 碳鋅電池（電壓不穩定） |

電子門鎖務必使用鹼性電池，以避免電池漏液損壞內部面板零組件，導致門鎖報銷。鎖市建議使用P牌鹼性電池。

**鋰電池充電規範：**
- 必須用 **5V1A 或 5V2A** 充電頭
- ❌ 禁止使用任何快充設備（僅限使用舊款iPhone豆腐頭等低功率充電器）
- 充電線：Type-C 轉 Type-A

> 電池品牌錯誤是最常見的異常耗電原因，確認後請客戶更換正確電池即可。

### Step 2：檢查 Wi-Fi 設定

若電子鎖有連接 Wi-Fi，確認：

1. **是否連接 2.4G 頻段**（❌ 不支援 5G）
2. **路由器 2.4G 和 5G 是否分開設定**（合併 = 異常耗電！）
3. **是否使用 Wi-Fi 6/7/8 路由器**（協定相容性差，可能異常耗電）

**解法：**
- 確保路由器 2.4G 和 5G 分開設定，並限制頻寬使用。
- 若使用新標準路由器：嘗試調整路由器後台的特定設定。若調整後仍無效，建議購買一台僅支援 2.4G 功能的入門級路由器（約500元）供電子鎖專用。

### Step 3：其他排查

若電池和 Wi-Fi 都排除後仍異常：
- 開關門速度是否變慢 → 電壓不足症狀
- 鎖栓伸縮是否異常 → 機械阻力增加耗電 → 呼叫 load_skill("ts-lock-tongue-chatlock")
- 鎖舌與門框是否未正確對準
- 電量顯示是否異常跳動

### 緊急供電與開鎖

#### AI-99 電子鎖
- **緊急開啟位置：** 位於外門中間偏下方，由一個圓形蓋子隱藏。
- **開啟蓋子：** 向下按壓並向右旋轉圓形蓋子，以露出內部緊急操作介面。
- **內部介面：** 顯露兩個孔洞，左側為Type-C充電孔，右側為備用鑰匙孔。
- **備用鑰匙開鎖：**
    1. 將備用專屬鑰匙插入右側鑰匙孔並轉動。
    2. 拔出鑰匙，門鎖將發出「嗶」聲，表示已成功解鎖，即可開門。
- **Type-C 緊急供電：**
    1. 利用具備Type-C插頭的行動電源，將其充電線插入左側的Type-C充電孔，為門鎖進行緊急供電以喚醒電子系統。
    2. 門鎖發出「嗶」聲表示已通電喚醒。
    3. 隨後，使用者即可透過指紋、密碼等電子驗證方式進行開門操作。

#### Chatlock A90 智慧門鎖
- **Type-C 緊急供電：**
    1. 找到外門鎖單元下方的圓形孔蓋。
    2. 向下按壓孔蓋的下緣，隨後向右旋轉，將孔蓋取下，露出Type-C充電埠及一個小型指示燈。
    3. 將備妥的Type-C行動電源透過Type-C充電線連接至門鎖的Type-C充電埠。
    4. 連接後，門鎖螢幕將會立即亮起，顯示「chatlock」標誌及操作介面，此時門鎖已成功喚醒並可使用預設的指紋、密碼等辨識方式進行解鎖。
    5. 完成緊急供電及解鎖操作後，拔除Type-C充電線，並將圓形孔蓋放回原位。
    6. 向左旋轉孔蓋以確保其穩固鎖定，使門鎖恢復至初始狀態。

### 機械鑰匙使用與保管提示
- 電子門鎖的實體鑰匙切勿放在家中，建議放置於車內、信任的親友家或常用隨身包中作為緊急備用。
- 若因鑰匙遺失或未攜帶導致無法進門，此為人為因素，不在保固範圍內。

### Step 4：判定

- 機械問題增加耗電 → 解決鎖舌卡澀
- 仍無法解決 → 可能為主板或馬達問題 → 需請專業技師檢測 → **需派工**

## 需派工的條件

- ❌ 更換正確電池 + 修正 Wi-Fi 設定後仍異常耗電
- ❌ 疑似馬達或主板異常耗電
- ❌ 電池槽或接點腐蝕（使用錯誤電池導致漏液）
