# 異常警報聲響 — 故障排除 SOP

**嚴重度：3** ｜ **分類：警報異常**

## 必須收集的資訊

| 欄位 | 追問話術 | 必要性 |
|------|---------|--------|
| 品牌 | 「請問您的電子鎖是什麼品牌？」 | ✅ 必要 |
| 聲音模式 | 「可以形容一下聲音嗎？大概幾聲？（短嗶 3 聲、長鳴 3 秒、連續嗶不停等）」 | ✅ 必要 |
| 觸發時機 | 「聲音什麼時候出現？（關門時、開門時、半夜突然響、裝電池時）」 | ✅ 必要 |
| 燈號狀態 | 「有注意到燈號嗎？紅燈閃幾次？面板顯示什麼數字？」 | 建議收集 |

> 💡 若客戶無法辨識警報模式，**請客戶錄一段聲音或影片傳送過來**，這是最有效的診斷方式。

## 常見原因排查（按可能性排序）

1. **電池品牌錯誤**（最常見）
   - 確認是否使用 Panasonic 鹼性電池（金紅包裝）
   - ❌ 禁止使用金鼎或碳鋅電池（極易漏液）
   - 更換正確電池

2. **地震觸發防盜感應器**
   - 詢問最近是否有地震
   - 正常現象，警報會自動停止

3. **電池安裝方向錯誤**
   - 確認正負極方向，重新安裝

4. **關鎖失敗**
   - 鎖栓撞到受口片或門框 → 調整受口片

## 需派工的條件

- ❌ Dormakaba 紅燈閃 4 次（馬達異常）
- ❌ 更換正確電池後警報仍持續
- ❌ 受口片嚴重偏位導致反覆關鎖失敗
- ❌ 系統異常重啟後仍無法解除
