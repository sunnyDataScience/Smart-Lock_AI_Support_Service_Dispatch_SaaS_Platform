# 驗證失敗 — 通用故障排除 SOP

**嚴重度：3** ｜ **分類：驗證故障**

## 必須收集的資訊

| 欄位 | 追問話術 | 必要性 |
|------|---------|--------|
| 解鎖方式 | 「您是用什麼方式解鎖的？指紋、密碼、卡片？」 | ✅ 必要 |
| 錯誤顯示 | 「螢幕或面板有顯示什麼嗎？」 | 建議收集 |
| 其他方式是否可用 | 「其他開鎖方式也都無法使用嗎？」 | ✅ 必要 |

## SOP 步驟

### Step 1：判斷失敗範圍

- **單一方式失敗** → Step 2
- **所有方式都失敗** → Step 5（系統層級問題）

### Step 2：指紋辨識失敗

依序確認：
1. 手指太乾或太濕 →「搓搓手」或「擦乾後重試」
2. 手指有傷口或脫皮 → 使用其他手指或替代方式
3. 老人/小孩指紋較淺 → 多設定幾根手指或改用其他方式
4. 設定時偏差 → 重新設定，確保面積完整
5. 感應區髒污 → 用乾布擦拭
6. **指紋辨識靈敏度因人而異：**
   - 小孩：建議指紋區域足夠覆蓋時再設定，並定期更新。
   - 中年人：建議常用手指重複設定至少2-3次。
   - 老年人及長輩：建議常用手指設定至少3次以上。
   - 家庭主婦及勞力工作者：建議同一隻手指設定3次以上。

### Step 3：密碼失敗

確認：
1. 密碼長度是否正確（通常 6-12 位）
2. 是否連續輸錯觸發防盜鎖定

### Step 4：卡片失敗

- 確認是已登記的卡片、NFC 感應位置正確

### Step 5：所有方式都失敗

1. 是否有人執行過恢復出廠設定（會清除所有使用者）
2. 嘗試**實體鑰匙**開門
   - 實體鑰匙切勿放在家中，建議放置於車內、信任的親友家或常用隨身包中。
3. 連鑰匙都無法使用 → 機械故障 → **需緊急派工**
4. **電力耗盡應變：** 可透過 9V 電池或 USB 緊急供電，具體方式依門鎖型號而異。

### 電池使用建議

- 電子門鎖務必使用鹼性電池，以避免電池漏液損壞內部面板零組件。建議使用P牌鹼性電池。

## 需派工的條件

- ❌ 所有驗證方式 + 實體鑰匙都無法開門
- ❌ 面板無任何反應（疑似主板故障）
- ❌ 感應器硬體損壞
