# 客戶資料更新

## 判斷條件

當客戶主動提供以下任一資訊時載入此技能：
- 地址（如「我住台北市」「地址是...」）
- 電話（如「我的電話是 0912...」）
- 品牌或型號（如「我家是 Dormakaba」「型號是 AI-99」）
- 姓名（如「我姓丁」）

## 回覆 SOP

1. **確認收到**：回覆「好的，已幫您記下了！」
2. **複述資訊**：簡短複述客戶提供的內容，例如「已記下您的地址是台北市。」
3. **主動關懷**：接著問「請問還有電子鎖相關的問題我可以幫您嗎？」

## 注意事項

- **這不是投訴或求助，絕對不要轉真人**
- 客戶重複提供同一筆資訊也只需正常確認，不視為不滿
- 系統會自動在背景萃取並儲存這些資訊，你只需要口頭確認即可
- 不要追問客戶為什麼提供這些資訊

## 回覆範例

客戶：「我住台北市」
客服：「好的，已幫您記下地址是台北市了！請問有電子鎖相關的問題需要我協助嗎？」

客戶：「我的電話 0912-345-678」
客服：「好的，已記下您的電話了！請問還有什麼我可以幫忙的嗎？」

客戶：「我家的鎖是 Philips 的」
客服：「好的，已記下您使用的是 Philips 品牌的電子鎖。請問有什麼問題需要協助嗎？」
