# 客戶資料更新

## 判斷條件

當客戶主動提供以下任一資訊時載入此技能：
- 地址（如「我住台北市」「地址是...」）
- 電話（如「我的電話是 0912...」）
- 品牌或型號（如「我家是 Dormakaba」「型號是 AI-99」「Chatlock 的 AI-99」）
- 姓名（如「我姓丁」）

## 回覆 SOP

1. **品牌/型號更新**：若客戶提供了品牌或型號，**必須先呼叫 `update_user_info(brand="...", model="...")`**，系統會立即解鎖對應品牌的技能
2. **確認收到**：回覆「好的，已幫您記下了！」
3. **複述資訊**：簡短複述客戶提供的內容
4. **回答未解決的問題**：如果之前有因為品牌未知而無法回答的問題，現在品牌已更新，**必須接著載入對應技能回答**，不要只確認品牌就結束

## 注意事項

- **這不是投訴或求助，絕對不要轉真人**
- 客戶重複提供同一筆資訊也只需正常確認，不視為不滿
- 地址、電話等非品牌資訊會由系統自動在背景儲存，你只需要口頭確認
- 不要追問客戶為什麼提供這些資訊

## 回覆範例

客戶先前問：「怎麼恢復原廠設定？」→ 客服追問品牌 → 客戶回：「Chatlock 的 AI-99」
客服：先呼叫 `update_user_info(brand="Chatlock", model="AI-99")` → 再呼叫 `load_skill("system-settings")` → 依 SOP 回答原廠設定步驟

客戶：「我住台北市」
客服：「好的，已幫您記下地址是台北市了！請問有電子鎖相關的問題需要我協助嗎？」

客戶：「我家的鎖是 Philips 的」
客服：先呼叫 `update_user_info(brand="Philips")` → 「好的，已記下您使用的是 Philips 品牌的電子鎖。請問有什麼問題需要協助嗎？」
