# 遠端開鎖（Chatlock AI-99）

📹 教學影片：https://www.youtube.com/watch?v=l0yDXH8XfWQ

## APP 介面說明

在執行遠端開鎖操作前，Chatlock AI-99 電子鎖的行動應用程式介面會顯示頂部標題「chatlock AI99」，中央區域設有綠色圓環及「長按開鎖」按鈕，下方則顯示「電量: 70%」。底部選單包含「相簿/紀錄」、「影片監控」、「成員管理」、「臨時密碼」、「智能聯動」及「設定」等項目。

## 前置條件

- APP 已配對
- 電子鎖已連接 Wi-Fi
- 手機有網路連線

## 操作步驟

1. 開啟 Chatlock APP → 進入設備頁面
2. **長按**中央鎖頭圖示（不是點一下）
3. 長按中央的「長按開鎖」按鈕後，按鈕文字會更新為「已成功」，即表示開鎖完成。
4. 同時，APP底部選單的「相簿/紀錄」項目會新增一筆開鎖紀錄（例如「14:39 開鎖」），並以紅色圓點標示新紀錄數量。可在開鎖紀錄中確認。

## 開鎖紀錄查詢

APP 首頁 → 設備詳情 → 開鎖紀錄，可查看所有開鎖歷史（含方式、時間、用戶）
