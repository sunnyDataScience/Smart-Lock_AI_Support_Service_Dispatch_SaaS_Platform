# 語音留言（Chatlock AI-99）

📹 教學影片：https://www.youtube.com/watch?v=nA2w58yyeZM

## 錄製留言

1.  **從主螢幕進入留言功能：** 觸碰螢幕喚醒，在待機畫面點擊右方的「訊息圖示」。
2.  **啟動錄音：** 進入「留言」介面後，螢幕中央會顯示聲波動畫，下方則有「開始留言」按鈕；點選此按鈕以啟動留言錄製功能。
3.  **錄製留言：** 當開始錄製語音留言時，螢幕中央的大圓圈會顯示計時器，從「0.1」秒開始計數，下方按鈕會變更為「結束留言」。此時使用者可開始錄製所需留言內容。
4.  **結束並儲存留言：** 錄製完成後，使用者需點擊「結束留言」按鈕。螢幕將顯示「操作成功」訊息，表示留言已成功儲存。

## 播放留言

*   **進入留言介面：** 觸碰螢幕喚醒，點擊主螢幕右方的「訊息圖示」進入「留言」介面。完成留言錄製後，此介面中央圓圈會顯示留言時長（例如「5.3」秒），右側列表圖示旁會出現綠色「1」的通知標誌，表示有新留言，下方按鈕則顯示「試聽留言」。

1.  **查看留言列表：**
    *   若要查看留言列表，使用者應點擊右側帶有綠色通知標誌的「列表圖示」，而非「試聽留言」按鈕。
    *   系統將要求驗證管理員密碼。輸入正確密碼後，螢幕會切換至留言列表介面，顯示留言詳情（如時間戳記）及播放、已讀、刪除等操作選項。
2.  **播放特定留言：**
    *   在留言列表介面中，使用者可點擊特定留言條目以選取該留言。
    *   螢幕將返回「留言」介面，顯示選取留言的時長，下方按鈕變為「播放留言」。
    *   點擊此按鈕後，螢幕中央會顯示計時器，表示留言正在播放，下方按鈕則變為「結束播放」。

> 適用場景：出門前留言給家人、提醒訪客等
