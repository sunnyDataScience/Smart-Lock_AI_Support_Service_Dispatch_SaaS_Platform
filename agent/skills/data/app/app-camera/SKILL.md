# 即時影像監控（Chatlock AI-99）

📹 教學影片：https://www.youtube.com/watch?v=-ZLd3d8EMTk

> ⚠️ **僅限 AI99 型號**（A90/AI88 無攝影鏡頭）

## 操作步驟

1. 開啟 Chatlock APP → 影片監控
2. 等待建立加密連線
3. 即可查看即時畫面

## 功能

| 功能 | 說明 |
|------|------|
| 鏡頭切換 | 前鏡頭（門外）/ 後鏡頭（門內） |
| 語音對講 | 按住麥克風即可雙向通話 |
| 音量調整 | 畫面中可調整音量 |
| 拍照/錄影 | 即時拍照或錄影存檔 |
| 遠端開鎖 | 影像畫面中長按鎖頭可直接遠端開門 |
