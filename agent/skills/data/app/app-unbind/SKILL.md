# 設備解除綁定（Chatlock AI-99）

📹 教學影片：https://www.youtube.com/watch?v=_fCq6mPlsDM

## 操作步驟

1. 開啟 Chatlock APP → 點擊設備卡片
2. 右上角鉛筆圖示（編輯）
3. 頁面底部 →「移除裝置」

## 解綁選項

| 選項 | 說明 |
|------|------|
| 解除綁定 | 僅解除 APP 連結，保留鎖上的所有設定（指紋/密碼/人臉等） |
| 解綁並清除數據 | 解除連結 + 清除 APP 端數據（不影響鎖上的生物辨識資料） |

## 常見情境

| 情境 | 建議 |
|------|------|
| 換手機 | 舊手機解綁 → 新手機重新配對 |
| 轉讓給別人 | 解綁 + 建議鎖上也恢復出廠設定 |
| APP 異常 | 解綁 → 重新配對 |
