## 入口

觸碰螢幕 → 螢幕左下角「系統設定」圖示（齒輪）→ 功能設定

## 各功能說明

### 語音音量
主選單 → 系統設定 → 功能設定 → 音量設定 → 語音音量 → 選擇「靜音」、「低音量」、「中音量」或「高音量」。設定成功後螢幕會顯示「設定成功」提示。

### 門鈴音量
主選單 → 系統設定 → 功能設定 → 音量設定 → 門鈴音量 → 選擇「靜音」、「低音量」、「中音量」或「高音量」。設定成功後螢幕會顯示「設定成功」提示。

### 語言切換
主選單 → 系統設定（齒輪圖示）→ 功能設定（齒輪圖示）→ 語言設定（語音氣泡圖示）→ 選擇語系（例如「繁體中文」旁的圓形選取框）。設定成功後螢幕會顯示「設定成功」提示。

### 童鎖（兒童鎖）
主選單 → 系統設定 → 進階設定 → 童鎖 → 點擊開關將狀態由灰色切換至綠色以開啟。開啟後，門內必須按壓把手才能開門，防止幼童自行開門。設定成功後螢幕會顯示「設定成功」提示。

### 常開模式
主選單 → 系統設定 → 進階設定 → 常開模式 → 點擊開關將狀態從關閉（灰色）切換至開啟（綠色）。開啟後門鎖保持不上鎖狀態（適用營業場所）。設定成功後螢幕會顯示「設定成功」提示。

### 雙重認證
進階設定 → 雙重認證 → 開啟後需兩種方式驗證才能開門（如指紋+密碼）

### 恢復出廠設定
主選單 → 系統設定 → 向下滑動 → 恢復出廠設定 → 彈出「恢復預設設定?」確認對話框，點擊「確認」。系統將顯示「正在恢復出廠設置中 請稍後...」進度，完成後顯示「恢復出廠成功」。此操作將清除所有資料（⚠️ 不可復原）。
