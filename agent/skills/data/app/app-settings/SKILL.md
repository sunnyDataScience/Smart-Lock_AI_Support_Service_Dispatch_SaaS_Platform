## 入口

觸碰螢幕 → 齒輪（系統設定）→ 功能設定

## 各功能說明

### 語音音量
功能設定 → 語音音量 → 調整 0~10 級

### 門鈴音量
功能設定 → 門鈴音量 → 調整 0~10 級

### 語言切換
功能設定 → 語言 → 選擇語系

### 童鎖（兒童鎖）
進階設定 → 童鎖 → 開啟後，門內必須按壓把手才能開門，防止幼童自行開門

### 常開模式
進階設定 → 常開模式 → 開啟後門鎖保持不上鎖狀態（適用營業場所）

### 雙重認證
進階設定 → 雙重認證 → 開啟後需兩種方式驗證才能開門（如指紋+密碼）

### 恢復出廠設定
系統設定 → 恢復出廠 → 確認後所有資料清除（⚠️ 不可復原）
