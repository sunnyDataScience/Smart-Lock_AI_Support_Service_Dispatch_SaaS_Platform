# 門扇卡死無法開啟 — 通用故障排除 SOP

**嚴重度：5（最高）** ｜ **分類：物理故障**

## 必須收集的資訊

| 欄位 | 追問話術 | 必要性 |
|------|---------|--------|
| 型號/開門方式 | 「型號是什麼？不確定的話，開門是把手下壓還是推拉？」 | ✅ 必要 |
| 開門方向 | 「您的門是向外拉開還是向內推開？」 | ✅ 必要 |
| 馬達聲 | 「按開鎖時，有聽到嗡嗡的馬達聲嗎？」 | ✅ 必要 |
| 目前位置 | 「您現在人在門外還是門內？」 | ✅ 必要 |

## SOP 步驟

### Step 1：確認馬達聲

請客戶按下開鎖鍵，聽是否有馬達運轉聲。

- **有馬達聲** → 前往 Step 2（機械卡死排除）
- **無馬達聲** → 可能是馬達故障或電力問題 → 前往 Step 5

### Step 2：推緊門板法（核心解法）

> 原理：先消除鎖舌與受口片的摩擦力，解鎖後門即可開啟

根據開門方向，指導對應操作（不分室內外，操作方式相同）：

**門是拉開的：**
> 「請先用力把門往門框方向推緊、不要放手，然後按解鎖，門就可以拉開了」

**門是推開的：**
> 「請先用力把門往自己的方向拉緊、不要放手，然後按解鎖，門就可以推開了」

### Step 3：確認結果

- **成功開門** → 告知客戶是鎖舌與受口片間隙問題，建議安排師傅調整，前往 Step 4
- **仍無法開門** → 前往 Step 5

### Step 4：預防建議

> 「這個問題通常是受口片與鎖舌之間缺乏 1-2mm 縫隙造成的，建議安排師傅到場微調受口片位置，避免反覆發生。」

### Step 5：進階排查

確認以下可能原因：
- 門縫是否有異物卡住
- 門扇是否下沉（底部摩擦地面）
- 是否有門扇反弓現象 → 呼叫 load_skill("ts-door-rebound")
- 鎖栓在門開啟狀態下是否能正常伸縮

若鎖栓無法動作 → **判定為機械故障，需派工**

### Step 6：緊急應急（被鎖在門外時優先）

| 方案 | 說明 |
|------|------|
| 🔑 備用鑰匙 | 門鎖底部蓋子內側的鑰匙孔 |
| 🔋 緊急供電 | 依型號使用 9V 電池或 Type-C 行動電源 |
| 🔧 緊急派工 | 上述方案都無效時安排 |

## 需派工的條件

- ❌ 推緊門板法無效且鎖栓無法動作
- ❌ 馬達無聲音且非電力問題
- ❌ 門扇嚴重反弓需專業調整
