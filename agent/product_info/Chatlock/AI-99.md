# Chatlock AI-99

## 產品概述

AI-99 為 Chatlock 高階觸控螢幕智慧電子鎖，配備圓形觸控螢幕、貓眼鏡頭（含內外鏡頭切換）以及 Wi-Fi 模組（Wi-Fi 模組整合在內側螢幕內）。支援 13 種解鎖方式：3D 人臉辨識、AI 掌靜脈辨識、半導體指紋辨識、IC 卡（含 NFC 手環/手錶）、密碼、APP 遠端、一次性密碼、限時密碼、機械鑰匙等。電池為內側螢幕後方可拆卸式鋰電池模組，可整顆取出充電；外側下方有 Type-C 緊急供電孔與機械鑰匙孔（同一圓形蓋體下）。

## 操作步驟

> AI-99 全部設定皆透過內側圓形觸控螢幕的選單操作。多數設定路徑為：螢幕 →【選單】→【系統設定】或【用戶管理】→ 對應子項。

### 喚醒螢幕與進入選單
1. 用手掌或手指輕觸內側圓形觸控螢幕。
2. 螢幕顯示主畫面（時間/日期/Wi-Fi/電量等）。
3. 點擊主畫面右側訊息圖示或進入【選單】可看到：【用戶管理】、【網路設定】、【系統設定】、【記錄查詢】。

### 新增用戶（前置步驟）
1. 主畫面 →【選單】→【用戶管理】。
2. 點擊【新增用戶】。
3. 選擇角色（爸爸／媽媽／爺爺／奶奶／外公／外婆／兒子／女兒／其他）。
4. 如需設為管理員，開啟【管理員用戶】開關。
5. 按【確認】→ 螢幕顯示「註冊成功」。
6. 回到【用戶管理】中點擊該用戶名稱進入辨識方式設定畫面。

### 新增密碼
1. 進入該用戶設定頁。
2. 點擊【密碼】右側的綠色【+】。
3. 輸入 6~12 位密碼後再次輸入確認。
4. 螢幕顯示「註冊成功」。

### 新增指紋
1. 進入該用戶設定頁。
2. 點擊【指紋】右側的綠色【+】。
3. 將同一根手指放在外側面板下方指紋辨識區，依語音提示重複感應約 5 次。
4. 螢幕顯示「註冊成功」。

### 新增門卡
1. 進入該用戶設定頁。
2. 點擊【門卡】右側的綠色【+】。
3. 將卡片貼於外側面板上方 NFC 感應區（卡片標示 chatlock 字樣的位置感應最佳）。
4. 偵測成功後螢幕顯示「註冊成功」。

### 新增人臉辨識
1. 進入該用戶設定頁。
2. 點擊【人臉】右側的綠色【+】。
3. 站在外側鏡頭正前方約 60 公分。
4. 等待掃描完成，螢幕顯示「註冊成功」。

### 新增掌靜脈
1. 進入該用戶設定頁。
2. 點擊【掌靜脈】右側的綠色【+】。
3. 將手掌置於外側鏡頭正前方 15~30 公分處。
4. 螢幕顯示「註冊成功」。

### 刪除驗證與用戶
1.【選單】→【用戶管理】→ 點擊欲刪除的用戶。
2. 該用戶下每一種已建立的辨識方式右側為紅色垃圾桶圖示。
3. 點紅色垃圾桶 → 跳出「確認刪除？」→ 按【確認】。
4. 必須先把該用戶 **所有辨識方式刪光**（全部變回綠色【+】），才可返回【用戶管理】刪除整個用戶。
5. 在【用戶管理】中點擊該用戶右側紅色垃圾桶 → 確認 → 用戶刪除完成。

### 語言設定
1.【選單】→【系統設定】→【功能設定】→【語言設定】。
2. 選擇日語／英語／繁體中文／繁體中文閩南語。

### 語音音量 / 門鈴音量
1.【選單】→【系統設定】→【功能設定】→【音量設定】。
2.【門鈴音量】或【語音音量】→ 選擇靜音／低／中／高。

### 常開模式
1.【選單】→【系統設定】→【高級設定】。
2. 點【常開模式】右側開關（綠色為開啟）。

### 兒童安全鎖
1.【選單】→【系統設定】→【高級設定】。
2. 點【兒童鎖】開關。

### 雙重認證模式
1.【選單】→【系統設定】→【高級設定】。
2. 點【雙重認證模式】開關（需先建立至少三種辨識方式才可開啟）。

### 防回頭機制（軟體更新後新增）
1.【選單】→【系統設定】→【功能設定】→ 滑到最下方【防回頭時間】。
2. 可選 5 秒／10 秒／15 秒，或關閉（關閉後仍會保留 2~3 秒上鎖等待時間）。
3. 集合式住宅或門前人流多時，建議調短或關閉，可避免「走到門前紅燈不亮」的情形。

### 未關門警報聲音切換
1.【選單】→【系統設定】→【高級設定】→ 滑到最下方【未關門警報聲音】。
2. 可開／可關。

### 內外鏡頭切換（APP 影片監控）
1. APP 主畫面 → 點【影片監控】。
2. 進入後預設顯示外鏡頭（前鏡頭）即時畫面。
3. 點底部【鏡頭切換】可切換為內鏡頭（後鏡頭）。

### 語音留言
1. 螢幕主畫面右側訊息圖示。
2. 進入留言介面 → 點【開始留言】→ 計時開始。
3. 完成後點【結束留言】→「操作成功」。
4. 試聽：點訊息列表 → 驗證管理員密碼 → 選擇留言 →【播放留言】。

### 臨時密碼（APP）
1. APP 主畫面 → 點【臨時密碼】→【新增臨時密碼】。
2. 第一位數字必須為 1，後續可手動輸入或選【隨機生成】。
3. 設定總長 7 位數字 → 設定生效時間／失效時間／密碼名稱（可選）。
4. 按【儲存】→ 顯示「密碼已複製」即完成。

### 遠端開鎖
- APP 主畫面綠色鎖頭按鈕【長按開鎖】→ 顯示「已成功」並在「相簿/紀錄」新增一筆開鎖紀錄。
- 也可在 APP 中點【影片監控】，先看畫面再決定是否開鎖。

### APP 配對（門鎖端）
1.【選單】→【網路設定】→【網路配對】→【開始配對】，門鎖顯示「連網中」。
2. 同步在 APP 右上角【+】→【添加設備】，APP 會搜尋到「chatlock AI99」。
3. 點【添加】→ 輸入家中 2.4G Wi-Fi 名稱與密碼 → 下一步。
4. 等待 → 門鎖顯示「配對成功」、APP 顯示「添加成功」。

### 邀請家庭成員
1. 邀請人 APP 主畫面 → 點左上家庭名稱（或左上指紋圖示）→【家庭管理】。
2. 點該家庭（如 Chatlock.JP）→【添加成員】→ 選擇邀請方式。
3. 輸入：成員名稱、國家/地區、被邀請人帳號（Email）、家庭角色（管理員／普通成員）→【保存】。
4. 被邀請人 APP →【家庭管理】→ 點【XX 家庭 待加入】→【接受邀請】。
5. 被邀請人切換到該家庭即可控制門鎖。

### 解除綁定（換主機/重綁定）
1. APP 主畫面點門鎖卡片進入裝置詳情。
2. 點右上角鉛筆（編輯）圖示。
3. 滑到頁面最底【移除裝置】。
4. 選【解除綁定】或【解綁並清除數據】（後者會清除歷史資料）→【確認】。

### 清理 APP 緩存
1. APP →【我】→ 右上角齒輪【設置】。
2. 滑到底部【清理緩存】，點擊後顯示「緩存清理成功」。

### 門鎖沒電時進門
1. 觀察外側面板下方圓形蓋（黃圈標示處）。
2. 大拇指向下壓蓋體，向右轉開蓋。
3. 蓋下露出兩個孔：左為 Type-C 充電孔、右為機械鑰匙孔。
4. 鑰匙開門：將備用專屬鑰匙插入右側孔，轉動開鎖（門鎖會嗶一聲）。
5. 行動電源喚醒：將 Type-C 線插入左側孔（任何行動電源即可），門鎖嗶一聲後即可使用指紋／密碼／人臉等已註冊辨識方式正常開門。

### 電池蓋拆裝（換電池／充電）
1. 雙手放在內側黑色螢幕兩側，將整片內螢幕往上推取下。
2. 露出下方電池槽，把長方形黑色鋰電池組整顆取出去充電。
3. 充飽後將電池組放回電池槽。
4. 把內螢幕對準上方卡準後蓋回，螢幕亮起顯示「chatlock」字樣即重啟完成。

### 恢復出廠設定
1.【選單】→【系統設定】→ 滑到下方【恢復出廠設定】。
2. 跳出「恢復預設設定？」→ 按【確認】。
3. 螢幕顯示「正在恢復出廠設置中 請稍後…」→「恢復出廠成功」。

> 恢復出廠後，原本設定的所有用戶／辨識方式／APP 綁定皆會清除，需要重新設定。建議由技師到場執行或客戶自行確認後再操作。

## 故障排除

### 鏡頭旁紅燈閃爍（正常現象，不是故障）
- 貓眼鏡頭兩旁紅燈**閃爍**代表鏡頭正在主動啟動人臉辨識或掌靜脈辨識，屬於**正常工作狀態**，不需排除故障。
- 客戶若反映「紅燈一直閃」其實是看到正常感應指示燈，請告知這是設備正在運作中、感應人臉/掌靜脈。
- 只有「紅燈完全不亮」才需要進入下方「紅燈未亮」段排查。

### 紅燈未亮、走到門前不感應（人臉/掌靜脈）
- AI-99 採用「防回頭機制」：每次上鎖完成後，紅外線感應器會在約 20 秒內進入冷卻期；該時段若有人/寵物經過，感應器啟動後判定失敗，又會再休眠 20 秒。
- 集合式住宅/透天前廳常因鄰居走動誤觸發冷卻：客戶到門前時剛好處於休眠期，紅燈不亮屬正常現象。
- 解法：摸一下螢幕讓紅外線重新啟動再感應；或進入【系統設定】→【功能設定】→【防回頭時間】，調短或關閉防回頭時間。

### 一關門就嗶嗶警報叫（關鎖失敗）
- 任何品牌的「關鎖失敗／關鎖未完全」警報都源自鎖栓在自動上鎖時撞到受口片或門框。
- 確認：開著門狀態下，按一下外把手後方（Buscle 後方）的【上鎖】圖示按鈕（按 0.5 秒放開），觀察鎖栓伸出與縮回是否順暢。
- 若開著門上下鎖正常但一關門就警報 → 是受口片偏斜或門框內有東西卡住，需調整受口片或檢查門框。
- 若開著門就會撞到 → 鎖體位置／門對齊問題，需技師調整。

### 突然感應辨識失靈／APP 顯示離線
- 多數情況是內側螢幕未插好導致 Wi-Fi 模組斷線（AI-99 / A90 / AI-88 系列的 Wi-Fi 模組都在內側螢幕內，拆下螢幕等於拔掉 Wi-Fi）。
- 把內側螢幕重新確認插入到底並完整蓋上，APP 應自動恢復連線。
- 若仍離線：APP →【設置】→【清理緩存】後重開 APP 試試；或檢查家中 2.4G Wi-Fi 是否正常。

### APP 控制無法解鎖
- 確認門鎖在 APP 顯示「在線」。
- 用手機螢幕點【長按開鎖】（必須長按超過 1 秒），畫面提示「已成功」即完成。
- 若顯示連線失敗，請執行【清理緩存】或重啟 APP；嚴重時可【解除綁定】後重新配對。

### 雙重認證模式誤觸（突然要兩種辨識才開）
- 在【系統設定】→【高級設定】→【雙重認證模式】將開關關閉即可恢復單一辨識開門。

### 派工條件
- ❌ 已換電池（含整顆鋰電池組充飽）後仍持續低電量警報或無反應 → 派工檢查 IC 板。
- ❌ 鎖栓動作開著門就異常（伸不出、縮不回、卡頓）→ 派工。
- ❌ 受口片需調整、門框需重對 → 派工。
- ❌ 行動電源從 Type-C 緊急供電孔仍無反應 → 派工。
- ❌ APP 重新配對失敗、解除綁定後仍無法搜尋到設備 → 派工檢查模組。
- ❌ 客戶遺失管理員辨識方式（密碼／指紋／卡片／人臉／掌靜脈全失效）需執行恢復出廠設定 → 派工協助。
- ❌ 內側螢幕損壞或無法插入到底 → 派工更換。
