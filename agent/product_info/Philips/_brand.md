# Philips 品牌通用資訊

> 此文件收錄 Philips 智慧電子鎖品牌的通用處理原則。當客戶**已知品牌為 Philips 但型號未確認**時，可作為主要參考。

## 品牌國別

Philips（飛利浦）為**荷蘭**品牌；電子鎖實際生產與授權多在亞洲區。

## ⚠️ 資料狀態（必讀）

目前 bronze 來源中**尚無任何 Philips 型號的官方影片字幕、文字資料或操作教學**（涵蓋型號：702E / 7300 / 9200 / 9300 / Alpha）。本品牌目前**沒有可信任的型號專屬按鍵步驟**。

**處理原則**：
- 客戶詢問 Philips 任何型號的具體操作（密碼設定、卡片新增、APP 配對、人臉註冊等）→ 客服必須坦誠告知「這部分這邊取不到 Philips 詳細按鍵步驟，建議您查看隨附說明書，或我這邊幫您安排專員協助」。
- **絕對禁止**編造任何 Philips 按鍵 SOP 或操作流程。
- 若客戶提供型號後仍是上述列表的型號，則 `Philips/{Model}` 文件內容也是相同的資料缺乏聲明，不會多出按鍵步驟。

## 通用故障處理（不依賴品牌資料）

以下流程適用所有電子鎖品牌（包含 Philips），可直接參考 `_common/troubleshoot`：

- **門打不開**：判斷開門方向（拉門 → 推緊門框、推門 → 拉緊把手）→ 緊急方案實體鑰匙。
- **關門沒上鎖**：確認關到位、把手未在手動模式。
- **警報聲響不停**：通用排查（近期是否換電池？多次錯誤密碼觸發防盜鎖定？）。
- **指紋／密碼／卡片感應失敗**：手指擦乾、長輩指紋多角度登錄、卡片頻率 13.56MHz、感應位置在識別區正中央。
- **電池快沒電**：依說明書規格更換電池（Panasonic 鹼性建議優先）。

## 派工建議

當 Philips 客戶遇到以下情境，**直接安排派工或轉真人**，不要嘗試遠端 SOP 指導：

- 任何需要型號專屬按鍵步驟的設定 / 操作（密碼、卡片、指紋、人臉、APP）。
- 警報持續無法解除。
- 鎖體機械損傷、鎖位移、馬達異常。
- 客戶遺失管理員驗證方式需要恢復出廠。

> 派工流程請參考 `_common/dispatch`。
