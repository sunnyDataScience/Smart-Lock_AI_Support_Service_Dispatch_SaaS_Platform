# 3E F(T7)

## 產品概述

3E 小島快鎖 F(T7)（年度銷售冠軍）是 3E 主力推拉式智慧電子鎖，提供 **直立式** 與 **橫式** 兩種安裝方向以對應不同門板配置。具 IP55 防水、防紫外線外殼、高品質鋁合金面板、APP 門鈴貓眼，整合 NFC，支援 200 組指紋。電源使用 4 顆 3 號鹼性電池（AA），底部隱藏式蓋體下有 Type-C 緊急供電孔與機械鑰匙孔。

> 客戶使用前請先確認自家機器為「直式（直立）」或「橫式」安裝方向，兩者拆裝方式不同（詳見「相關影片」內的橫式 / 直式安裝教學）。

## 操作步驟

### 出廠首次設定（更改預設管理員密碼）
> 安裝完成後 **必須先更改管理者密碼**。第一組管理者密碼無法更動或刪除，僅能初始化（出廠重置），重置後機器需要全部重新設定。

1. 在面板輸入【1】、【#】 → 輸入預設密碼【123456】、【#】。
2. 語音「請驗證管理員」 → 再輸入【123456】、【#】 → 語音「操作成功」。
3. 語音「按 1 用戶設置；按 2 系統設置」 → 按【1】。
4. 語音「按 1 添加管理員；按 2 添加普通用戶」 → 按【1】。
5. 語音「請輸入編號 1 到 5，或者按【#】自動生成」 → 按【#】 → 語音播報自動編號（如 001）。
6. 語音「按 1 添加指紋；按 2 添加卡片；按 3 添加密碼」 → 按【3】。
7. 語音「請輸入新密碼」 → 輸入新密碼 + 按【#】 → 「請再次輸入」 → 再輸入相同密碼 + 按【#】 → 「操作成功」。

> 管理員順位 1~5；普通用戶從順位 6 開始或按【#】自動生成。

### 新增管理員 / 普通用戶指紋
1. 面板輸入【1】、【#】 → 輸入已修改的管理者密碼 + 按【#】 → 「操作成功」。
2. 「按 1 用戶設置」 → 按【1】。
3. 「按 1 添加管理員；按 2 添加普通用戶」 → 按【1】或【2】。
4. 輸入編號（管理員 1~5；普通用戶從 6 起）或按【#】自動生成。
5. 「按 1 添加指紋」 → 按【1】 → 「請放手指」。
6. 將同一根手指放在指紋辨識區，依語音「請移開，再放一次」重複動作（約 4~5 次） → 「操作成功」。

### 新增管理員 / 普通用戶卡片
1. 進入用戶設置（同上 1~3 步驟）。
2. 設定編號（自動或手動） → 「按 2 添加卡片」 → 按【2】。
3. 「請刷卡」 → 將卡片靠近數字面板中央 → 「操作成功」。

### 新增管理員 / 普通用戶密碼
1. 進入用戶設置（同上 1~3 步驟）。
2. 設定編號 → 「按 3 添加密碼」 → 按【3】。
3. 輸入新密碼 + 按【#】 → 再次輸入相同密碼 + 按【#】 → 「操作成功」。

### APP 綁定網路設定
1. 從各大商店下載 3E 對應 APP（IOS App Store / Google Play）。
2. **手機必須先連結家中 2.4G Wi-Fi**。
3. 喚醒門鎖面板，輸入【8】、【#】 → 「請驗證管理員」。
4. 用管理員密碼 + 【#】或管理員指紋驗證 → 「操作成功」。
5. 在 APP 點右上角【+】 → 【新增裝置】。
6. 輸入 Wi-Fi 名稱（自動帶入）與 Wi-Fi 密碼 → 點【下一步】（密碼錯誤會無法連線）。
7. APP 找到裝置（如 3E-XXXXXX） → 「等待連線中」。
8. 門鎖語音「操作成功」 + 底部亮綠燈 → 點 APP【完成】 → 「正在連網更新」。

### 解鎖方式
- **指紋解鎖**：將手指放在門鎖上方指紋辨識區 → 綠燈 → 語音「開鎖」 → 「叮咚 開」。
- **密碼解鎖**：觸碰螢幕喚醒 → 輸入密碼後門鎖底部亮綠燈 → 「開鎖」。
- **卡片解鎖**：將卡片貼近門鎖中央「CARD」感應區 → 綠燈 → 「開鎖」。
- **鑰匙解鎖**：打開外側下方圓形隱藏蓋 → 將鑰匙插入鑰匙孔轉到底 → 「開鎖」。
- **APP 遠端解鎖**：APP 主畫面點綠色鎖頭 → 「正在請求遠程開鎖」 → APP 切換到貓眼即時畫面 → 確認後點下方解鎖按鈕 → 顯示「開門成功」 → 門鎖「開鎖」。
- **室內按鈕解鎖**：按下室內側按鈕（按壓 0.5~1 秒，避免幼童寵物誤觸；連續短按或長按不放皆不會開）。
- **室內旋鈕解鎖**：轉動室內側旋鈕，鎖舌縮回。

### 鑰匙開門（沒電 / 緊急）
1. 用手推開門鎖底部的隱藏式蓋板，露出鑰匙孔。
2. 將實體鑰匙插入鑰匙孔並轉動到底 → 「開鎖」。
3. 再次反向轉到底 → 「關鎖」。
4. 取出鑰匙、蓋回蓋板。

### 行動電源緊急供電
1. 將底部圓形蓋打開（同鑰匙開門步驟），露出 Type-C 緊急供電孔。
2. 將 Type-C 充電線插入孔內。
3. 螢幕亮起，語音「正在更新本地時間」 → 「操作成功」。
4. 用已註冊的卡片／指紋／密碼正常解鎖（語音「開鎖」）。
5. 進到室內後務必更換電池。

### 更換電池（必看）
> **必須使用四顆全新 3 號鹼性電池（AA）！** 不可混用新舊電池或非鹼性電池。

1. 推開電池蓋。
2. 取出電池盒。
3. 取出舊電池。
4. 將四顆全新 AA 鹼性電池放入電池盒（注意正負極方向）。
5. 將電池盒插回門鎖。
6. 蓋上電池蓋 → 語音「操作成功」。

### 系統設置
- 系統設置進入方式為按【2】（用戶設置為按【1】），詳細子項目以實機語音播報為準。

### 安裝注意（橫式 / 直式皆通用）
- **配件清單**：說明書、保護貼、室外機、膠墊、室內機（底板）、受口盒墊片、受口盒、木紋螺絲（木門用）、3.5 mm 鑽尾與螺絲（金屬門用）、4 顆電池、鑰匙 ×2、卡片 ×3、PH2 直徑 5 mm 十字起子、長／短主軸螺絲。
- **主軸螺絲長度規則**：門厚 3.5 公分以內用短螺絲；門厚超過 3.5 公分使用長螺絲，長度需 = **門厚 − 1.5 公分**，多餘部分需裁切。
- **鎖芯預留 2 公分**：鎖芯主軸務必預留 2 公分，多的用砂輪機裁切並打磨平滑。
- **訊號線收納**：訊號線先不要全部塞進去，預留可塞入空間，避免鎖到線。
- **室外機防撬開關**：紅色防撬開關必須貼合門板平面，否則會誤觸防撬警報。
- **受口盒對位**：機器上的三角形感應器必須壓入受口盒至少一半，才能觸發自動上鎖；過鬆需加墊片，特殊規格門框需另購配件。
- **特殊規格受口盒**：可詢問廠商訂製其他樣式的受口配件。

> 詳細安裝步驟請參考相關影片。直式與橫式在「線材繞行方向」「室內機安裝順序」上有差異。

## 故障排除

### 通用症狀分流
3E 在 bronze 資料中**沒有專屬的故障排除文字稿**，請同時參考 `_common/troubleshoot` 進行通用症狀分流（鎖舌卡住／受口片偏斜／電池異常／APP 無法配對等）。下述為 F(T7) 已知特定狀況。

### 一關門就警報（關鎖失敗）
- 警報源自鎖栓在自動上鎖時撞到受口片或門框。
- 確認：開著門狀態下，按一下室內按鈕讓鎖栓伸縮，觀察是否順暢。
- 若開著門上下鎖正常但一關門警報 → 受口盒未對齊或感應器壓入深度不足，需要重新調整受口盒位置或加墊片。
- 受口盒設計需要「機器上三角形感應器壓入受口盒至少一半」才能觸發上鎖，過鬆會誤判失敗。

### 防撬警報誤響
- 室外機紅色防撬開關必須貼合門板平面才不會觸發。
- 若安裝面有縫隙或膠墊未壓緊 → 會持續誤觸發，需重新安裝室外機。

### 室內按鈕無法解鎖
- 室內按鈕設計為「按壓 0.5~1 秒」才會作動，避免寵物 / 幼童誤觸。
- 連續短按或長按不放皆不會開鎖，請以中等時長單次按壓。
- 若仍無法開鎖，改用室內手動旋鈕。

### 換電池後仍立刻沒電 / 反覆警報
- 確認是否使用四顆 **全新** 3 號鹼性電池（AA），不可混用舊電池或非鹼性電池。
- 若已換正確電池仍復發 → 派工檢查 IC 板。

### APP 找不到裝置
- 確認手機已連到家中 2.4G Wi-Fi（不是 5G）。
- 重新進入面板輸入【8】、【#】 → 管理員驗證後再次配對。
- 若配對途中失敗，先在 APP 中解除綁定後再重綁。

### 派工條件
- ❌ 已換 4 顆全新 AA 鹼性電池後仍持續低電量警報或無反應 → 派工檢查 IC 板。
- ❌ 鎖栓開著門狀態就異常（伸不出、縮不回、卡頓）→ 派工。
- ❌ 受口盒位置／感應器深度需調整、特殊規格需另購配件安裝 → 派工。
- ❌ 防撬警報持續誤響、室外機需重新安裝 → 派工。
- ❌ 行動電源從 Type-C 緊急供電孔仍無反應 → 派工。
- ❌ APP 重新配對失敗、解除綁定後仍搜尋不到設備 → 派工檢查模組。
- ❌ 客戶遺失管理員密碼且無已註冊管理員指紋／卡片可用 → 派工協助執行恢復出廠設定（重置後機器需全部重設）。
- ❌ 主軸需重新裁切、線材需重接 → 派工。
