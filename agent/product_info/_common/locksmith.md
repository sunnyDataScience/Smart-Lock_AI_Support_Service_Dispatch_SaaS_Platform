# 開鎖服務

## 服務範圍

### 開鎖
- **類型**：專利鎖、非專利鎖、電子鎖、喇叭鎖、鐵櫃鎖、折疊鑰匙鎖、鋁窗鎖、汽車晶片鎖。
- **特徵**：
    - 鑰匙遺失、鎖芯損壞、無法轉動、門鎖卡住、關門自鎖、把手掉落、鎖舌被鎖住、電子鎖故障。
    - 鐵門、房門、大門、櫥櫃、推拉門。
- **流程要點**：
    1. 客戶提供鎖具照片/影片，說明狀況（是否上鎖、是否有鎖段、鎖具類型、門扇類型）。
    2. 評估是否可開鎖，若可開鎖則報價。
    3. 若無法開鎖，可能需破壞鎖具，並建議更換新鎖。
    4. 若為電子鎖故障，可能需先破壞再更換。
    5. 若為特殊鎖具（如折疊鑰匙、鋁窗鎖、建商特規鎖），可能需叫料或評估替代方案。
- **限制**：
    - 無法複製原廠特殊鑰匙（如東隆原廠鑰匙）。
    - 部分電子鎖型號無法開鎖，只能破壞。
    - 特殊規格鎖具（如鋁窗鎖、建商特規電子鎖）替換選擇有限，可能無法完全遮蔽原有孔洞。
    - 電子鎖破壞後門會關不起來，需更換新鎖。

### 換鎖 / 裝鎖 / 修鎖
- **類型**：傳統鎖、電子鎖（包含電子把手、輔助鎖）、喇叭鎖、鋁窗鎖。
- **特徵**：
    - 鎖具損壞、防盜性需求、內部開鎖便利性需求。
    - 新裝修、舊鎖升級。
- **流程要點**：
    1. 客戶提供門鎖照片、門扇厚度、鎖閘尺寸、鎖體尺寸、鎖芯距離等詳細資訊。
    2. 評估門扇限制（如門扇厚度、門框寬度、門與牆面間距、原有孔洞大小）。
    3. 推薦適合的鎖具類型（傳統鎖、電子把手、輔助鎖、電子鎖）。
    4. 說明不同鎖具的特性、開鎖難易度、防盜性。
    5. 若為電子鎖，需確認是否有特殊功能需求（指紋、密碼、卡片、藍牙、遠端、人臉辨識、掌靜脈）。
    6. 若為電子鎖，需確認是否需要遮飾板（依原有孔洞大小決定）。
    7. 安排安裝時間，並告知預計工時。
- **限制**：
    - 部分門扇（如鋁窗、窄框門）限制多，只能更換相同類型或少數替代品。
    - 電子鎖安裝可能需要擴孔，但會確保原有把手可遮蔽施工痕跡。
    - 特殊規格鎖具（如鋁窗鎖）可能需叫貨，製作時間較長。
    - 電子鎖安裝需考量門扇厚度、門與牆面間距，避免影響功能或外觀。

### 鑰匙複製
- **類型**：一般鑰匙、折疊鑰匙、汽車晶片鑰匙、磁扣/磁卡。
- **特徵**：
    - 鑰匙損壞、遺失、備用需求。
    - 磁扣/磁卡拷貝至手機貼或電子鎖。
- **流程要點**：
    1. 客戶提供鑰匙照片或實物。
    2. 評估是否可複製，若為特殊鑰匙（如原廠鑰匙）可能無法複製。
    3. 若為折疊鑰匙，可能需更換整個外殼。
    4. 若為晶片鑰匙，需確認晶片是否可移植。
    5. 若為磁扣/磁卡，需確認規格（IC規格）及社區門禁系統是否支援拷貝。
    6. 告知製作時間。
- **限制**：
    - 部分原廠鑰匙（如東隆原廠鑰匙）無法複製，因握把形狀特殊。
    - 磁扣/磁卡拷貝需確認規格，非IC規格可能不適用。
    - 磁扣/磁卡拷貝至手機貼可能需調整感應角度。
    - 晶片移植損壞機率不高，但仍有風險。

## 作業流程

### 開鎖 / 換鎖 / 裝鎖 / 修鎖
1. **客戶諮詢**：客戶透過Line提供鎖具照片/影片、說明狀況、地址、聯絡電話。
2. **初步評估與報價**：客服根據客戶提供資訊進行初步判斷，告知是否可處理、預估費用範圍。
3. **預約時間**：與客戶確認師傅到場時間。
4. **師傅到場**：師傅前往現場，再次評估實際狀況，確認最終報價。
5. **施工**：進行開鎖、換鎖、裝鎖或修鎖作業。
6. **驗收與付款**：客戶確認服務完成，現場付款。

### 鑰匙複製
1. **客戶諮詢**：客戶提供鑰匙照片或實物，說明需求。
2. **評估與報價**：客服評估是否可複製，告知製作時間。
3. **預約取件**：與客戶確認取件時間。
4. **製作**：進行鑰匙複製。
5. **取件與付款**：客戶到店取件，現場付款。

## 時程

### 開鎖 / 換鎖 / 裝鎖 / 修鎖
- **到場時間**：
    - 一般情況：約30-60分鐘內可到場（若師傅在林口地區）。
    - 特殊情況：師傅外出裝鎖或處理其他案件時，到場時間可能延後至下午或傍晚，或需隔日處理。
- **施工時間**：
    - 開鎖：依鎖具複雜度而定。
    - 換鎖/裝鎖：約30分鐘內。
    - 電子鎖安裝：約30分鐘。

### 鑰匙複製
- **一般鑰匙**：約15分鐘內。
- **折疊鑰匙**：約15分鐘內（若有鎖胚）。
- **汽車晶片鑰匙**：約15分鐘內（若有鎖胚）。
- **磁扣/磁卡**：現場拷貝。

## 派工 / 到店 / 自取判斷

- **派工觸發**：
    - 任何開鎖、換鎖、裝鎖、修鎖服務。
    - 汽車晶片鑰匙複製（若客戶無法到店）。
    - 鑰匙斷在鎖孔內需取出。
    - 電子鎖故障需檢測或破壞。
    - 客戶明確要求師傅到府服務。
- **到店觸發**：
    - 鑰匙複製（一般鑰匙、折疊鑰匙、汽車晶片鑰匙）。
    - 磁扣/磁卡拷貝。
    - 購買電子鎖（可到店看實體）。
    - 門鎖維修諮詢（可帶鎖具到店）。
    - 客戶自願到店。
- **自取觸發**：
    - 鑰匙複製完成後。
    - 師傅外出無法即時回店時，可將完成品放置門口信箱供客戶自取。

## 不接受的服務
- 無法複製原廠特殊鑰匙（如東隆原廠鑰匙）。
- 無法提供電子鎖雙向通話功能。
- 無法提供生辰八字鑒定等開運印章服務。
- 無法保證急件印章製作時程。
- 無法提供電子鎖圖片回覆。

## 常見誤解 / 客戶常忽略的細節
- **營業時間**：客戶常誤以為店面有固定營業時間，但因鎖匠工作性質，師傅會隨時外出開鎖或裝鎖，建議客戶來店前先Line確認是否有人在店。
- **電子鎖安裝**：
    - 客戶常以為電子鎖安裝不需擴孔，但部分情況下需要擴孔才能安裝。
    - 客戶常以為電子鎖可以完全遮蔽原有孔洞，但建商特規鎖或孔洞過大時，可能需加裝遮飾板。
    - 客戶常忽略門扇厚度、門與牆面間距等因素對電子鎖安裝的影響。
    - 電子鎖的貓眼/人臉辨識鏡頭方向固定，無法調整，廣角偵測範圍需注意。
    - 電子鎖臨時密碼設定需注意生效時間，避免設定到未來時間。
- **鑰匙複製**：客戶常以為所有鑰匙都能複製，但部分原廠特殊鑰匙無法複製。
- **磁扣/磁卡拷貝**：客戶常以為所有磁扣/磁卡都能拷貝，但需確認是否為IC規格。
- **開鎖報價**：客戶常期望電話中能給出精確報價，但實際費用需依現場鎖具種類、狀況、鎖段數而定。
- **印章製作**：
    - 客戶常誤以為橡皮章/連續章可當天取件，但製作時間通常為2個工作天。
    - 客戶常忽略印章尺寸、字體、墨水顏色等細節，導致重製。
    - 公司大小章字數過多時，可能需調整尺寸或字體，並可能產生額外費用。
    - 發票章內容需客戶自行與承辦單位確認，店家無法協助決定。
- **服務時間**：客戶常忽略師傅可能因其他案件延遲到場，建議客戶預留彈性時間。
- **付款方式**：電子鎖安裝僅接受轉帳或現金，不支援信用卡。
