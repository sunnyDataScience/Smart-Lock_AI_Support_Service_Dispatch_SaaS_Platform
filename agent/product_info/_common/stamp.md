# 印章服務

## 服務範圍

### 個人印鑑章
- **用途**：銀行開戶、印鑑證明。
- **尺寸**：常見為五分 (1.5x1.5公分) 或六分 (1.8x1.8公分)。
- **特徵**：可選材質、字體、形狀（方/圓）。圓章多用於畫作或風水考量（錢財滾滾），方章則有守財、鎮財之意。
- **限制**：台灣對於個人用印證明的大小無硬性規定。

### 公司大小章
- **用途**：公司登記、銀行業務、合約用印。
- **尺寸**：
    - 小章：常見為四分 (1.2x1.2公分) 或五分 (1.5x1.5公分)。
    - 大章：常見為七分 (2.1x2.1公分) 至一吋 (3x3公分)。
    - 建議：
        - 8個字以下建議七分。
        - 10個字以內建議八分。
        - 10個字以上建議九分起。
- **特徵**：通常為方形。
- **限制**：字數過多可能需要更大尺寸或特殊排版。

### 肚臍胎毛章
- **用途**：紀念、開戶用印。
- **特徵**：可將寶寶的肚臍或胎毛封入印章中。
- **限制**：
    - 胎毛量可能不足以製作胎毛筆，但肚臍章通常可行。
    - 非洲黑檀（消光材質）不適用，因灌膠過程難以清理，會導致印章受損。

### 橡皮章 / 連續章
- **用途**：發票章、收發章、集點卡章、姓名章、職章、活動章等。
- **特徵**：
    - 橡皮章：需搭配印台使用。
    - 連續章：本身含墨水，不需印台。
    - 皆可客製化內容、尺寸、墨水顏色、是否加框。
- **限制**：
    - 無法當日完成，需至少1個工作天。
    - 越小的字體筆畫越多，清晰度風險越高。
    - 連續章蓋印力道會影響清晰度，太大力可能糊在一起。
    - 特殊排版（如掃圖製作）可做到與原圖一模一樣。

### 騎縫章
- **用途**：文件防偽。
- **特徵**：通常為長條形，內容可分排。
- **尺寸**：可依需求客製，常見寬度約1-1.5公分。
- **限制**：字數過多可能需要較大尺寸。

## 規格與選項

### 尺寸
- **個人章**：
    - 四分 (1.2x1.2公分)
    - 五分 (1.5x1.5公分)
    - 六分 (1.8x1.8公分)
- **公司章**：
    - 七分 (2.1x2.1公分)
    - 八分 (2.4x2.4公分)
    - 九分 (2.7x2.7公分)
    - 一吋 (3x3公分)
- **橡皮章/連續章**：
    - 姓名章：常見 0.5x1公分 或 0.6x1.2公分。
    - 發票章：尺寸固定。
    - 職章：常見 0.7x2.7公分 或 1x3公分。
    - 其他客製章：可依客戶需求提供長寬尺寸評估。

### 材質
| 等級 | 材質 | 特性 | 製作時間 | 備註 |
|---|---|---|---|---|
| 基本 | 木頭便章 | 最經濟實惠 | 5分鐘 | 通常為4分小章 |
| 一般 | 黃楊木 | 簡單快速，常見 | 1-2工作天 | 可選素面或雷雕（吉祥話） |
| 中階 | 黑牛角 | 天然材質，質感極簡，耐髒 | 1-2工作天 | 附贈皮套 |
| 中高 | 紫檀木 | 天然材質，高級傢俱紅木，沉穩素雅 | 1-2工作天 | 附贈皮套 |
| 高級 | 赤牛角 | 高級印鑑首選，最具獨特性 | 1-2工作天 | 附贈皮套 |
| 特殊 | 水晶、玉石 | 最高等級，獨特 | 10工作天內 | 肚臍章可選紅琥珀、琥珀生肖等 |

### 字體
- **常見字體**：
    - S1 開運印相體 (連邊印相體)：吉祥印概念，熱門，未滿(具體費用請洽真人客服)加收排版費。
    - S2 印篆
    - S3 正楷
    - S4 隸書 (AL5)
    - S5 行書
    - S6 圓體
    - S7 篆體 (小篆、大篆)
    - S8 (目前無此字體)
- **排版**：
    - 一般印鑑章無預覽服務，依經驗調整。
    - 英文內容可預覽3次，超過加收費用。
    - 多字數印章（如中英文並存）通常中文在上、英文在下。
    - 圓形印章不適合多字數內容，邊角文字可能不完整。
- **限制**：
    - 越小的印章選擇筆畫過多的字體，清晰度風險越高。
    - 電腦預覽與實際刻印效果可能存在差異。

### 墨水顏色 (連續章)
- 紅色
- 藍色
- 黑色
- 紫色 (較少人使用，可能斷貨)
- 綠色 (較少人使用，可能斷貨)

### 印章外殼 / 配件
- **印章套**：黑牛角等級以上材質附贈皮套。
- **印章蓋**：黃楊木等一般材質附贈蓋子。附贈皮套的印章通常不附蓋子，因蓋子會加大尺寸，不易放入套中。
- **印章盒**：現場有販售，可一併選購。

## 作業流程

1. **客戶詢問**：客戶透過LINE提出印章製作需求。
2. **提供資訊**：客戶需提供印章類型、內容、尺寸、材質、字體、墨水顏色（連續章）、是否加框等詳細資訊。
3. **報價與確認**：客服根據客戶需求提供報價，並確認訂單內容。
4. **下單製作**：客戶確認訂單後，客服進行下單。
5. **付款**：可選擇現金、Line Pay、銀行轉帳，或取貨時付款。
6. **製作**：依印章類型與材質進行製作。
7. **通知取貨**：印章完成後，客服會通知客戶取貨。
8. **交付**：客戶至店面取貨，或依約定方式（如郵筒自取）。
9. **收據/發票**：可提供收據，若需統編請事先告知。

## 時程

- **木頭便章**：5分鐘。
- **一般材質印鑑章** (黃楊木、黑牛角、紫檀木、赤牛角)：1-2個工作天。
- **橡皮章 / 連續章**：
    - 每日下午4:30 (或5:00) 前下單，隔日可取貨。
    - 超過截稿時間則為次日下單，再隔日取貨。
    - 週五下單，週一取貨。
    - 週六日下單，下週二或週三取貨。
    - 無法當日完成，不接急件。
- **特殊材質** (玉、石頭、水晶、肚臍章)：10個工作天內 (肚臍章約15-28天)。
- **公司大小章** (黃楊木)：最快30分鐘。
- **特殊排版/掃圖製作**：可能需額外時間。

## 派工 / 到店 / 自取判斷

- **到店取貨**：
    - 客服會通知印章完成，客戶可依營業時間到店取貨。
    - 若客服外出，會告知預計回店時間。
- **郵筒自取**：
    - 若客戶無法配合營業時間，或客服外出，可將印章放置於店門口紅色郵筒內。
    - 郵筒內會標示客戶姓名或手機後三碼。
    - 未付款客戶可將現金投入郵筒內，或使用Line Pay/轉帳。
- **派工**：
    - 僅限特殊情況，如客戶有急件且距離近，或店家因故無法在店內。
    - 需事先約定時間與地點。

## 不接受的服務

- **印鑑章排版預覽**：一般印鑑章不提供排版預覽服務，除非客戶有特殊要求並支付額外費用。
- **仿章**：不提供製作與原印章一模一樣的仿章服務，除非是掃描製作的橡皮章或連續章。
- **肚臍章使用非洲黑檀**：非洲黑檀為消光材質，不適用於肚臍章的灌膠製作。
- **印鑑章使用印泥**：橡皮章或連續章不可使用印泥，否則會損壞印章。

## 常見誤解 / 客戶常忽略的細節

- **印章尺寸**：客戶常誤以為印章外殼尺寸即為印面尺寸，需提醒客戶以「印面」大小為準，並可提供尺規示意圖。
- **印章用途與材質**：客戶常認為印章有分「小孩章」或「大人章」，實際上印章選擇主要依預算、材質、風水信仰及個人喜好。
- **印章保存**：天然材質印章需注意保存方式，避免潮濕、冷氣直吹、手汗接觸，並應收納於印盒中，蓋印後清潔印面，以延長使用壽命。
- **字體選擇與清晰度**：客戶常忽略印章尺寸與字體筆畫數的關係，印章越小、字體筆畫越多，清晰度風險越高，可能導致文字模糊。
- **公司章名稱**：公司名稱（如「企業社」、「有限公司」）需依政府核定資訊提供，店家無法提供建議，以免影響稅籍或公司登記。
- **發票章內容**：發票章內容需依政府單位規範，客戶應自行與承辦單位確認所需資訊，店家僅照客戶提供內容製作。
- **取貨資訊**：客戶常忘記提供聯絡人姓名與手機號碼，或請他人代領時未告知印章內容，導致取貨困難。需強調取貨時需報上「下單人姓氏+手機後三碼」或「公司名+統編後三碼」。
- **連續章/橡皮章製作時程**：客戶常誤以為連續章/橡皮章可當日完成，需明確告知需至少1個工作天。
- **印章排版**：客戶常要求預覽排版或不斷修改，需告知印鑑章通常無預覽服務，且過度修改可能產生額外費用。
- **印章瑕疵**：天然材質印章可能存在天然紋路或輕微瑕疵，若客戶介意可協助更換。
