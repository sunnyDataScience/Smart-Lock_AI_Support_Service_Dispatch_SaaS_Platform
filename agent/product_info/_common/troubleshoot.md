# 通用故障排除路由

> 此文件為跨品牌通用排查流程。具體型號的按鍵步驟請參考 `{brand}/{model}` 文件；本文件僅在型號未知或先做通用排查時使用。

## 第一步：確認狀況（客服問診核心）

遇到客戶反映故障，依以下順序確認：

1. **品牌** — 「請問您的電子鎖是什麼品牌？」
2. **型號** — 「型號是什麼？不確定可以描述外觀」
3. **若型號問不到** — 「您的鎖是握住把手往下壓開門（把手款），還是直接推或拉把手就可以開門（推拉款）？」
4. 確認款式後再依品牌特性循線排查

## 第二步：症狀分流

### A. 門打不開（門外被鎖在外）

判斷開門方向（人站在門外）：
- **拉門開門**（門向外開）：先**推緊**門框，讓鎖舌與受口片之間有縫隙 → 解鎖 → 拉開
- **推門開門**（門向內開）：先**拉緊**把手讓門貼合門框 → 解鎖 → 推開

原理：消除鎖舌與受口片之間的摩擦力。

如果推/拉緊後仍打不開：
- 檢查門扇四周是否卡到隔音條、氣密條、地墊
- 鎖體外觀是否仍直立（歪斜代表鎖位移，需技師處理）
- 緊急方案：實體鑰匙（鎖體底部蓋子內）

### B. 關門沒上鎖（自動上鎖失效）

兩種可能：
1. **沒關到位**：鎖匣未對準受口片 → 推緊門再試
2. **誤觸手動模式**：把手轉到手動上鎖模式 → 把手轉回自動模式

半自動鎖匣特徵：關門後 3-5 秒，把手會「空轉」並有馬達聲，這是正常上鎖；不是故障。

### C. 警報聲響不停 / 一直嗶嗶叫

各品牌警報含義不同，禁止憑燈號顏色或聲響次數臆測。**先載入該品牌的警報排除技能**（如 Dormakaba 直接看 `Dormakaba/{model}` 故障排除段）。

通用排查：
- 是否近期換過電池？電池品牌是否為 Panasonic 鹼性電池？
- 是否有人嘗試錯誤密碼／指紋多次（防盜鎖定）？
- 確認門是否關緊

### D. 指紋、密碼、卡片感應失敗

通用建議：
- 手指擦乾再試
- 長輩指紋較淺：**同一根手指用不同角度（指尖／指腹／側邊）多登錄幾次**，或登錄紋路較清楚的不同手指
- 多次失敗會觸發防盜鎖定，需等待解除（通常 3 分鐘）
- 卡片：確認頻率（13.56MHz）、感應位置（識別區正中央）

### E. 電池快沒電 / 異常耗電

**第一件事先檢查電池品牌**：
- ✅ Panasonic 鹼性電池（金紅／金藍包裝）或太元素電池
- ❌ 金鼎、其他品牌（容易漏液、電壓不穩）
- ❌ 碳鋅電池（電壓不穩）

8 顆鹼性電池正常續航約 6 個月至 1 年。一個月內又叫換電池 = 異常耗電。

異常耗電排查：
1. 電池確認 Panasonic 鹼性
2. 換一組新電池排除單顆品質問題
3. 若有 Wi-Fi 模組 → 確認家用路由器 2.4G 與 5G 已分開設定（合併會異常耗電）
4. Wi-Fi 6/7/8 路由器與電子鎖協定不相容 → 改用入門級僅 2.4G 路由器
5. 仍異常 → 派工檢查 IC 板耗電

緊急供電：
- 電池外露型：9V 方型電池貼觸供電
- 鋰電池型（Chainlock AI99/A90）：底部蓋向下按壓並向右轉 → Type-C 接行動電源（5V1A 或 5V2A，禁快充）

### F. 網路斷線 / APP 離線

- 確認家用 Wi-Fi 為 **2.4 GHz**（5G 大多不支援）
- 路由器 2.4G 與 5G 必須分開設定（合併會 IoT 設備連線不穩 + 異常耗電）
- 若是 Wi-Fi 6/7/8 路由器，協定可能不相容 → 進路由器後台改 802.11 規格，或改用僅 2.4G 入門路由器
- **Mesh 路由器**（網狀網路）：可能造成電子鎖視訊開門卡頓、APP 連線不穩、配對失敗等問題；**建議使用獨立的 2.4GHz 入門級路由器或 IoT Network 專供電子鎖**，避免讓電子鎖跟隨 mesh 節點切換

### G. 門扇反弓（門會自己彈開、關不緊、卡很緊）

定義：解鎖或沒裝鎖時門扇自動往外或往內移動，像自動門。
原因：門扇鉸鍊區擠壓到門檻或門框 → 公差變大 → 鎖舌與受口片摩擦異常。

客戶反應通常是「門縫很大」「開門卡很緊」「關門關不上」。

排除：**派工調整門扇或鉸鍊**。客服無法電話排除，需技師到場。

## 第三步：派工 vs 電話可解決

### 電話可解決
- 推緊／拉緊門解鎖
- 換正確電池
- Wi-Fi 路由器設定
- 關閉誤觸雙重認證（依品牌技能執行）
- 重新登錄指紋／卡片

### 必須派工
- 門扇反弓、鉸鍊歪斜、門下沉
- 鎖體機械損傷
- 管理者密碼與管理者卡片皆遺失（恢復原廠）
- 紅燈閃 4 次（馬達異常）
- 異常耗電已換電池仍復發 → 量測 IC 板

## 客戶口語對照

- 「鎖卡住了」→ 鎖舌卡死 或 門扇卡澀（需確認）
- 「門關不起來」→ 自動上鎖失敗 或 鎖栓無法伸出
- 「鎖沒電了」→ 電池耗盡（先確認電池品牌）
- 「被鎖在外面」→ 緊急優先處理
- 「鎖會漏電」→ 異常耗電（並非真正漏電）
- 「不小心按到什麼」→ 可能誤觸雙重認證

## 緊急處理優先順序（被鎖在外）

1. 實體鑰匙（鎖體底部蓋子內）
2. 行動電源緊急供電（Type-C，部分型號）
3. 安排緊急派工
