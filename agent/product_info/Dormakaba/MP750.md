# Dormakaba MP750

## 產品概述

MP750 是推拉式智慧電子鎖（密碼／卡片／指紋／機械鑰匙）。觸控面板配指紋模組與卡片感應區，4 顆 AA 電池，背面 CLOSE 手動快速上鎖。隱藏式機械鑰匙作為備援。

## 操作步驟

### 管理者密碼設定
1. 打開背蓋按【註冊】鍵。
2. 輸入【管理者密碼】+【#】。
3. 按【0】鍵。
4. 輸入新密碼 6~12 位 +【#】完成。

### 使用者密碼設定
1. 開背蓋按【註冊】。
2. 輸入管理者密碼 +【#】。
3. 按【1】鍵。
4. 輸入新密碼 4~12 位 +【#】，再按一次【#】確定。

### 卡片設定
1. 開背蓋按【註冊】。
2. 輸入管理者密碼 +【#】。
3. 按【2】鍵。
4. 將 RFID 卡接觸感應區後按【#】完成。

### 指紋設定
1. 開背蓋按【註冊】。
2. 輸入管理者密碼 +【#】。
3. 按【3】鍵。
4. 在指紋模組感應【3 次】（面板顯示 1/2/3）+【#】完成。

### 鑰匙解鎖
- 撥開門鎖側面防塵蓋，鑰匙插入後向右轉上鎖、向左轉解鎖。

### 全部刪除（密碼／卡片／指紋）
1. 長按背面【註冊】鍵 10 秒。
2. 輸入管理者密碼 +【#】。
3. 全部密碼：按【1】+ 長按【#】3 秒；
   全部卡片：按【2】+ 長按【#】3 秒；
   全部指紋：按【3】+ 按【*】完成。

### 卡片設定（跨型號通用）
- **連續註冊**：按【註冊】→ 管理者密碼／卡片 → 按【2】→ 連續感應卡片 → 按【#】退出。
- **指定位址**：按【2】→ 輸入位址 1~100 → 按【#】→ 感應卡 → 按【#】。
- **單刪**：長按註冊鍵 5 秒（面板閃爍）→ 管理者密碼 → 按【2】→ 感應或輸入位址 → 按【*】。
- **全刪**：相同進入流程 → 按【2】後長按【#】3 秒。

### 背蓋與電池更換
- 雙手按住背蓋上方往上拉取下；裝回時由上往下推回。
- 電池槽 4 顆 AA（Panasonic／TOSHIBA 皆有示範，建議 Panasonic 鹼性）。

### APP / 藍牙遠端金鑰
- 掃描電子鎖背面 QR Code 下載 SmartLocky APP，允許藍牙與定位。
- 添加智能門鎖 → 輸入序號等資訊 → 開始配對 → 聽提示音後按電子鎖【註冊】鍵綁定。
- 共享密鑰可生成一次性遠端金鑰分享給訪客；僅第一支綁定手機具管理權。

## 故障排除

### 鎖舌卡住（門打不開）
Dormakaba 鎖舌為擺動式（前後／左右），不是伸縮式：
- 拉門：先把門推緊到底再拉把手。
- 推門：先拉住把手把門拉緊，再用力推。
- 外部解鎖後立刻推或拉，不要遲疑。

### 雙重認證誤觸
- 驗證：「密碼+#」後立刻感應卡片或按指紋，能開即代表已啟用雙重認證。
- 解除：開門狀態下按一次內側 CLOSE 讓鎖栓伸出，喚醒面板輸入管理者密碼+【*】一次，再按【8】解除（按【5】開啟）。

### 鎖栓測試
1. 開門狀態按一次 CLOSE/OPEN 鍵，鎖栓應能正常伸縮 → 鎖體沒問題。
2. 一關門就上鎖失敗 → 受口片偏斜或內有異物，需檢查門框受口片。
3. 解鎖失敗：鎖栓伸出時卡到受口片，需對位。

### 派工條件
- ❌ 管理者密碼與管理者卡片皆遺失，需初始化 → 派工
- ❌ 紅燈閃 4 次（馬達異常）→ 派工
- ❌ 恢復出廠設定 → 派工
- ❌ 受口片需調整 → 派工
