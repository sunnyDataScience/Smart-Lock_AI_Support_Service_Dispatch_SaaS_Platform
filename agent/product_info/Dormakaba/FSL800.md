# Dormakaba FSL800

## 產品概述

FSL800 是把手式電子鎖，操作邏輯較其他 Dormakaba 型號特殊：以「M 鍵」（針孔）初始化，使用者透過編號管理（指紋／卡片編號 10–79，密碼編號 01–07）；門把上提即可二段上鎖；室內可旋鈕第三段手動反鎖。電池為 8 顆 AA。

## 操作步驟

### 管理者密碼設定（初始化用 M 鍵）
1. 按住電池蓋下方，將蓋子往上拉開。
2. 用針狀物（迴紋針）按住電池槽內【M】鍵約 10 秒，直到聽到提示音。
3. 輸入自訂管理者密碼 6~12 位後按【#】。
4. 重複輸入該密碼後按【#】完成。

### 指紋設定
1. 掀開指紋蓋，輸入管理者密碼 +【#】。
2. 按【1】+【#】。
3. 輸入兩位數編號（範圍 10~79，不可重複）+【#】。
4. 在指紋模組感應【3 次】完成。

### 卡片設定
1. 輸入管理者密碼 +【#】。
2. 按【2】+【#】。
3. 輸入兩位數編號（範圍 10~79，不可重複）+【#】。
4. 用 RFID 卡接觸感應區完成。

### 密碼設定（使用者）
1. 輸入管理者密碼 +【#】。
2. 按【3】+【#】。
3. 按【1】+【#】。
4. 輸入兩位數編號（範圍 01~07，不可重複）+【#】。
5. 輸入自訂密碼 6~12 位 +【#】。
6. 重複輸入該密碼 +【#】完成。

### 鑰匙解鎖
- 將鑰匙插入下方鑰匙孔，向右轉動解鎖。

### 室外二段上鎖
- 門把向上提即完成二段上鎖；解鎖後下壓把手即開門。

### 室內多段上鎖
- 室內把手向上提：二段上鎖。
- 反方向旋轉室內旋鈕：第三段上鎖（內部手動反鎖）。
- 反方向旋轉旋鈕並下壓把手：解鎖開門。

### 刪除單枚指紋
1. 輸入管理者密碼 +【#】。
2. 按【1】+【#】→ 按【2】+【#】。
3. 輸入欲刪除的編號 +【#】。

### 刪除全部指紋
1. 輸入管理者密碼 +【#】。
2. 按【1】+【#】→ 按【3】+【#】→ 按【1】+【#】。

### 刪除單張卡片
1. 輸入管理者密碼 +【#】。
2. 按【2】+【#】→ 按【2】+【#】。
3. 輸入欲刪除的卡片編號 +【#】。

### 刪除全部卡片
1. 輸入管理者密碼 +【#】。
2. 按【2】+【#】→ 按【3】+【#】→ 按【1】+【#】。

### 刪除單組密碼
1. 輸入管理者密碼 +【#】。
2. 按【3】+【#】→ 按【2】+【#】。
3. 輸入欲刪除密碼編號 +【#】。

### 刪除全部密碼
1. 輸入管理者密碼 +【#】。
2. 按【3】+【#】→ 按【3】+【#】→ 按【1】+【#】。

### 電池蓋與電池更換
- 按住電池蓋下方往上拉打開；安裝 8 顆 AA 電池；蓋子由上往下蓋回。

### 卡片設定（跨型號通用補充）
- 其他 Dormakaba 型號採用「位址 1~100」與「2 鍵連續註冊／#鍵退出／*鍵單刪」流程；FSL800 改用編號（10~79）與【1/2/3】功能切換鍵，請以本機 SOP 為準。

### APP / 藍牙遠端金鑰
- 同 Dormakaba 其他型號：掃描 QR Code 下載 SmartLocky APP → 添加智能門鎖 → 輸入序號等資訊 → 配對時按下電子鎖【註冊】鍵綁定。
- 共享密鑰可建立一次性遠端金鑰分享給訪客。

## Dormakaba WiFi 設定

> 來源：原廠《WIFI 設定說明書》。本章節為 Dormakaba 通用 WiFi 流程，所有支援 WiFi 的 Dormakaba 型號操作步驟相同；按鍵位置依各型號面板略有差異。

### 前置準備
1. 手機至 App Store / Google Play 搜尋並下載 **dormakaba DDL** APP。
2. 開啟 APP → **註冊用戶**：輸入手機號碼 → 設定登入密碼 → 完成註冊後登入。
3. **網路限制**：電子鎖只支援 **2.4G WiFi**（5G 不支援）；APP 中輸入的 WiFi 名稱與密碼必須與家中實際 WiFi 完全一致（含大小寫）。

### WiFi 連線流程

**步驟 1：APP 端新增設備**
- 進入 APP →「新增設備」→ 掃描電子鎖隨附 / 內側貼紙 QR 碼。
- 在 APP 輸入家中 WiFi 名稱與密碼（與要連的網路相同）。

**步驟 2：電子鎖端開啟 WiFi**
- 在電子鎖**進入註冊模式**（管理者驗證）。
- 輸入【管理者密碼】後按【#】。
- 按【7】鍵 → 切換至 WiFi 網路介面 → 連線「dormakaba」網路。

**步驟 3：APP 完成綁定**
- WiFi 連線成功後切回 APP → 點選「設置門鎖」→ 點選「允許」進入連線狀態 → 點選主選單完成設置。

### WiFi 功能（連線成功後可用）

| 功能 | APP 操作 |
|---|---|
| **遠端解鎖** | 主畫面點選遠端解鎖；訊息中顯示開門方式與解鎖時間；點選「通知」可瀏覽開門紀錄 |
| **遠端密鑰** | 自訂密鑰名稱與時效長度 → 點選生成 → APP 隨機產生一組密鑰；可重新生成新密鑰覆蓋舊的 |
| **分享管理權限** | 輸入欲新增管理權的手機號碼（**對方手機需先註冊 dormakaba DDL APP**）→ 自訂名稱 → 保存號碼 |

### 常見問題

- **APP 顯示連線失敗**：先確認手機連的是 2.4G WiFi（不是 5G）；APP 中輸入的網路名稱與密碼是否與實際完全相同；電子鎖是否有確實進入 WiFi 設定介面（按【7】後是否顯示連線「dormakaba」網路）。
- **遠端解鎖按下沒反應**：檢查電子鎖端 WiFi 連線狀態是否仍然在線；家中 WiFi 是否正常；嘗試重新進入註冊模式按【7】重新連線一次。
- **要分享給家人**：對方必須**先**自行下載並註冊 dormakaba DDL APP，再由管理者在 APP 內輸入對方手機號碼授權。

> ⚠️ **重要**：以上為 Dormakaba 通用 WiFi 設定流程，部分型號（如 RL599 採用近場藍牙、APP 搖一搖）連線方式略有差異；若客戶操作後仍無法成功配對，請依該型號故障排除段落判斷，必要時派工協助。

## 故障排除

### 鎖舌卡住（門打不開）
Dormakaba 鎖舌為擺動式（前後／左右），不是伸縮式。先確認門關到位、鎖舌卡入受口：
- 拉門：先把門推緊到底再拉把手。
- 推門：先拉住把手把門拉緊，再用力推。
- 外部解鎖後立刻推或拉。
- FSL800 補充：若門把已上提到二段位置但鎖栓未完全動作，請先把門推緊，再下壓把手或使用旋鈕完整收回鎖栓。

### 雙重認證誤觸
- 驗證：請客人試「密碼+#」後立刻感應卡片或按指紋，能開即代表已啟用雙重認證。
- 解除：在開門狀態下，先按一次內側 CLOSE/OPEN 鍵讓鎖栓伸出，喚醒面板輸入管理者密碼+【*】一次，再按【8】解除（按【5】開啟）。
- 註：FSL800 操作邏輯不同，若上述步驟無效請建議客戶查閱說明書或派工確認。

### 鎖栓測試
1. 開門狀態下動作把手或旋鈕，看鎖栓能否正常伸出與收回 → 正常即鎖體沒問題。
2. 一關門就上鎖失敗 → 受口片偏斜或受口片內被異物擋住，檢查門框受口片。
3. 解鎖失敗：鎖栓伸出時卡到受口片，需對位。

### 派工條件
- ❌ 管理者密碼遺失需初始化（M 鍵不靈）→ 派工
- ❌ 紅燈閃 4 次（馬達異常）→ 派工
- ❌ 恢復出廠設定 → 派工
- ❌ 多段上鎖機構卡死 → 派工
