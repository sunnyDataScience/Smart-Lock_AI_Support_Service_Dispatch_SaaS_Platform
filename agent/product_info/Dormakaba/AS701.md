# Dormakaba AS701

## 產品概述

AS701 是第二代推拉式四合一智慧電子鎖（密碼／卡片／指紋／機械鑰匙）。把手強度增加 135%，一鍵推拉開門省力；指紋為半導體電容式（感應 < 0.3 秒，支援 100 組）；密碼支援 4 組（含圖形解鎖）；感應卡可註冊 100 張（悠遊卡/一卡通/RFID 皆可）；附 3 支隱藏式機械鑰匙作為馬達故障備援。電池為 8 顆 Panasonic 鹼性 3 號（AA），底部有 9V 緊急供電接觸點。

## 操作步驟

### 電池安裝
1. 輕按背蓋上方 PUSH 處，將背蓋向下取下。
2. 依電池槽圖案放入 8 顆 Panasonic 鹼性 AA 電池（正極朝上 / 正極朝上 / 負極朝上 / 負極朝上）。請勿使用他牌，否則容易漏液或電流不穩。
3. 將背蓋由上往下蓋回。

### 管理者密碼註冊（#鍵版）
1. 按下背面【註冊】鍵。
2. 輸入【目前管理者密碼】後按【#】鍵。
3. 按【0】鍵。
4. 輸入【新管理者密碼】6~12 位後按【#】鍵。

### 管理者卡片註冊
1. 按下背面【註冊】鍵。
2. 輸入【管理者密碼】後按【#】鍵。
3. 按【0】鍵。
4. 將【管理者卡片】感應後按【#】鍵。

> 請牢記管理者密碼／管理者卡片，遺失將無法增加或刪除設定。

### 使用者密碼註冊
1. 按【註冊】鍵 → 輸入管理者密碼 + #。
2. 按【1】鍵。
3. 輸入指定位址 1~4 後按【#】（不指定可略過）。
4. 輸入【使用者密碼】4~12 位後按【#】。

### 使用者卡片註冊（一卡通／悠遊卡／RFID 皆可）
1. 按【註冊】鍵 → 輸入管理者密碼 + #。
2. 按【2】鍵。
3. 輸入指定位址 1~100 後按【#】（不指定可略過）。
4. 感應【卡片】後按【#】。

### 使用者指紋註冊
1. 按【註冊】鍵 → 輸入管理者密碼 + #。
2. 按【3】鍵。
3. 在指紋模組感應【3 次】要註冊的指紋後按【#】。

### 一次性密碼
1. 按【註冊】鍵 → 輸入管理者密碼／卡片 + #。
2. 按【4】鍵。
3. 輸入 4~12 位一次性密碼後按【#】。
> 開門後密碼即失效，一次只能設定一組。

### 卡片單刪／指定位址刪除
1. 按下背面【註冊】鍵約 5 秒不放，第二次提示音、面板閃爍。
2. 輸入管理者密碼／卡片 + #。
3. 按【2】鍵後感應欲刪除的卡片，或輸入位址後按【*】。

### 全部密碼／卡片／指紋刪除
1. 長按【註冊】鍵 3~5 秒，面板二次閃爍。
2. 輸入管理者密碼 + #。
3. 全部密碼：按【1】+ 長按【#】3 秒；
   全部卡片：按【2】+ 長按【#】3 秒；
   全部指紋：按【3】+ 長按【*】3 秒。

### 機械鑰匙解鎖（馬達故障或沒電時備援）
1. 撥開門鎖側面防塵蓋。
2. 鑰匙橡膠把手較長一側朝上插入。
3. 向左轉到底解鎖；向右轉到底上鎖。

### 常開模式
1. 喚醒面板輸入管理者密碼 + 連按【*】兩次。
2. 按【4】：自動上鎖；按【7】：手動上鎖（手動模式下關門請輕碰面板觸發上鎖）。

### 音量調整
1. 喚醒面板輸入管理者密碼 + 按【*】。
2. 按【3】：調高；按【6】：調低。

### 卡片設定（跨型號通用）
- **註冊**：按背面註冊鍵 → 輸入管理者密碼或感應管理者卡片 → 按【2】→ 連續感應卡片 → 按【#】退出。可同時註冊多張，順序排列。
- **指定位址註冊**：按【2】→ 輸入位址 1~100 → 按【#】→ 感應卡片 → 按【#】退出。位址不可重複，最多 100 組。
- **單刪**：長按背面註冊鍵約 5 秒（面板閃爍）→ 輸入管理者密碼 → 按【2】→ 感應欲刪除的卡片或輸入順序數字 → 按【*】退出。
- **位址刪除**：相同步驟 → 按【2】→ 輸入位址 → 按【*】。
- **全刪**：相同進入流程 → 按【2】後按住【#】約 3 秒。

### 背蓋與電池更換
- AS701 背蓋：壓住背蓋往上拉取下，由上往下蓋回。
- 電池槽 8 顆 Panasonic EVOLTA AA。

### APP / 藍牙遠端金鑰
- 掃描電子鎖背面 QR Code 下載 dormakaba SmartLocky APP（Android／iOS）。
- 開啟藍牙與定位權限，輸入手機資訊、勾選同意條款。
- 「+ 添加智能門鎖」→ 輸入序號、類型、名稱 → 開始配對 → 聽到提示音後按下電子鎖內部【註冊】鍵完成綁定。
- 「共享密鑰」→ 創建新密鑰 → 輸入標籤、開始時間、有效期（日／時／分／持續生效）→ 生成密碼 → 透過訊息分享給對方。
> 注意：只有第一支綁定 APP 的手機具備管理權；分享出去的金鑰使用一次後即失效。

## Dormakaba WiFi 設定

> 來源：原廠《WIFI 設定說明書》。本章節為 Dormakaba 通用 WiFi 流程，所有支援 WiFi 的 Dormakaba 型號操作步驟相同；按鍵位置依各型號面板略有差異。

### 前置準備
1. 手機至 App Store / Google Play 搜尋並下載 **dormakaba DDL** APP。
2. 開啟 APP → **註冊用戶**：輸入手機號碼 → 設定登入密碼 → 完成註冊後登入。
3. **網路限制**：電子鎖只支援 **2.4G WiFi**（5G 不支援）；APP 中輸入的 WiFi 名稱與密碼必須與家中實際 WiFi 完全一致（含大小寫）。

### WiFi 連線流程

**步驟 1：APP 端新增設備**
- 進入 APP →「新增設備」→ 掃描電子鎖隨附 / 內側貼紙 QR 碼。
- 在 APP 輸入家中 WiFi 名稱與密碼（與要連的網路相同）。

**步驟 2：電子鎖端開啟 WiFi**
- 在電子鎖**進入註冊模式**（管理者驗證）。
- 輸入【管理者密碼】後按【#】。
- 按【7】鍵 → 切換至 WiFi 網路介面 → 連線「dormakaba」網路。

**步驟 3：APP 完成綁定**
- WiFi 連線成功後切回 APP → 點選「設置門鎖」→ 點選「允許」進入連線狀態 → 點選主選單完成設置。

### WiFi 功能（連線成功後可用）

| 功能 | APP 操作 |
|---|---|
| **遠端解鎖** | 主畫面點選遠端解鎖；訊息中顯示開門方式與解鎖時間；點選「通知」可瀏覽開門紀錄 |
| **遠端密鑰** | 自訂密鑰名稱與時效長度 → 點選生成 → APP 隨機產生一組密鑰；可重新生成新密鑰覆蓋舊的 |
| **分享管理權限** | 輸入欲新增管理權的手機號碼（**對方手機需先註冊 dormakaba DDL APP**）→ 自訂名稱 → 保存號碼 |

### 常見問題

- **APP 顯示連線失敗**：先確認手機連的是 2.4G WiFi（不是 5G）；APP 中輸入的網路名稱與密碼是否與實際完全相同；電子鎖是否有確實進入 WiFi 設定介面（按【7】後是否顯示連線「dormakaba」網路）。
- **遠端解鎖按下沒反應**：檢查電子鎖端 WiFi 連線狀態是否仍然在線；家中 WiFi 是否正常；嘗試重新進入註冊模式按【7】重新連線一次。
- **要分享給家人**：對方必須**先**自行下載並註冊 dormakaba DDL APP，再由管理者在 APP 內輸入對方手機號碼授權。

> ⚠️ **重要**：以上為 Dormakaba 通用 WiFi 設定流程，部分型號（如 RL599 採用近場藍牙、APP 搖一搖）連線方式略有差異；若客戶操作後仍無法成功配對，請依該型號故障排除段落判斷，必要時派工協助。

## 故障排除

### 鎖舌卡住（門打不開）
Dormakaba 鎖舌是前後（左右）擺動式，不是縮進式。先確認門有確實關到位、鎖舌卡進門框受口：
- 人在裡面拉門：先把門用力推緊到底，再拉把手。
- 人在裡面推門：先拉住把手把門拉緊，再用力推把手。
- 人在外面推門：把整支電子鎖把手拉緊頂住門，解鎖後立刻推開。
- 人在外面拉門：把門推緊，解鎖後再拉把手。

### 雙重認證誤觸（突然單一方式打不開）
若客人原本一指就開、突然要密碼+卡片才開，是雙重認證模式被誤觸啟用。
- 驗證：請客人試「密碼 → #」後立刻感應卡片，能開即代表雙重認證已開。
- 解除：在開門狀態下，先按一次內側 CLOSE/OPEN 鍵讓鎖栓伸出，然後喚醒面板，輸入管理者密碼 + 按【*】一次，再按【8】解除（按【5】開啟）。開著門測試確認正常後再關門。

### 鎖栓測試（關鎖／解鎖失敗）
1. 開著門按一下內側 CLOSE 或 OPEN 鍵，看鎖栓能不能正常伸出與縮回。
2. 若開著門鎖栓動作正常，但一關門就上鎖失敗 → 是門框受口片偏斜或內部有東西卡住，檢查並調整受口片。
3. 解鎖失敗：鎖栓伸出時撞到受口片或門框導致縮不回。檢查受口片對位。

### 派工條件
- ❌ 管理者密碼與管理者卡片皆遺失，需初始化 → 派工
- ❌ 紅燈閃 4 次（馬達異常）→ 派工
- ❌ 恢復出廠設定 → 派工（需技師處理）
- ❌ 受口片需調整或門體需重對 → 派工
