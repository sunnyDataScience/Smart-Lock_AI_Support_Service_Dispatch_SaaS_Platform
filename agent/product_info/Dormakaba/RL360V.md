# Dormakaba RL360V

## 產品概述

RL360V 是三合一直立式智慧輔助電子鎖（密碼／卡片／指紋）。1 組管理者密碼（無法刪除僅能更改）、最多 10 組管理者卡片、4 組使用者密碼、100 組使用者卡片（一卡通／悠遊卡／RFID）、100 組使用者指紋。具螢幕顯示「Success」回饋；底部有 9V 緊急充電。電池為 4 顆 Panasonic 鹼性 AA。

## 操作步驟

### 電池安裝
1. 壓住背蓋向上推取下。
2. 依電池槽圖案放入 4 顆 Panasonic 鹼性 AA。請勿使用他牌。
3. 蓋回背蓋。

### 管理者密碼註冊
1. 按背面【註冊】鍵。
2. 輸入【現有管理者密碼】+【#】。
3. 按【0】鍵。
4. 輸入新管理者密碼 6~12 位 +【#】，螢幕顯示 Success。

### 管理者卡片註冊（最多 10 組）
1. 按【註冊】→ 管理者密碼 + #。
2. 按【0】。
3. 輸入位址 1~10 + #（不指定可略）。
4. 感應【管理者卡片】。

### 使用者密碼註冊
1. 按【註冊】→ 管理者密碼 + # 或感應管理者卡片。
2. 按【1】。
3. 輸入位址 1~4 + #（可略）。
4. 輸入使用者密碼 4~12 位 + #。

### 使用者卡片註冊（100 組）
1. 按【註冊】→ 管理者密碼/卡片。
2. 按【2】。
3. 輸入位址 1~100 + #（可略）。
4. 感應卡 + #（一卡通／悠遊卡／RFID 皆可）。

### 使用者指紋註冊（100 組）
1. 按【註冊】→ 管理者密碼/卡片。
2. 按【3】。
3. 在指紋模組感應【3 次】（螢幕顯示 1/2/3）+ #。可連續註冊，結束按【#】。

### 一次性密碼
1. 按【註冊】→ 管理者密碼/卡片。
2. 按【4】，輸入 6 位密碼 + #。
> 開門後即失效，一次只能設定一組。

### 管理者密碼更改
1. 按【註冊】→ 管理者密碼 + #。
2. 按【0】+ 輸入新管理者密碼 + #。

### 各類刪除
進入刪除模式：長按背面【註冊】鍵約 3 秒，發出第二次提示音、面板二次閃爍。輸入管理者密碼+# 或感應管理者卡片，再操作：
- **管理者卡片單刪**：按【0】+【#】+ 輸入位址 +【*】。
- **管理者卡片全刪**：按【0】後長按【#】3 秒。
- **使用者密碼單刪**：按【1】+【#】+ 輸入位址 +【*】。
- **使用者密碼全刪**：按【1】後長按【#】3 秒。
- **使用者卡片單刪**：按【2】+【#】+ 輸入位址 +【*】或感應卡刪除。
- **使用者卡片全刪**：按【2】後長按【#】3 秒。
- **使用者指紋全刪**：按【3】後長按【#】3 秒。

### 常開模式
1. 喚醒面板輸入管理者密碼 + 連按【*】兩次。
2. 按【4】：自動上鎖；按【7】：手動上鎖（手動模式關門請輕碰面板）。

### 內部反鎖
- 關門狀態下長按內部 CLOSE 鍵約 3 秒；外部面板將失效；按下鎖體按鈕或手動旋鈕即可解除。

### 外部反鎖（內部按鈕失效）
- 喚醒面板輸入管理者密碼 +【*】，按【0】：內部按鈕失效（內部無法用按鈕開門，外部面板仍可開）。
- 用密碼／卡片／內部旋鈕解鎖即可解除。

### 音量
- 喚醒面板輸入管理者密碼 +【*】，按【3】調高、按【6】調低、按【#】結束。

### 緊急充電
- 9V 電池對準底部緊急接口、用力壓下，過電時電子鎖亮燈（任何品牌皆可）。

### 卡片設定（跨型號通用）
- **連續註冊**：按【註冊】→ 管理者密碼／卡片 → 按【2】→ 連續感應卡片 → 按【#】退出。
- **指定位址**：按【2】→ 輸入位址 1~100 → 按【#】→ 感應卡 → 按【#】。
- **單刪**：長按註冊鍵 5 秒（面板閃爍）→ 管理者密碼 → 按【2】→ 感應或輸入位址 → 按【*】。
- **全刪**：相同進入流程 → 按【2】後長按【#】3 秒。

### 背蓋與電池
- 壓住背蓋向上推取下；4 顆 Panasonic 鹼性 AA。

### APP / 藍牙遠端金鑰
- 掃描背面 QR Code 下載 SmartLocky APP，允許藍牙與定位。
- 添加智能門鎖 → 輸入序號等資訊 → 開始配對 → 聽提示音後按電子鎖【註冊】鍵綁定。
- 共享密鑰可生成有效期一次性密碼分享給訪客。

## Dormakaba WiFi 設定

> 來源：原廠《WIFI 設定說明書》。本章節為 Dormakaba 通用 WiFi 流程，所有支援 WiFi 的 Dormakaba 型號操作步驟相同；按鍵位置依各型號面板略有差異。

### 前置準備
1. 手機至 App Store / Google Play 搜尋並下載 **dormakaba DDL** APP。
2. 開啟 APP → **註冊用戶**：輸入手機號碼 → 設定登入密碼 → 完成註冊後登入。
3. **網路限制**：電子鎖只支援 **2.4G WiFi**（5G 不支援）；APP 中輸入的 WiFi 名稱與密碼必須與家中實際 WiFi 完全一致（含大小寫）。

### WiFi 連線流程

**步驟 1：APP 端新增設備**
- 進入 APP →「新增設備」→ 掃描電子鎖隨附 / 內側貼紙 QR 碼。
- 在 APP 輸入家中 WiFi 名稱與密碼（與要連的網路相同）。

**步驟 2：電子鎖端開啟 WiFi**
- 在電子鎖**進入註冊模式**（管理者驗證）。
- 輸入【管理者密碼】後按【#】。
- 按【7】鍵 → 切換至 WiFi 網路介面 → 連線「dormakaba」網路。

**步驟 3：APP 完成綁定**
- WiFi 連線成功後切回 APP → 點選「設置門鎖」→ 點選「允許」進入連線狀態 → 點選主選單完成設置。

### WiFi 功能（連線成功後可用）

| 功能 | APP 操作 |
|---|---|
| **遠端解鎖** | 主畫面點選遠端解鎖；訊息中顯示開門方式與解鎖時間；點選「通知」可瀏覽開門紀錄 |
| **遠端密鑰** | 自訂密鑰名稱與時效長度 → 點選生成 → APP 隨機產生一組密鑰；可重新生成新密鑰覆蓋舊的 |
| **分享管理權限** | 輸入欲新增管理權的手機號碼（**對方手機需先註冊 dormakaba DDL APP**）→ 自訂名稱 → 保存號碼 |

### 常見問題

- **APP 顯示連線失敗**：先確認手機連的是 2.4G WiFi（不是 5G）；APP 中輸入的網路名稱與密碼是否與實際完全相同；電子鎖是否有確實進入 WiFi 設定介面（按【7】後是否顯示連線「dormakaba」網路）。
- **遠端解鎖按下沒反應**：檢查電子鎖端 WiFi 連線狀態是否仍然在線；家中 WiFi 是否正常；嘗試重新進入註冊模式按【7】重新連線一次。
- **要分享給家人**：對方必須**先**自行下載並註冊 dormakaba DDL APP，再由管理者在 APP 內輸入對方手機號碼授權。

> ⚠️ **重要**：以上為 Dormakaba 通用 WiFi 設定流程，部分型號（如 RL599 採用近場藍牙、APP 搖一搖）連線方式略有差異；若客戶操作後仍無法成功配對，請依該型號故障排除段落判斷，必要時派工協助。

## 故障排除

### 鎖舌卡住（門打不開）
Dormakaba 鎖舌為擺動式（前後／左右）：
- 拉門：先把門推緊到底再拉把手。
- 推門：先拉住把手把門拉緊，再用力推。
- 外部解鎖後立刻推或拉，不要遲疑。

### 雙重認證誤觸
- 驗證：「密碼+#」後立刻感應卡片或按指紋，能開即代表已啟用雙重認證。
- 解除：開門狀態下按一次內側 CLOSE 讓鎖栓伸出，喚醒面板輸入管理者密碼+【*】一次，再按【8】解除（按【5】開啟）。

### 鎖栓測試
1. 開門狀態按一次 CLOSE/OPEN 或內部按鈕，鎖栓應能正常伸縮 → 鎖體沒問題。
2. 一關門就上鎖失敗 → 受口片偏斜或內有異物，需檢查門框受口片。
3. 解鎖失敗：鎖栓伸出時卡到受口片，需對位。

### 派工條件
- ❌ 管理者密碼與管理者卡片皆遺失，需初始化 → 派工
- ❌ 紅燈閃 4 次（馬達異常）→ 派工
- ❌ 恢復出廠設定 → 派工
- ❌ 受口片需調整 → 派工
