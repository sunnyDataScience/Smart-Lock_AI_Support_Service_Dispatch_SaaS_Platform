# Dormakaba ML660

## 產品概述

ML660 是把手式四合一智慧電子鎖（密碼／卡片／指紋／機械鑰匙）。4 組密碼（含圖形解鎖虛擬密碼）、感應卡 100 張（一卡通／悠遊卡）、把手上指紋辨識 100 組、隱藏式機械鑰匙。內部按鈕可手動快速上鎖／解鎖；長按 3 秒可內部反鎖（外部面板失效，僅能從內部解除）。底部 9V 緊急供電與 Micro USB 緊急供電孔。具防撬警報。

## 操作步驟

### 管理者密碼註冊
1. 向上推開背蓋，按下【註冊】鍵。
2. 輸入初始密碼【123456】+【#】。
3. 按【0】鍵。
4. 輸入新管理者密碼 6~12 位 +【#】完成。

> 請在開門狀態下註冊。

### 密碼註冊（使用者密碼）
1. 按【註冊】鍵。
2. 輸入管理者密碼 +【#】。
3. 按【1】鍵。
4. 輸入使用者密碼 4~12 位 +【#】。

### 卡片設定
1. 按【註冊】鍵。
2. 輸入管理者密碼 +【#】。
3. 按【2】鍵。
4. 將 RFID 卡接觸感應區後按【#】。

### 指紋設定
1. 按【註冊】鍵。
2. 輸入管理者密碼 +【#】。
3. 按【3】鍵。
4. 將手指放在掃描器上掃描【3 次】+【#】。

### 一次性密碼
1. 按【註冊】鍵。
2. 輸入管理者密碼 +【#】。
3. 按【4】鍵。
4. 輸入密碼 4~12 位 +【#】。

### 機械鑰匙開鎖
- 取下把手上方圓孔的蓋子露出鑰匙孔，鑰匙把手洞口面朝上插入後轉動開鎖。

### 沒電時開門
- **9V 緊急供電**：將 9V 電池接觸電子鎖底部緊急供電接口，喚醒後輸入密碼開鎖。
- **機械鑰匙**：將鑰匙插入隱藏式鑰匙孔轉動開鎖。
- 也可使用 Micro USB 線接行動電源從底部供電。

### 內部反鎖（外部面板失效）
- 關門狀態下按住內部按鈕約 3 秒（會有提示音），外部面板即失效，僅能從內部解除。

### 開門方式
- 把手上指紋辨識：握住把手、拇指按壓指紋區、同時下壓把手即開門。
- 卡片／密碼解鎖後也是直接下壓把手。

### 刪除設定
1. 向上推開背蓋。
2. 按下【註冊】鍵約 5 秒（提示音）。
3. 輸入管理者密碼 +【#】。
4. 輸入欲刪除設定：
   - 【1】+【#】長按 3 秒：刪除密碼
   - 【2】+【#】長按 3 秒：刪除卡片
   - 【3】+【*】長按 3 秒：刪除指紋

### 卡片設定（跨型號通用）
- **連續註冊**：按【註冊】→ 管理者密碼／卡片 → 按【2】→ 連續感應卡片 → 按【#】退出。
- **指定位址**：按【2】→ 輸入位址 1~100 → 按【#】→ 感應卡片 → 按【#】退出。
- **單刪**：長按註冊鍵 5 秒（面板閃爍）→ 管理者密碼 → 按【2】→ 感應或輸入位址 → 按【*】。
- **全刪**：相同進入流程 → 按【2】後長按【#】3 秒。

### 背蓋與電池
- ML660 背蓋向上推開取下；裝回向下推合。電池槽 8 顆 AA。

### APP / 藍牙遠端金鑰
- 掃描 QR Code 下載 SmartLocky APP，允許藍牙與定位。
- 添加智能門鎖 → 輸入序號等資訊 → 開始配對 → 聽提示音後按電子鎖【註冊】鍵綁定。
- 共享密鑰可生成有效期一次性密碼分享給訪客。

## Dormakaba WiFi 設定

> 來源：原廠《WIFI 設定說明書》。本章節為 Dormakaba 通用 WiFi 流程，所有支援 WiFi 的 Dormakaba 型號操作步驟相同；按鍵位置依各型號面板略有差異。

### 前置準備
1. 手機至 App Store / Google Play 搜尋並下載 **dormakaba DDL** APP。
2. 開啟 APP → **註冊用戶**：輸入手機號碼 → 設定登入密碼 → 完成註冊後登入。
3. **網路限制**：電子鎖只支援 **2.4G WiFi**（5G 不支援）；APP 中輸入的 WiFi 名稱與密碼必須與家中實際 WiFi 完全一致（含大小寫）。

### WiFi 連線流程

**步驟 1：APP 端新增設備**
- 進入 APP →「新增設備」→ 掃描電子鎖隨附 / 內側貼紙 QR 碼。
- 在 APP 輸入家中 WiFi 名稱與密碼（與要連的網路相同）。

**步驟 2：電子鎖端開啟 WiFi**
- 在電子鎖**進入註冊模式**（管理者驗證）。
- 輸入【管理者密碼】後按【#】。
- 按【7】鍵 → 切換至 WiFi 網路介面 → 連線「dormakaba」網路。

**步驟 3：APP 完成綁定**
- WiFi 連線成功後切回 APP → 點選「設置門鎖」→ 點選「允許」進入連線狀態 → 點選主選單完成設置。

### WiFi 功能（連線成功後可用）

| 功能 | APP 操作 |
|---|---|
| **遠端解鎖** | 主畫面點選遠端解鎖；訊息中顯示開門方式與解鎖時間；點選「通知」可瀏覽開門紀錄 |
| **遠端密鑰** | 自訂密鑰名稱與時效長度 → 點選生成 → APP 隨機產生一組密鑰；可重新生成新密鑰覆蓋舊的 |
| **分享管理權限** | 輸入欲新增管理權的手機號碼（**對方手機需先註冊 dormakaba DDL APP**）→ 自訂名稱 → 保存號碼 |

### 常見問題

- **APP 顯示連線失敗**：先確認手機連的是 2.4G WiFi（不是 5G）；APP 中輸入的網路名稱與密碼是否與實際完全相同；電子鎖是否有確實進入 WiFi 設定介面（按【7】後是否顯示連線「dormakaba」網路）。
- **遠端解鎖按下沒反應**：檢查電子鎖端 WiFi 連線狀態是否仍然在線；家中 WiFi 是否正常；嘗試重新進入註冊模式按【7】重新連線一次。
- **要分享給家人**：對方必須**先**自行下載並註冊 dormakaba DDL APP，再由管理者在 APP 內輸入對方手機號碼授權。

> ⚠️ **重要**：以上為 Dormakaba 通用 WiFi 設定流程，部分型號（如 RL599 採用近場藍牙、APP 搖一搖）連線方式略有差異；若客戶操作後仍無法成功配對，請依該型號故障排除段落判斷，必要時派工協助。

## 故障排除

### 鎖舌卡住（門打不開）
Dormakaba 鎖舌為擺動式（前後／左右），不是伸縮式。確認門關到位、鎖舌卡入受口：
- 拉門：先把門推緊到底再拉把手。
- 推門：先拉住把手把門拉緊，再用力推。
- 外部解鎖後立刻推或拉，不要遲疑。

### 雙重認證誤觸
- 驗證：「密碼+#」後立刻感應卡片或按指紋，能開即代表已啟用雙重認證。
- 解除：開門狀態下按一次內側按鈕讓鎖栓伸出，喚醒面板輸入管理者密碼+【*】一次，再按【8】解除（按【5】開啟）。

### 鎖栓測試
1. 開門狀態下按一次內部按鈕，鎖栓應正常伸出與縮回 → 鎖體沒問題。
2. 一關門就上鎖失敗 → 受口片偏斜或受口片內有異物，需檢查門框受口片。
3. 解鎖失敗：鎖栓伸出時卡到受口片，需對位。

### 警報
- 模擬被撬開時鎖會發出警報；若為誤觸請使用感應卡或指紋解除警報。

### 派工條件
- ❌ 管理者密碼遺失，需初始化 → 派工
- ❌ 紅燈閃 4 次（馬達異常）→ 派工
- ❌ 恢復出廠設定 → 派工
- ❌ 受口片需調整 → 派工
