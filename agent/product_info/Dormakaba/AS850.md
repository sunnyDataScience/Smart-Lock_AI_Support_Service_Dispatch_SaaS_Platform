# Dormakaba AS850

## 產品概述

AS850 是推拉式四合一智慧電子鎖（密碼／卡片／指紋／機械鑰匙）。雙向推拉式設計，半導體直壓式指紋（< 0.3 秒、支援 100 組），密碼 4 組（含圖形解鎖虛擬密碼），感應卡 100 張，3 支隱藏式機械鑰匙。底部具 9V 電池接觸點與 Type-C 充電孔，背面 CLOSE 按鈕可手動快速上鎖；內側把手機械鎖定切換綠（Open）／紅（Close），可防寵物與小孩誤開。設定有中文語音導引（可改英文或停用）。

## 操作步驟

### 上蓋開關
- 按壓上蓋上方使其彈起，往上拉取下；蓋回時由上往下放回，再按壓上方即可關上。

### 管理者密碼設定
1. 按壓上蓋取下，按下背蓋內【註冊】鍵。
2. 輸入【管理者密碼】後按【#】。
3. 按【0】鍵。
4. 輸入新密碼 6~12 位 + 【#】完成。

### 使用者密碼設定
1. 開背蓋按【註冊】。
2. 輸入管理者密碼 + 【#】。
3. 按【1】。
4. 輸入新密碼 4~12 位 + 【#】，再按一次【#】確定。

### 卡片設定
1. 開背蓋按【註冊】。
2. 輸入管理者密碼 + 【#】。
3. 按【2】。
4. 將 RFID／悠遊卡／一卡通感應於上方 CARD 區後按【#】。

### 指紋設定
1. 開背蓋按【註冊】。
2. 輸入管理者密碼 + 【#】。
3. 按【3】。
4. 在指紋模組感應【3 次】後按【#】。

### 遙控器設定
1. 開背蓋按【註冊】。
2. 輸入管理者密碼 + 【#】。
3. 按下遙控器上的【OPEN】鍵後按【#】完成。

### 鑰匙解鎖
- 撥開門鎖下方防塵蓋，鑰匙插入後向右轉上鎖、向左轉解鎖。

### 全部刪除（密碼／卡片／指紋／遙控器）
1. 長按背面【註冊】鍵 5 秒（提示音）。
2. 輸入管理者密碼 + 【#】。
3. 全部密碼：按【1】+ 長按【#】3 秒；
   全部卡片：按【2】+ 長按【#】3 秒；
   全部指紋：按【3】+ 長按【*】3 秒；
   刪除遙控器：按【5】+ 長按【*】3 秒。

### 卡片設定（跨型號通用）
- **連續註冊**：按【註冊】→ 管理者密碼／卡片 → 按【2】→ 連續感應卡片 → 按【#】退出。
- **指定位址**：按【2】→ 輸入位址 1~100 → 按【#】→ 感應卡 → 按【#】退出。
- **單刪**：長按註冊鍵 5 秒 → 管理者密碼 → 按【2】→ 感應或輸入位址 → 按【*】。

### 背蓋與電池更換（DP850/AS850 風格上下蓋）
- 雙手按住背蓋上方往下打開；裝回時由下往上推回。
- 電池槽 8 顆 Panasonic EVOLTA AA（依槽內圖案決定正負極方向）。

### APP / 藍牙遠端金鑰
- 掃描背面 QR Code 下載 dormakaba SmartLocky APP，開啟藍牙與定位權限。
- 註冊／登入 → 添加智能門鎖 → 輸入序號／類型／名稱／設備地址 → 開始配對 → 聽到提示音後按下電子鎖內部【註冊】鍵完成綁定。
- 「共享密鑰」可建立一次性遠端金鑰（標籤、開始時間、有效期）並透過訊息分享給對方，僅綁定的第一支手機具管理權。

## 故障排除

### 鎖舌卡住（門打不開）
Dormakaba 鎖舌為前後／左右擺動式（非伸縮式）。先確認門有關到位、鎖舌卡入受口：
- 內部拉門：先用力推門到底，再拉把手。
- 內部推門：先拉住把手把門拉緊，再用力推把手。
- 外部推門：把整支電子鎖拉緊頂住，解鎖後立刻推開。
- 外部拉門：先把門推緊，解鎖後再拉把手。

### 雙重認證誤觸
若原本一個方式可開、突然要密碼+卡片才能開：
- 驗證：請客人輸入密碼 + #，緊接著感應卡片，能開即代表雙重認證已開啟。
- 解除：在開門狀態下，先按一次內側 CLOSE/OPEN 鍵讓鎖栓伸出，喚醒面板輸入管理者密碼 + 【*】一次，再按【8】解除（按【5】是開啟）。

### 鎖栓測試（自動上鎖確認）
1. 開門狀態下按一次內側 CLOSE/OPEN 鍵，鎖栓應正常伸出與縮回 → 鎖體本身沒問題。
2. 若一關門就上鎖失敗 → 受口片偏斜或受口片內被異物卡住，需檢查並調整門框受口片。
3. 解鎖失敗：鎖栓伸出時卡到受口片導致縮不回，需重新對位。

### 派工條件
- ❌ 管理者密碼與管理者卡片皆遺失，需初始化 → 派工
- ❌ 紅燈閃 4 次（馬達異常）→ 派工
- ❌ 恢復出廠設定 → 派工（需技師處理）
- ❌ 受口片需調整 → 派工
