# Dormakaba FA9000

## 產品概述

FA9000 是五合一人臉辨識智慧電子鎖（人臉／密碼／卡片／指紋／機械鑰匙）。100 組人臉註冊（紅外線夜視熱能感應，3D 結構光，身高 120~200 cm 皆可辨識，可單刪）；1 組管理者密碼、10 組管理者卡片、4 組使用者密碼、100 組使用者卡片、100 組使用者指紋；半導體指紋（< 0.3 秒）；隱藏式鑰匙孔（特殊鎖胚不易複製）。8 顆 3 號鹼性電池（最高 12 個月續航），9V 緊急充電。具防撬警報、入侵警報、高溫感應警報、提示更換電池、提示鎖舌卡住、CLOSE 按鍵可鎖定外部面板，IP54 外部生活防水。

## 操作步驟

### 電池安裝
1. 輕按背蓋上方 PUSH 處取下背蓋。
2. 依槽內圖案放入 8 顆 Panasonic 鹼性 AA（正極朝上 / 正極朝上 / 負極朝上 / 負極朝上）。請勿使用他牌。
3. 蓋回背蓋。

### 管理者密碼註冊
1. 按背面【註冊】鍵。
2. 輸入【現有管理者密碼】+【#】。
3. 按【0】鍵。
4. 輸入新密碼 6~12 位 +【#】。

### 管理者卡片註冊（最多 10 組）
1. 按【註冊】→ 管理者密碼 + #。
2. 按【0】。
3. 輸入位址 1~10 + #（不指定可略）。
4. 感應【管理者卡片】+【#】。

### 人臉辨識註冊（最多 100 組）
1. 按【註冊】→ 管理者密碼 + # 或感應管理者卡片。
2. 按【6】（不指定位址按【*】略過）。
3. 輸入位址 1~100 + #（可略）。
4. 站到電子鎖前（130~200 cm，不需刻意彎腰，大人小孩都適用），等面板倒數完成註冊後按【#】。

### 使用者密碼註冊（4 組）
1. 按【註冊】→ 管理者密碼 + # 或卡片。
2. 按【1】。
3. 輸入位址 1~4 + #（可略）。
4. 輸入使用者密碼 4~12 位 + #。

### 使用者卡片註冊（100 組）
1. 按【註冊】→ 管理者密碼 + # 或卡片。
2. 按【2】。
3. 輸入位址 1~100 + #（可略）。
4. 感應卡 + #（一卡通／悠遊卡／RFID 皆可）。

### 使用者指紋註冊（100 組）
1. 按【註冊】→ 管理者密碼 + # 或卡片。
2. 按【3】。
3. 輸入位址 1~100 + #（可略）。
4. 在指紋模組感應【3 次】+ #。

### 一次性密碼
1. 按【註冊】→ 管理者密碼 + # 或卡片。
2. 按【4】，輸入 6 位密碼 + #。
> 開門後失效，一次只能設定一組。

### 機械鑰匙解鎖
- 鑰匙橡膠把手較長一側朝上插入；向左轉到底解鎖、向右轉到底上鎖。

### 管理者密碼更改（無法刪除，僅能更改）
1. 按【註冊】→ 管理者密碼 + #。
2. 按【0】+ 輸入新管理者密碼 + #。

### 各類刪除
進入刪除模式：長按背面【註冊】鍵 3 秒不放，發出第二次提示音、面板二次閃爍。輸入管理者密碼 + # 或感應管理者卡片，再依下方操作：
- **管理者卡片單刪**：按【0】+【#】+ 輸入卡片位址 +【*】。
- **管理者卡片全刪**：按【0】後長按【#】3 秒。
- **人臉單刪**：按【6】+【#】+ 輸入位址 +【*】。
- **人臉全刪**：按【6】後長按【#】3 秒。
- **使用者密碼單刪**：按【1】+【#】+ 輸入位址 +【*】。
- **使用者密碼全刪**：按【1】後長按【#】3 秒。
- **使用者卡片單刪**：按【2】+【#】+ 輸入位址 +【*】或直接感應該卡。
- **使用者卡片全刪**：按【2】後長按【#】3 秒。
- **使用者指紋單刪**：按【3】+【#】+ 輸入位址 +【*】。
- **使用者指紋全刪**：按【3】後長按【#】3 秒。

### 常開模式
1. 喚醒面板輸入管理者密碼 + 連按【*】兩次。
2. 按【4】：自動上鎖；按【7】：手動上鎖（手動模式關門請輕碰面板）。

### 內部反鎖
- 關門狀態下長按內部 CLOSE 鍵約 3 秒，外部面板將失效；拉內部把手即可解除。

### 把手鎖定（防寵物／小孩）
- 內部把手下方按鈕：綠（Open）正常／紅（Close）內部失效。注意：紅色狀態下「外部面板仍可開」。

### 音量
- 喚醒面板輸入管理者密碼 +【*】，按【3】調高、按【6】調低、按【#】結束。

### 緊急充電
- 9V 電池對準底部緊急接口、用力壓下，過電時電子鎖亮燈（任何品牌皆可）。

### 卡片設定（跨型號通用）
- **連續註冊**：按【註冊】→ 管理者密碼／卡片 → 按【2】→ 連續感應卡片 → 按【#】退出。
- **指定位址**：按【2】→ 輸入位址 1~100 → 按【#】→ 感應卡 → 按【#】。
- **單刪**：長按註冊鍵 5 秒（面板閃爍）→ 管理者密碼 → 按【2】→ 感應或輸入位址 → 按【*】。
- **全刪**：相同進入流程 → 按【2】後長按【#】3 秒。

### APP / 藍牙遠端金鑰
- 掃描背面 QR Code 下載 SmartLocky APP，允許藍牙與定位，註冊／登入。
- 添加智能門鎖 → 輸入序號等資訊 → 開始配對 → 聽提示音後按電子鎖內【註冊】鍵綁定。
- 「共享密鑰」可生成有效期一次性密碼分享給訪客；僅第一支綁定手機具管理權。

## 故障排除

### 鎖舌卡住（門打不開）
Dormakaba 鎖舌為擺動式（前後／左右），不是伸縮式。先確認門有確實關到位、鎖舌卡入受口：
- 拉門：先把門推緊到底再拉把手；推門：先拉住把手拉緊再用力推。
- 外部解鎖後請立刻推或拉，不要遲疑。

### 雙重認證誤觸
- 驗證：「密碼+#」後立刻感應卡片或按指紋，能開即代表雙重認證已開。
- 解除：開門狀態下按一次內側 CLOSE 讓鎖栓伸出，喚醒面板輸入管理者密碼+【*】一次，再按【8】解除（按【5】是開啟）。

### 鎖栓測試
1. 開門狀態按一次 CLOSE/OPEN，鎖栓應能正常伸縮 → 鎖體沒問題。
2. 一關門就上鎖失敗 → 受口片偏斜或內有異物，需檢查門框受口片。
3. 解鎖失敗：鎖栓伸出時卡到受口片，需對位。

### 警報處理
- 防撬／入侵警報：人為破壞造成大門開啟會引發警報；若為誤觸，請使用指紋或感應卡解除。
- 高溫感應警報：偵測異常高溫時觸發，現場應確認環境安全。
- 低電量提示：請盡快更換電池。

### 派工條件
- ❌ 管理者密碼與管理者卡片皆遺失，需初始化 → 派工
- ❌ 紅燈閃 4 次（馬達異常）→ 派工
- ❌ 恢復出廠設定 → 派工
- ❌ 人臉辨識完全無法註冊或反應、警報持續無法解除 → 派工
- ❌ 受口片需調整 → 派工
