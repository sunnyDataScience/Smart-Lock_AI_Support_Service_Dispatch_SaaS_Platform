# Dormakaba DP850

## 產品概述

DP850 是第二代推拉式六合一智慧電子鎖（密碼／卡片／指紋／機械鑰匙／藍牙／APP 遠端金鑰）。雙向推拉式設計，直壓式指紋（< 0.3 秒，100 組）；4 組密碼（含圖形解鎖）；感應卡 100 張（一卡通／悠遊卡）；隱藏式機械鑰匙 2 支（4mm 鎖匠級鎖芯）。底部具 9V 緊急電池接觸點與 Type-C 充電孔。內側有 CLOSE 手動快速上鎖鍵與機械式鎖定切換（綠 Open／紅 Close）防寵物與小孩誤開。支援近場藍牙、APP 搖一搖開鎖、免連網遠端金鑰。

## 操作步驟

### 上蓋開關
- 按壓上蓋上方使其彈起，往上拉取下；蓋回時由上往下放回，再按壓上方關上。

### 管理者密碼設定
1. 打開背蓋，按下【註冊】鍵。
2. 輸入【管理者密碼】+【#】。
3. 按【0】鍵。
4. 輸入新密碼 6~12 位 +【#】完成。

### 使用者密碼設定
1. 開背蓋按【註冊】。
2. 輸入管理者密碼 +【#】。
3. 按【1】。
4. 輸入新密碼 4~12 位 +【#】，再按一次【#】確定。

### 卡片設定
1. 開背蓋按【註冊】。
2. 輸入管理者密碼 +【#】。
3. 按【2】。
4. 將 RFID 卡感應於上方 CARD 區後按【#】完成。

### 指紋設定
1. 開背蓋按【註冊】。
2. 輸入管理者密碼 +【#】。
3. 按【3】。
4. 在指紋模組感應【3 次】後按【#】完成。

### 遙控器設定
1. 開背蓋按【註冊】。
2. 輸入管理者密碼 +【#】。
3. 按下遙控器 OPEN 鍵後按【#】。

### 鑰匙解鎖
- 撥開門鎖側面防塵蓋，鑰匙插入後向左轉上鎖、向右轉解鎖。

### 全部刪除（密碼／卡片／指紋／遙控器）
1. 長按【註冊】鍵 5 秒（提示音）。
2. 輸入管理者密碼 +【#】。
3. 全部密碼：按【1】+ 長按【#】3 秒；
   全部卡片：按【2】+ 長按【#】3 秒；
   全部指紋：按【3】+ 按【*】完成；
   刪除遙控器：按【5】+ 按【*】完成。

### APP / 藍牙遠端金鑰（DP850 主打功能）
- 掃描電子鎖背面 QR Code 下載 dormakaba SmartLocky APP，允許藍牙與定位。
- 註冊帳號 → 添加智能門鎖 → 輸入序號／類型／名稱／設備地址 → 開始配對 → 聽提示音後按電子鎖內部【註冊】鍵綁定。
- 近場藍牙開鎖：APP 內點擊鎖頭圖示；亦可「搖一搖手機自動開鎖」。
- 遠端金鑰：「共享密鑰」→ 創建新密鑰 → 設定標籤、開始時間、有效期（日／時／分／持續生效）→ 生成密碼 → 透過訊息／郵件分享。對方輸入該密碼即可一次性開門，使用後失效。
- 注意：只有第一支綁定 APP 的手機才能管理。

### 卡片設定（跨型號通用）
- **連續註冊**：按【註冊】→ 管理者密碼或卡片 → 按【2】→ 連續感應卡片 → 按【#】退出。
- **指定位址**：按【2】→ 輸入位址 1~100 → 按【#】→ 感應卡片 → 按【#】退出。位址不可重複。
- **單刪／位址刪**：長按註冊鍵 5 秒 → 管理者密碼 → 按【2】→ 感應卡或輸入位址 → 按【*】。
- **全刪**：同上 → 按【2】後長按【#】3 秒。

### 背蓋與電池更換
- 雙手按住背蓋上方往下打開，由下往上推回。
- 電池槽 4 顆 AA（Panasonic / TOSHIBA 皆有示範，建議 Panasonic 鹼性）。

## Dormakaba WiFi 設定

> 來源：原廠《WIFI 設定說明書》。本章節為 Dormakaba 通用 WiFi 流程，所有支援 WiFi 的 Dormakaba 型號操作步驟相同；按鍵位置依各型號面板略有差異。

### 前置準備
1. 手機至 App Store / Google Play 搜尋並下載 **dormakaba DDL** APP。
2. 開啟 APP → **註冊用戶**：輸入手機號碼 → 設定登入密碼 → 完成註冊後登入。
3. **網路限制**：電子鎖只支援 **2.4G WiFi**（5G 不支援）；APP 中輸入的 WiFi 名稱與密碼必須與家中實際 WiFi 完全一致（含大小寫）。

### WiFi 連線流程

**步驟 1：APP 端新增設備**
- 進入 APP →「新增設備」→ 掃描電子鎖隨附 / 內側貼紙 QR 碼。
- 在 APP 輸入家中 WiFi 名稱與密碼（與要連的網路相同）。

**步驟 2：電子鎖端開啟 WiFi**
- 在電子鎖**進入註冊模式**（管理者驗證）。
- 輸入【管理者密碼】後按【#】。
- 按【7】鍵 → 切換至 WiFi 網路介面 → 連線「dormakaba」網路。

**步驟 3：APP 完成綁定**
- WiFi 連線成功後切回 APP → 點選「設置門鎖」→ 點選「允許」進入連線狀態 → 點選主選單完成設置。

### WiFi 功能（連線成功後可用）

| 功能 | APP 操作 |
|---|---|
| **遠端解鎖** | 主畫面點選遠端解鎖；訊息中顯示開門方式與解鎖時間；點選「通知」可瀏覽開門紀錄 |
| **遠端密鑰** | 自訂密鑰名稱與時效長度 → 點選生成 → APP 隨機產生一組密鑰；可重新生成新密鑰覆蓋舊的 |
| **分享管理權限** | 輸入欲新增管理權的手機號碼（**對方手機需先註冊 dormakaba DDL APP**）→ 自訂名稱 → 保存號碼 |

### 常見問題

- **APP 顯示連線失敗**：先確認手機連的是 2.4G WiFi（不是 5G）；APP 中輸入的網路名稱與密碼是否與實際完全相同；電子鎖是否有確實進入 WiFi 設定介面（按【7】後是否顯示連線「dormakaba」網路）。
- **遠端解鎖按下沒反應**：檢查電子鎖端 WiFi 連線狀態是否仍然在線；家中 WiFi 是否正常；嘗試重新進入註冊模式按【7】重新連線一次。
- **要分享給家人**：對方必須**先**自行下載並註冊 dormakaba DDL APP，再由管理者在 APP 內輸入對方手機號碼授權。

> ⚠️ **重要**：以上為 Dormakaba 通用 WiFi 設定流程，部分型號（如 RL599 採用近場藍牙、APP 搖一搖）連線方式略有差異；若客戶操作後仍無法成功配對，請依該型號故障排除段落判斷，必要時派工協助。

## 故障排除

### 鎖舌卡住（門打不開）
Dormakaba 鎖舌為擺動式（前後／左右），不是伸縮式。確認門關到位、鎖舌卡入受口：
- 內部拉門：先把門推緊到底再拉把手。
- 內部推門：先拉住把手把門拉緊，再用力推。
- 外部推門：把整支電子鎖把手拉緊頂住門，解鎖後立刻推開。
- 外部拉門：先把門推緊，解鎖後再拉把手。

### 雙重認證誤觸
- 驗證：請客人試「密碼+#」後立刻感應卡片或按指紋，能開即代表已啟用雙重認證。
- 解除：開門狀態下按一次內側 CLOSE/OPEN 鍵讓鎖栓伸出，喚醒面板輸入管理者密碼+【*】一次，再按【8】解除（按【5】是開啟）。

### 鎖栓測試（自動上鎖確認）
1. 開門狀態按一次 CLOSE/OPEN，鎖栓應能正常伸縮 → 鎖體沒問題。
2. 一關門就上鎖失敗 → 受口片偏斜或受口片內被異物擋住，需檢查門框受口片。
3. 解鎖失敗：鎖栓伸出時卡到受口片，需重新對位。

### 派工條件
- ❌ 管理者密碼與管理者卡片皆遺失，需初始化 → 派工
- ❌ 紅燈閃 4 次（馬達異常）→ 派工
- ❌ 恢復出廠設定 → 派工
- ❌ 受口片需調整 → 派工
