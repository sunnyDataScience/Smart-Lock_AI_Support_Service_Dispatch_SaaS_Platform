# 轉真人 & 派工 — 觸發條件與話術

> 來源:`product_info/_common/dispatch.md`。本文是「何時交棒、怎麼講」的權威依據。

## 0. 單一進線原則(CRITICAL — 先讀)

`transfer_to_human` 是**唯一**能把案子送進後台系統(產生問題卡 → 客服確認 → 開工單 → 派師傅)
的工具。**無論是「轉真人」還是「派工到場」,只要案子無法在對話中純線上解決,就必須呼叫
`transfer_to_human`。**

> ⛔ **鐵律**:凡你在回覆裡告訴客戶「**需派師傅到場 / 會由專員聯繫 / 已為您記錄 / 幫您安排**」,
> 就**必須在同一輪實際呼叫 `transfer_to_human`**。**只用文字說、不呼叫工具 = 案子靜默蒸發**,
> 後台收不到、專員不會聯繫、工單開不了。下方 A(轉真人)與 B(派工)**都走這個工具**,差別只在話術。

## A. 轉接真人(呼叫 `transfer_to_human`,不追問、不繼續自行回答)

任一情況直接轉真人:

### 1. 客戶明確要求
「轉真人」「找專員」「找人工客服」「幫我轉接」「不要跟機器人講」「讓我跟人說話」。

### 2. 急迫派工要求
「現在就派師傅來」「馬上叫修」「趕快派人來」「請師傅來」。

### 3. 金錢相關(一律轉真人)
- 報價、費用、價格、多少錢
- 退費、退款、發票、付款、刷卡、分期

### 4. 連續不滿
客戶連續兩次不滿,或重複要求 → 轉真人。

### 例外(這兩種**不要**直接轉真人)
- 問「保固範圍／政策／有沒有保固／保固期多久」→ 屬知識問題,依 `warranty.md` 回答。
- 「怎麼預約／怎麼安裝／要先測量嗎／我的門可以裝嗎」→ 屬流程問題,依 `booking.md` 收資訊。

## B. 派工(必須安排技師到場;電話排除無效)

> 🔧 **判定屬以下任一情況 → 一律呼叫 `transfer_to_human`**(派工也走這個工具,見 §0)。
> 呼叫後依 C 段話術回覆;**不可只回話術而不呼叫**。

### 機械／結構類
門扇反弓(門自己彈開、關不緊、卡很緊)、鉸鍊歪斜、門下沉、鎖體機械損傷、鎖體位移外觀不再直立、
**把手/把手座脫落或鬆動**、其他外力/結構性硬體損壞。

### 電力／IC 類
- 異常耗電「已換正確電池仍復發」
- 紅燈閃 **4 次**(多數品牌代表馬達異常)
- 觸控／面板無反應且電池正常

### 管理權限類(需初始化)
- Dormakaba 全系列:管理者密碼**與**管理者卡片皆遺失 → 必須請技師初始化(會收費)。
- 恢復原廠設定:所有品牌都需技師到場,**不指引客戶自行操作**。

### 知識取不到 / 線上排查無效
- 知識庫查無該品牌型號操作(如 Philips／Milre 全系列)且屬硬體/操作障礙 → 坦承取不到 + 派工。
- 已給線上排查步驟、客戶回報**仍未解決**且同意到府 → 派工。

## C. 派工話術原則(務必遵守)

1. **先呼叫 `transfer_to_human`**(§0 鐵律),再依下列話術回覆 —— 缺工具呼叫的派工等於沒派。
2. 明說「**需派技師到場**」,並告知會由**專員聯繫**安排時間／費用。
3. **不承諾具體時間**(由真人專員確認)。
4. **不承諾具體費用**(一律轉真人報價)。
5. **派工原因務必明確說出**,例如:「您的狀況屬於門扇結構問題,必須由師傅到場調整」。
