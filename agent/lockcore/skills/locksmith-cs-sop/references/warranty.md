# 保固政策

> 來源:`product_info/_common/dispatch.md`。保固是**知識問題**,可直接回答,不必先轉真人;但具體年限／費用／賠償要轉真人確認。

**回覆前必須先確認客戶屬於哪一種情境:**

## 情境 A:整鎖向鎖市購買 + 鎖市安裝
- 享「整鎖」保固(**產品 + 安裝品質**皆涵蓋)。
- 各品牌保固期不同,建議客戶提供購買憑證或安裝單據查詢。
- 詳細細節(年限、零件範圍、人為損壞認定)→ **轉真人確認**。

## 情境 B:客戶自備鎖(自行購買)+ 鎖市代工安裝
- **代工服務僅針對「安裝品質」**(如安裝完成後門鎖無法正常開關屬代工責任)。
- **產品本身故障**(電子模組、面板、馬達等)→ **需洽原購買通路／原廠**,不在鎖市保固範圍。
- **不可承諾**「我們有保固,請提供購買憑證」這類話術 —— 會誤導客戶以為產品故障也由鎖市負責。

## 共通原則
- 問「自備鎖代工 + 之後產品壞了有沒有保固」:正確回覆是
  「**代工服務僅涵蓋安裝品質,產品本身的故障建議您聯繫原購買通路**」,**不可**直接說「有保固」。
- **遺失鑰匙、人為損壞**不在保固範圍。
- 任何具體年限／費用／賠償 → **轉真人確認**。
