# Chatlock A90

## 產品概述

A90 為 Chatlock 中階智慧電子鎖，**沒有圓形觸控螢幕**，全部設定皆透過外側的數字鍵盤＋語音引導完成（按 `*#` 喚醒、輸入管理員密碼後依語音提示按 1~9 數字進入子選單）。支援人臉辨識、AI 掌靜脈、半導體指紋、IC 卡、密碼、APP 遠端、一次性密碼、限時密碼與機械鑰匙。電池為內側下方拉帶式可拆充電鋰電池組（內門蓋翻起後抽出電池盒），並可拆卸頂部貓眼蓋取鋰電池進行充電。外側下方圓形蓋下有 Type-C 緊急供電孔與機械鑰匙孔。

## 操作步驟

> A90 所有設定須先「按 `*` →按 `#` → 輸入管理員密碼 → 按 `#`」進入管理員模式，圓形指示燈轉綠後依語音提示往下選。

### 進入管理員模式
1. 觸碰外側面板喚醒（圓形指示燈亮藍）。
2. 依序按【*】→【#】，畫面提示「請輸入管理員密碼」。
3. 輸入管理員密碼後按【#】，指示燈轉綠並語音提示。

### 新增普通用戶與密碼
1. 進入管理員模式。
2. 語音提示「新增普通用戶 請按 1」→ 按【1】。
3. 「新增密碼 請按 3」→ 按【3】。
4. 輸入欲設定的 6 位（含以上）密碼 + 按【#】。
5. 再次輸入相同密碼 + 按【#】→ 語音「新用戶 註冊成功」。

### 新增指紋
1. 進入管理員模式。
2. 按【1】（新增普通用戶）。
3. 按【3】（新增手指）。
4. 將要註冊的手指放在前面板感應處，依語音重複放入直到指示燈轉綠。
5. 語音「新用戶 註冊成功」。

### 新增卡片
1. 進入管理員模式。
2. 按【1】（新增普通用戶）。
3. 按【3】（新增卡片）。
4. 將卡片放在數字鍵盤【5】與【8】中間的感應位置。
5. 提示音響、指示燈轉綠 → 語音「新用戶 註冊成功」。

### 新增人臉辨識
1. 進入管理員模式。
2. 按【1】（新增普通用戶）。
3. 按【1】（新增人臉）。
4. 注視外側鏡頭直到畫面提示「新用戶 註冊成功」。

### 新增掌靜脈
1. 進入管理員模式。
2. 按【1】（新增普通用戶）。
3. 按【2】（新增掌靜脈）。
4. 將手掌伸出，距離鏡頭 15~30 公分感應 → 語音「新用戶 註冊成功」。

### 刪除用戶（驗證／指紋／密碼／卡片／人臉／掌靜脈）
1. 進入管理員模式。
2. 語音「刪除用戶 請按 3」→ 按【3】。
3. 依語音提示選擇刪除方式：
   - 編號刪除：按【1】（記得編號時最快）。
   - 手指刪除：按【2】後感應該指紋。
   - 密碼刪除：按【3】。
   - 卡片刪除：按【4】後感應該卡片。
   - 人臉刪除：按【5】。
   - 掌靜脈刪除：按【6】。
4. 完成後語音「刪除成功」。

### 語言設定
1. 進入管理員模式。
2. 語音「系統管理 請按 4」→ 按【4】。
3. 「語言設定 請按 5」→ 按【5】。
4. 從語音播報選擇：1. 中文 / 2. 英語 / 3. 粵語 / 4. 台語 / 5. 日語，按對應數字。

### 音量設定
1. 進入管理員模式。
2. 語音「音量設定 請按 4」→ 按【4】。
3. 從語音播報選擇：1. 高音量 / 2. 中音量 / 3. 低音量 / 4. 靜音，按對應數字 + 按【#】確認。

### 常開模式 / 兒童安全鎖
1. 進入管理員模式。
2. 「系統管理 請按 4」→ 按【4】。
3. 「開門功能 請按 1」→ 按【1】（進入常開／兒童鎖選單）。
4. 「常開設定 請按 1；兒童安全鎖 請按 5」→ 按對應數字，指示燈轉綠表示啟用。

### 恢復出廠設定
1. 進入管理員模式。
2. 「系統管理 請按 4」→ 按【4】。
3. 「恢復出廠設定 請按 3」→ 按【3】。
4. 「確定恢復出廠設定 請按【#】」→ 按【#】。
5. 提示音響起、指示燈綠 → 語音「恢復成功」。

> 恢復出廠後所有用戶／辨識方式／APP 綁定皆會清除，請事先確認。

### APP 連網設定
1. 觸碰面板喚醒。
2. 進入管理員模式（`*#` + 管理員密碼 + #）。
3. 語音「連網設定 請按 5」→ 按【5】→ 提示音 → 按【#】確認連網。
4. 同時打開手機 APP → 主畫面右上【+】→【添加設備】→ APP 自動搜尋「chatlock AI99」（A90 與 AI-99 在 APP 內顯示相同名稱）。
5. 點【添加】→ 輸入家中 2.4G Wi-Fi 名稱與密碼 →【下一步】。
6. 等待至門鎖叮咚一聲 → APP 顯示「添加成功」。

> A90 與 AI-99 的 APP 連網流程相同，差別只在進入網路設定的方式：A90 透過數字鍵盤按 5，AI-99 透過螢幕選單。

### 鑰匙開門
1. 觀察外側下方圓形孔蓋。
2. 將圓蓋下方向下壓，向右轉開蓋取下。
3. 蓋下露出 Type-C 充電孔與鑰匙孔。
4. 將備用鑰匙插入鑰匙孔，順時針轉動鎖芯完成解鎖。

### 行動電源緊急供電
1. 將圓形孔蓋下壓向右轉開取下。
2. 將 Type-C 線插入左側 Type-C 孔（任何行動電源即可）。
3. 門鎖螢幕亮起、發出開機提示音。
4. 使用已註冊的指紋／密碼／卡片／人臉等正常開門。
5. 拔出 Type-C 線，將圓形孔蓋向左旋轉復位。

### 貓眼蓋拆裝（電池拆裝）
1. 雙手放在內側貓眼蓋上方，將貓眼蓋向上推取下。
2. 取下後可看到電池槽內的鋰電池。
3. 取出鋰電池進行充電。
4. 充飽後將鋰電池放回電池槽。
5. 將貓眼蓋對準後方卡準，向下安裝至貼合。

### 內門下部電池盒拆裝（替代電池路徑）
1. 將內門下部把手位置的卡縫找出。
2. 用細長工具插入卡縫向上撬，將內門蓋翻起。
3. 露出電池倉，將底部黑色卡扣向左推、向上提解鎖電池。
4. 抓住電池上的黑色拉帶，將電池抽出充電。
5. 充電完成後反向裝回：電池放回 → 卡扣下壓向右推鎖定 → 內門蓋蓋回。

## 故障排除

### 紅燈未亮、走到門前不感應（人臉/掌靜脈）
- A90 與 AI-99 同樣有「防回頭機制」：上鎖完成後紅外線感應器約 20 秒冷卻，期間若有寵物/鄰居經過會啟動感應失敗再休眠。
- 解法：摸一下面板讓紅外線重新啟動；或在系統設定中（透過數字鍵盤）依語音找尋【防回頭時間】調整或關閉（部分軟體版本支援，若機器語音無此選項，請聯繫客服確認韌體版本）。

### 一關門就嗶嗶警報叫（關鎖失敗）
- 警報源自鎖栓在自動上鎖時撞到受口片或門框。
- 確認方式：開著門狀態下，按一下外把手後方（Buscle 後方）的【上鎖】按鈕（按 0.5 秒放開），觀察鎖栓是否能正常伸縮。
- 若開著門上下鎖正常但一關門就警報 → 受口片偏斜或門框內有異物，需要調整受口片。
- 若開著門就上鎖失敗 → 鎖體位置／門對齊問題，需技師處理。

### 突然感應辨識失靈／APP 顯示離線
- A90 與 AI-99 同樣的 Wi-Fi 模組設計（在內側螢幕／貓眼蓋內），若內側螢幕未插到底會導致 APP 離線。
- 確認內側螢幕／貓眼蓋已重新插好、貓眼線排線無鬆脫。
- 仍離線：APP 清理緩存後重開、檢查家中 2.4G Wi-Fi 是否正常。

### 雙重認證模式誤觸
- A90 透過語音引導：進入管理員模式 →「系統管理 請按 4」→ 找到雙重認證選項按對應數字關閉（具體數字以機器當前語音播報為準）。

### 派工條件
- ❌ 已換新電池或鋰電池組充飽後仍持續低電量警報或無反應 → 派工檢查 IC 板。
- ❌ 鎖栓動作開著門就異常（伸不出、縮不回、卡頓）→ 派工。
- ❌ 受口片需調整、門框需重對 → 派工。
- ❌ 行動電源從 Type-C 緊急供電孔仍無反應 → 派工。
- ❌ APP 重新配對失敗、解除綁定後仍搜尋不到設備 → 派工檢查模組。
- ❌ 客戶遺失管理員密碼且無管理員辨識方式 → 派工協助執行恢復出廠設定。
- ❌ 貓眼蓋插不回、線材鬆脫無法接好 → 派工更換或調整。
