# Chatlock 品牌通用資訊

> 此文件收錄 Chatlock 跨型號的通用流程與品牌共通知識。當客戶**已知品牌為 Chatlock 但型號未確認**時，可作為主要參考；若客戶後續提供具體型號（A90 / AI-88 / AI-99），請改載入 `Chatlock/{Model}` 取得型號專屬步驟。

## 品牌國別

Chatlock 為**中國**品牌。

## 品牌與系列概述

Chatlock 智慧電子鎖目前主要型號為 **A90**、**AI-88**、**AI-99**：
- **AI-88 / AI-99**：圓形觸控螢幕＋貓眼鏡頭設計（同一條產品線設計理念），Wi-Fi 模組整合在內側螢幕內。
- **A90**：中階型號，**沒有圓形觸控螢幕**，全部設定皆透過外側數字鍵盤＋語音引導完成（按 `*#` 喚醒、輸入管理員密碼後依語音提示按 1~9 數字進入子選單）。

## APP / Wi-Fi 通用設定

### APP 名稱（重要）
Chatlock 全系列在 APP（iOS App Store / Google Play）中**統一搜尋名稱為「chatlock AI99」**——A90 與 AI-99 在 APP 添加設備清單裡都顯示「chatlock AI99」，這是正常情況，不是錯誤。

### Wi-Fi 限制
- **只支援 2.4G Wi-Fi**（5G 無法連線）。
- 設定時 APP 中輸入的 Wi-Fi 名稱與密碼必須與家中實際 Wi-Fi 完全一致（含大小寫）。

### 通用配對流程框架
1. 在電子鎖端進入管理員模式（A90: 數字鍵盤；AI-88/AI-99: 觸控螢幕選單）。
2. 進入網路設定 → 啟動連網模式（語音或畫面提示「網路配置中」/「請添加設備」）。
3. 手機 APP 點右上【+】或【添加設備】 → APP 自動搜尋到「chatlock AI99」。
4. 點【添加】→ 輸入家中 2.4G Wi-Fi 名稱與密碼 →【下一步】。
5. 等待門鎖叮咚一聲 → APP 顯示「添加成功」。

> ⚠️ 詳細按鍵步驟（A90 透過數字鍵盤按 5、AI-99 透過螢幕選單進入網路設定）依型號略有差異；確認型號後請載入 `Chatlock/{Model}` 取得正確按鍵流程。

## 跨型號設計重點

- **拆螢幕＝斷網**（限 AI-88 / AI-99）：Wi-Fi 模組整合在內側觸控螢幕內，若客戶反映「換過內側螢幕後 APP 斷線」屬於正常現象，需重新配對。
- **緊急供電**：全系列均有 **Type-C 緊急供電孔** + **隱藏式機械鑰匙孔**（外側下方圓形蓋體下）。沒電開不了門時可用行動電源接 Type-C 暫時供電，或用機械鑰匙開門。
- **電池**：A90 / AI-99 均為內側可拆卸式鋰電池模組，可整顆取出充電（不含 AI-88 確認狀態）。

## 通用故障警示

- **APP 顯示離線**：先確認家中 Wi-Fi 是否正常；2.4G 訊號是否到達門鎖位置；若內側螢幕近期被拆過（更換或維修）則 Wi-Fi 模組可能需重新配對。
- **辨識失靈（人臉 / 掌靜脈）**：紅燈未亮通常代表感應器斷電 / 線材鬆動；摸一下面板讓紅外線重新啟動是常見緊急解法。
- **客戶遺失全部管理者驗證方式**（密碼 / 指紋 / 卡片 / 人臉 / 掌靜脈全失效）需執行恢復出廠 → 一律派工，禁止指導客戶自行操作。

> 詳細故障排除請依型號載入對應 `Chatlock/{Model}` 文件，本文件僅提供品牌共通指引。

## 通用操作邏輯（型號未確認時的高階流程）

> 來源：歸納 A90 與 AI-99 兩型號的共通模式（AI-88 資料較稀，沿用 AI-99 邏輯）。**操作介面依型號分兩種**：A90 用數字鍵盤＋語音、AI-99 / AI-88 用內側觸控螢幕選單。確認型號後請載入 `Chatlock/{Model}` 取得精確操作。

### 共通三步驟（所有設定的核心模式）
1. **喚醒**
   - A90：觸碰外側面板（圓形指示燈亮藍）
   - AI-99 / AI-88：用手掌或手指輕觸內側圓形觸控螢幕
2. **進入管理員模式**
   - A90：按【*】→【#】 → 輸入管理員密碼 +【#】（指示燈轉綠）
   - AI-99：主畫面 →【選單】（部分需要管理員驗證才能進入特定子選單）
3. **選擇功能分支**
   - A90：依語音提示按 1~9 數字進入子選單（新增普通用戶 = 1、刪除 = 3、系統管理 = 4、連網 = 5）
   - AI-99：點觸控螢幕對應選單（用戶管理／網路設定／系統設定／記錄查詢）

### 通用新增使用者流程
> 共通邏輯：進入管理員模式 → 新增使用者 → 選辨識方式（密碼／指紋／卡片／人臉／掌靜脈）→ 採集／輸入 → 「註冊成功」提示。

| 辨識方式 | 採集要點（跨型號通用） |
|---|---|
| **密碼** | 輸入 6~12 位密碼 +【#】，再次輸入相同密碼 +【#】 |
| **指紋** | 將同一根手指放在指紋辨識區，依語音重複放入直到指示燈／螢幕顯示成功（約 4~5 次） |
| **卡片** | 將卡片貼於外側面板感應區（A90：數字【5】與【8】中間；AI-99：上方 NFC 區） |
| **人臉** | 注視外側鏡頭（A90：依語音；AI-99：站在鏡頭正前方約 60 公分） |
| **掌靜脈** | 手掌伸向外側鏡頭，距離 **15~30 公分**感應 |

### 通用刪除流程
- **A90**：管理員模式 → 按【3】（刪除用戶）→ 依語音選擇刪除方式（編號【1】最快、手指【2】、密碼【3】、卡片【4】、人臉【5】、掌靜脈【6】）
- **AI-99**：選單 →【用戶管理】→ 點該用戶 → 各辨識方式右側紅色垃圾桶刪除 → 全部刪光後才能從【用戶管理】刪除整個用戶

### 通用恢復出廠設定（資料全清）
- A90：管理員模式 → 系統管理（按 4）→ 恢復出廠（按 3）→【#】確認
- AI-99：選單 → 系統設定 → 恢復出廠 → 確認

> ⚠️ 恢復出廠後**所有用戶／辨識方式／APP 綁定皆會清除**，操作前須與客戶確認；客戶遺失管理員驗證時不指引自行操作，**直接派工**。

## 通用緊急開門 SOP（沒電 / 鎖死）

所有 Chatlock 型號的緊急開門設計**完全共通**：

### 機械鑰匙開門
1. 觀察外側下方圓形孔蓋，下壓蓋體向右轉開取下
2. 蓋下露出 **Type-C 充電孔**（左）與**鑰匙孔**（右）
3. 將備用鑰匙插入鑰匙孔，**順時針**轉動鎖芯解鎖

### 行動電源緊急供電
1. 打開同一個圓形孔蓋
2. 將 Type-C 線插入左側 Type-C 孔（任何行動電源即可）
3. 螢幕亮起、發出開機提示音
4. 用已註冊的指紋／密碼／卡片／人臉正常開門
5. 拔出 Type-C 線，將圓形孔蓋向左旋轉復位
6. **進到室內後務必更換／充電鋰電池**

### 鋰電池拆裝
- A90 / AI-99 內側為**可拆卸鋰電池**，可整顆取出充電：
  - 路徑 1：頂部貓眼蓋向上推取下 → 取出電池槽內鋰電池充電
  - 路徑 2（A90 替代）：內門下部把手位置卡縫 → 撬開內門蓋 → 黑色拉帶抽出電池
- AI-88 電池拆裝方式同一系列邏輯，細節以實機標示為準

## 通用故障排除

### 紅燈未亮、走到門前不感應（人臉／掌靜脈）
- 全系列共有「**防回頭機制**」：上鎖完成後紅外線感應器約 20 秒冷卻，期間若有寵物／鄰居經過會啟動感應失敗再休眠
- 解法：
  - **臨時**：摸一下面板讓紅外線重新啟動
  - **永久**：A90 用語音引導進系統管理找「防回頭時間」；AI-99 走選單 → 系統設定 → 功能設定 → 防回頭時間（可選 5/10/15 秒或關閉）
- 集合式住宅或門前人流多時建議調短或關閉

### 一關門就嗶嗶警報叫（關鎖失敗）
- 警報源自鎖栓在自動上鎖時撞到受口片或門框
- 確認方式（A90）：開著門按外把手後方【上鎖】按鈕（按 0.5 秒放開），觀察鎖栓伸縮是否順暢
- 開著門上下鎖正常但一關門警報 → **受口片偏斜或門框內有異物**，需調整受口片
- 開著門就上鎖失敗 → 鎖體位置／門對齊問題，需技師處理

### 突然感應辨識失靈／APP 顯示離線
- 全系列 Wi-Fi 模組設計**整合在內側螢幕／貓眼蓋內**
- 若內側螢幕／貓眼蓋曾被拆開或未插到底，會導致 APP 離線（**正常現象**，需重新配對）
- 確認內側螢幕／貓眼蓋已重新插好、線材無鬆脫
- 仍離線：APP 清理緩存後重開 → 檢查家中 2.4G Wi-Fi 是否正常

### 雙重認證模式誤觸
- 客戶反映「原本一個方式可開，突然要兩種辨識才能開」表示誤啟雙重認證
- A90：管理員模式 → 系統管理（按 4）→ 找到雙重認證選項（具體數字以機器當前語音為準）→ 關閉
- AI-99：選單 → 系統設定 → 高級設定 → 雙重認證模式開關（關閉前需保留至少三種辨識方式）

## 派工條件（必派技師）

以下情境用通用 SOP 無法解決，須派技師到府：

- ❌ 已換新電池或鋰電池組充飽後仍持續低電量警報或無反應 → 派工檢查 IC 板
- ❌ 鎖栓**開著門狀態就異常**（伸不出、縮不回、卡頓）→ 派工
- ❌ 受口片需調整、門框需重對 → 派工
- ❌ 行動電源從 Type-C 緊急供電孔仍無反應 → 派工
- ❌ APP 重新配對失敗、解除綁定後仍搜尋不到設備 → 派工檢查模組
- ❌ 客戶**遺失管理員密碼且無管理員辨識方式**可用 → 派工協助恢復出廠（重置後機器需全部重新設定）
- ❌ 貓眼蓋插不回、線材鬆脫無法接好 → 派工更換或調整
- ❌ 客戶要求**恢復出廠設定**（不指引自行操作）
