# Kaadas 凱迪仕品牌通用資訊

> 此文件收錄 Kaadas 跨型號的通用品牌資訊。當客戶**已知品牌為 Kaadas 但型號未確認**時，可作為主要參考；若客戶後續提供具體型號（藍寶堅尼3D人臉辨識 / 藍寶堅尼門鈴款），請改載入 `Kaadas/{Model}` 取得型號專屬資訊。

## 品牌國別

Kaadas（凱迪仕）為**中國**品牌。本店販售的「藍寶堅尼」系列為 Kaadas 與 Lamborghini 授權合作款式。

## 系列概述

本店目前販售的 Kaadas 型號集中在「藍寶堅尼」授權系列：
- **藍寶堅尼3D人臉辨識**：以 3D 人臉辨識為主要解鎖方式
- **藍寶堅尼門鈴款**：搭配門鈴模組

## ⚠️ 資料狀態

目前 bronze 來源中**尚無 Kaadas 型號的官方影片字幕、文字資料或操作教學**。本品牌目前**沒有可信任的型號專屬按鍵步驟**。

**處理原則**：
1. **跨型號通用問題**（電池、Wi-Fi、門框、開門方向、緊急供電…）→ 載入 `_common/general-knowledge` 給通用解
2. **故障排查**（鎖打不開、鎖卡死、警報誤響…）→ 載入 `_common/troubleshoot` 走通用診斷流程
3. **派工 / 安裝 / 保固**問題 → 載入 `_common/dispatch`
4. **型號專屬按鍵步驟**（密碼登記、感應卡新增、解除雙重認證…）→ 站內無資料，請走 `transfer_to_human` 安排專員協助
5. **絕對不要**從訓練記憶編造 Kaadas 任何型號的具體操作步驟
