# Dormakaba ML770

## 產品概述

ML770 是四合一智慧電子鎖（密碼／卡片／指紋／機械鑰匙）。1 組管理者密碼（無法刪除僅能更改）、最多 10 組管理者卡片、4 組使用者密碼、100 組使用者卡片（一卡通／悠遊卡／RFID）、100 組使用者指紋（半導體模組）。電池為 8 顆 Panasonic 鹼性 AA。

## 操作步驟

### 電池安裝
1. 輕壓背蓋向上滑開。
2. 依槽內圖案放入 8 顆 Panasonic 鹼性 AA（正極朝上 / 正極朝上 / 負極朝上 / 負極朝上）。請勿使用他牌。
3. 蓋回背蓋。

### 管理者密碼註冊
1. 按背面【註冊】鍵。
2. 輸入【現有管理者密碼】+【#】。
3. 按【0】鍵。
4. 輸入新管理者密碼 6~12 位 +【#】完成。
> 管理者密碼僅能更改，無法刪除。

### 管理者卡片註冊（最多 10 組）
1. 按【註冊】→ 管理者密碼 + #。
2. 按【0】。
3. 輸入位址 1~10 + #（不指定可略）。
4. 感應【管理者卡片】+ #。

### 使用者密碼註冊
1. 按【註冊】→ 管理者密碼 + # 或感應管理者卡片。
2. 按【1】。
3. 輸入位址 1~4 + #（可略）。
4. 輸入使用者密碼 4~12 位 + #。

### 使用者卡片註冊（100 組）
1. 按【註冊】→ 管理者密碼/卡片。
2. 按【2】。
3. 輸入位址 1~100 + #（可略）。
4. 感應卡 + #（一卡通／悠遊卡／RFID 皆可）。

### 使用者指紋註冊（100 組）
1. 按【註冊】→ 管理者密碼/卡片。
2. 按【3】。
3. 輸入位址 1~100 + #（可略）。
4. 在指紋模組感應【3 次】+ #。上方數字會閃爍對應次數。

### 一次性密碼
1. 按【註冊】→ 管理者密碼/卡片。
2. 按【4】，輸入 6 位密碼 + #。
> 開門後即失效，一次只能設定一組。

### 各類刪除
進入刪除模式：長按背面【註冊】鍵約 3 秒，發出第二次提示音、面板二次閃爍。輸入管理者密碼+# 或感應管理者卡片，再操作：
- **管理者卡片單刪**：按【0】+ 輸入位址 +【*】，或直接感應該卡。
- **管理者卡片全刪**：按【0】後長按【#】3 秒。
- **使用者密碼單刪**：按【1】+ 輸入位址 +【*】。
- **使用者密碼全刪**：按【1】後長按【#】3 秒。
- **使用者卡片單刪**：按【2】+ 輸入位址 +【*】或感應卡刪除。
- **使用者卡片全刪**：按【2】後長按【#】3 秒。
- **使用者指紋單刪**：按【3】+ 輸入位址 +【*】。
- **使用者指紋全刪**：按【3】後長按【#】3 秒。

### 常開模式
1. 喚醒面板輸入管理者密碼 + 連按【*】兩次。
2. 按【4】：自動上鎖；按【7】：手動上鎖（手動模式關門請輕碰面板）。

### 內部反鎖
- 關門狀態下長按內部 CLOSE 鍵約 3 秒；外部面板將失效，轉動內部把手即可解除反鎖。

### 音量
- 喚醒面板輸入管理者密碼 +【*】，按【3】調高、按【6】調低、按【#】結束。

### 卡片設定（跨型號通用）
- **連續註冊**：按【註冊】→ 管理者密碼／卡片 → 按【2】→ 連續感應卡片 → 按【#】退出。
- **指定位址**：按【2】→ 輸入位址 1~100 → 按【#】→ 感應卡 → 按【#】。
- **單刪**：長按註冊鍵 5 秒（面板閃爍）→ 管理者密碼 → 按【2】→ 感應或輸入位址 → 按【*】。
- **全刪**：相同進入流程 → 按【2】後長按【#】3 秒。

### 背蓋與電池
- 輕壓背蓋向上滑開取下；蓋回滑下推合。電池槽 8 顆 Panasonic 鹼性 AA。

### APP / 藍牙遠端金鑰
- 掃描背面 QR Code 下載 SmartLocky APP，允許藍牙與定位。
- 添加智能門鎖 → 輸入序號等資訊 → 開始配對 → 聽提示音後按電子鎖【註冊】鍵綁定。
- 共享密鑰可生成有效期一次性密碼分享給訪客；僅第一支綁定手機具管理權。

## 故障排除

### 鎖舌卡住（門打不開）
Dormakaba 鎖舌為擺動式（前後／左右）：
- 拉門：先把門推緊再拉把手。
- 推門：先拉住把手把門拉緊再用力推。
- 外部解鎖後立刻推或拉，不要遲疑。

### 雙重認證誤觸
- 驗證：「密碼+#」後立刻感應卡片或按指紋，能開即代表已啟用雙重認證。
- 解除：開門狀態下按一次內側 CLOSE 讓鎖栓伸出，喚醒面板輸入管理者密碼+【*】一次，再按【8】解除（按【5】開啟）。

### 鎖栓測試
1. 開門狀態按一次 CLOSE/OPEN，鎖栓應能正常伸縮 → 鎖體沒問題。
2. 一關門就上鎖失敗 → 受口片偏斜或內有異物，需檢查門框受口片。
3. 解鎖失敗：鎖栓伸出時卡到受口片，需對位。

### 派工條件
- ❌ 管理者密碼與管理者卡片皆遺失，需初始化 → 派工
- ❌ 紅燈閃 4 次（馬達異常）→ 派工
- ❌ 恢復出廠設定 → 派工
- ❌ 受口片需調整 → 派工
