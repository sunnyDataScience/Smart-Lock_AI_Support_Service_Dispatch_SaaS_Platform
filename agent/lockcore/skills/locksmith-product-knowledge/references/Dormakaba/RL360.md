# Dormakaba RL360

## 產品概述

RL360 是三合一智慧輔助電子鎖（密碼／卡片／指紋）。觸控面板支援 4 組密碼（含圖形解鎖）、感應卡 100 組（一卡通／悠遊卡／RFID）、指紋 100 組。室內側手動旋鈕可快速上鎖／解鎖；底部具 9V 電池接觸點作為緊急供電解鎖。電池槽 4 顆 AA。

## 操作步驟

### 管理者密碼註冊
1. 推開電池背蓋，按下【註冊】鍵。
2. 輸入初始密碼【123456】+【#】。
3. 按【0】鍵。
4. 輸入新管理者密碼 6~12 位 +【#】完成。

> 請在開門狀態下註冊。

### 密碼註冊（最多 4 組）
1. 按下內門【註冊】鍵。
2. 輸入管理者密碼 +【#】。
3. 按【1】鍵。
4. 輸入使用者密碼 4~12 位 +【#】確認。

### 卡片註冊（最多 100 組）
1. 按【註冊】鍵。
2. 輸入管理者密碼 +【#】。
3. 按【2】鍵。
4. 將 RFID 卡接觸感應區後按【#】。

### 指紋註冊（最多 100 組）
1. 按【註冊】鍵。
2. 輸入管理者密碼 +【#】。
3. 按【3】鍵。
4. 將手指放在指紋掃描器上【3 次】（每次燈光閃爍提示）+【#】。

### 一次性密碼
1. 按【註冊】鍵。
2. 輸入管理者密碼 +【#】。
3. 按【4】鍵。
4. 輸入一次性密碼 4~12 位 +【#】。

### 緊急充電解鎖
- 將 9V 電池接觸電子鎖底部的兩個充電接點，觸控面板亮起後輸入密碼解鎖。

### 室內手動旋鈕
- 旋鈕中央按鈕按下後旋轉，鎖栓動作完成上鎖／解鎖。

### 刪除設定（密碼／卡片／指紋）
1. 推開背蓋，按【註冊】鍵約 5 秒（提示音）。
2. 輸入管理者密碼 +【#】。
3. 輸入欲刪除類型 +【#】（指紋按【*】）並壓住約 3 秒：
   - 【1】：刪除密碼
   - 【2】：刪除卡片
   - 【3】：刪除指紋

### 卡片設定（跨型號通用）
- **連續註冊**：按【註冊】→ 管理者密碼／卡片 → 按【2】→ 連續感應卡片 → 按【#】退出。
- **指定位址**：按【2】→ 輸入位址 1~100 → 按【#】→ 感應卡 → 按【#】。
- **單刪**：長按註冊鍵 5 秒（面板閃爍）→ 管理者密碼 → 按【2】→ 感應或輸入位址 → 按【*】。
- **全刪**：相同進入流程 → 按【2】後長按【#】3 秒。

### 背蓋與電池更換
- RL360 背蓋向上推取下；電池槽 4 顆 AA（建議 Panasonic 鹼性）。

### APP / 藍牙遠端金鑰
- 掃描電子鎖背面 QR Code 下載 SmartLocky APP，允許藍牙與定位。
- 添加智能門鎖 → 輸入序號等資訊 → 開始配對 → 聽提示音後按電子鎖【註冊】鍵綁定。
- 共享密鑰可生成有效期一次性密碼分享給訪客。

## 故障排除

### 鎖舌卡住（門打不開）
Dormakaba 鎖舌為擺動式（前後／左右），不是伸縮式：
- 拉門：先把門推緊到底再拉把手。
- 推門：先拉住把手把門拉緊，再用力推。
- 外部解鎖後立刻推或拉，不要遲疑。

### 雙重認證誤觸
- 驗證：「密碼+#」後立刻感應卡片或按指紋，能開即代表已啟用雙重認證。
- 解除：開門狀態下按一次內側按鈕讓鎖栓伸出，喚醒面板輸入管理者密碼+【*】一次，再按【8】解除（按【5】開啟）。

### 鎖栓測試
1. 開門狀態按一次內部按鈕／旋鈕，鎖栓應能正常伸縮 → 鎖體沒問題。
2. 一關門就上鎖失敗 → 受口片偏斜或內有異物，需檢查門框受口片。
3. 解鎖失敗：鎖栓伸出時卡到受口片，需對位。

### 派工條件
- ❌ 管理者密碼遺失，需初始化 → 派工
- ❌ 紅燈閃 4 次（馬達異常）→ 派工
- ❌ 恢復出廠設定 → 派工
- ❌ 受口片需調整 → 派工
