# 汽車鑰匙服務

## 服務範圍

### 汽車晶片鑰匙複製
- **特徵**: 適用於具備晶片防盜功能的汽車鑰匙。
- **限制**:
    - 需有原廠可正常使用的遙控器才能複製。若無，則無法處理。
    - 部分特殊車款（如VW）因需要特定設備，無法處理。
    - 部分車款（如Nissan March）需開車到店進行測試。
    - 部分車款（如2012 Toyota Camry）若選擇副廠款式，部分功能（如尋車）可能無法使用。
- **流程**:
    1. 客戶提供汽車品牌、型號、年份及鑰匙照片。
    2. 客服初步評估並告知是否需要到店測試。
    3. 到店後，使用機器測試晶片與頻率。
    4. 根據測試結果與客戶需求，提供原廠或副廠鑰匙選項及報價。
    5. 客戶確認後，進行製作。
    6. 製作完成後，進行車輛設定。
- **派工判斷**:
    - 若車輛無法移動（如被扣牌），可安排師傅到社區停車場進行設定。
    - 若客戶僅需複製鑰匙，可到店處理。

### 汽車鑰匙電池更換
- **特徵**: 更換汽車遙控器電池。
- **限制**: 部分遙控器電池有焊點，需看到實體才能評估是否可更換。
- **流程**:
    1. 客戶提供遙控器照片及電池更換頻率。
    2. 建議客戶到店測試，確認是否為電池問題。
    3. 到店後，進行電池更換。
- **到店判斷**: 建議客戶到店處理，以便現場測試與更換。

### 機車鑰匙複製
- **特徵**: 複製機車鑰匙。
- **限制**:
    - 部分特殊車款（如CBR150 2020年款）無法提供「無中生有」的服務。
    - 鑰匙類型若非一般鑰匙（如卡巴鎖），需由老闆處理。
- **流程**:
    1. 客戶提供機車品牌、型號、年份及鑰匙照片。
    2. 客服初步評估。
    3. 客戶到店進行複製。
- **到店判斷**: 建議客戶到店處理。

### 機車鑰匙遺失開鎖與製作
- **特徵**: 處理機車鑰匙遺失，包含開鎖及製作新鑰匙。
- **限制**:
    - 若龍頭或鑰匙蓋有鎖住，需額外評估。
    - 部分車款無法提供「無中生有」的服務。
- **流程**:
    1. 客戶提供機車品牌、型號、地點。
    2. 確認龍頭與鑰匙蓋是否鎖住。
    3. 師傅到場進行開鎖。
    4. 製作新鑰匙。
- **派工判斷**: 需派師傅到客戶指定地點處理。

### 汽車鑰匙外殼更換/折疊鑰匙改裝
- **特徵**: 更換破損的鑰匙外殼，或將傳統鑰匙改裝為折疊式。
- **限制**:
    - 部分折疊鑰匙需整個換殼，因鑰匙與殼一體成形。
    - 內部晶片需移植到新殼。
    - 需到店測試才能確認是否可改裝為折疊鑰匙。
    - 外殼料件可能缺貨，需先確認庫存。
- **流程**:
    1. 客戶提供鑰匙照片。
    2. 客服評估是否可更換外殼或改裝。
    3. 確認料件庫存。
    4. 客戶到店進行處理。
- **到店判斷**: 需客戶到店處理，以便測試與製作。

## 規格與選項

### 汽車晶片鑰匙
- **外觀**:
    - 原廠型
    - 副廠型 (外觀可能與原廠不同)
- **功能**:
    - 完整功能 (包含尋車等)
    - 部分功能 (如副廠鑰匙可能無尋車功能)

### 機車鑰匙
- **類型**: 一般鑰匙、卡巴鎖鑰匙

## 作業流程

### 汽車晶片鑰匙複製
1. **客戶詢問**: 客戶提供車輛資訊（品牌、型號、年份）及鑰匙照片。
2. **初步評估**: 客服根據資訊判斷是否可處理及初步報價。
3. **到店測試**: 客戶開車攜帶鑰匙到店，使用機器測試晶片頻率。
4. **確認款式與報價**: 根據測試結果與客戶需求，提供原廠/副廠選項及最終報價。
5. **下單製作**: 客戶確認後，若需調貨則進行調貨。
6. **製作與設定**: 鑰匙製作完成後，進行車輛設定。
7. **交付**: 客戶取走新鑰匙。

### 機車鑰匙遺失開鎖與製作
1. **客戶詢問**: 客戶提供機車資訊（品牌、型號）及地點。
2. **確認狀況**: 客服詢問龍頭與鑰匙蓋是否鎖住。
3. **安排派工**: 師傅前往客戶指定地點。
4. **現場處理**: 師傅進行開鎖並製作新鑰匙。
5. **交付**: 現場交付新鑰匙。

## 時程

### 汽車晶片鑰匙複製
- **製作時間**: 約15-30分鐘（若料件齊全）。
- **調貨時間**: 若需調貨，時間不確定，需等廠商回覆。

### 機車鑰匙複製
- **製作時間**: 依鑰匙類型而定，一般鑰匙可快速複製。特殊鑰匙（如卡巴鎖）需老闆處理，時間較長。

## 派工 / 到店 / 自取判斷

### 派工觸發
- **機車鑰匙遺失**: 需到客戶指定地點進行開鎖與製作。
- **汽車晶片鑰匙設定**: 若車輛無法移動（如被扣牌），可派師傅到車輛所在地進行設定。

### 到店觸發
- **汽車晶片鑰匙複製**: 需將車輛開到店內進行晶片與頻率測試及設定。
- **汽車鑰匙電池更換**: 建議到店測試與更換。
- **機車鑰匙複製**: 建議到店處理。
- **汽車鑰匙外殼更換/折疊鑰匙改裝**: 需到店測試與製作。
- **車道遙控器拷貝**: 需到店使用機器測試，判斷是否可拷貝及設定。

## 不接受的服務
- **VW車款晶片鑰匙複製**: 因需要特定設備，無法處理。
- **CBR150 2020年款機車鑰匙「無中生有」**: 無法提供此服務。
- **無原廠可正常使用遙控器之汽車晶片鑰匙複製**: 無法處理。
- **跨區代工安裝電子鎖**: 若客戶自行購買電子鎖，且地址非林口地區，原則上不提供代工服務，除非客戶願意支付車馬費且接受現場無法安裝的風險。

## 常見誤解 / 客戶常忽略的細節
- **遙控器無法解鎖不一定是遙控器問題**: 若遙控器仍能上鎖與解鎖，則可能不是遙控器本身問題。
- **汽車晶片鑰匙複製需有原廠鑰匙**: 客戶常以為無鑰匙也能複製，但通常需要一顆正常鑰匙才能進行拷貝。
- **副廠鑰匙功能可能不完整**: 客戶選擇副廠鑰匙時，需注意部分功能（如尋車）可能無法使用。
- **鑰匙外殼與晶片分離**: 客戶常以為鑰匙與外殼是獨立的，但部分折疊鑰匙是鑰匙與殼一體成形，更換時需整個換殼並移植晶片。
- **車道遙控器拷貝限制**: 客戶常以為所有車道遙控器都能拷貝，但部分社區系統有加密或主機鎖死，無法拷貝或需社區管理員設定。
- **跨區代工風險**: 客戶自行購買電子鎖要求跨區代工時，需理解現場可能因尺寸不合或配件不足導致無法安裝，並需支付車馬費。
