# 門鎖五金服務

## 服務範圍

### 傳統鎖更換/維修
- **特徵**: 包含喇叭鎖、水平把手鎖、輔助鎖、連體鎖、抽屜鎖、信箱鎖等。
- **流程要點**:
    1. 客戶提供舊鎖照片及門扇照片。
    2. 測量門厚、鎖體長寬、鎖芯距離等關鍵尺寸。
    3. 評估是否可維修或需更換。
    4. 若更換，提供可替代款式及報價。
    5. 預約安裝時間。
- **限制**:
    - 特殊規格（如日規、進口防盜鎖、鋁門窗特規鎖）可能需叫貨或現場修改，且款式選擇較少。
    - 部分老舊或特規鎖可能無現貨或無法找到完全相符的替代品，需接受現場修改或外觀差異。
    - 房門喇叭鎖故障打不開，通常需破壞性開鎖。
    - 遺失鑰匙需配鎖，需將鎖拆回店內配置。

### 電子鎖安裝
- **特徵**: 包含電子把手、電子輔助鎖、推拉式電子鎖等。
- **流程要點**:
    1. 客戶提供門扇照片、門厚、內外門間距、舊鎖照片及尺寸。
    2. 評估門扇是否適合安裝電子鎖（如防火門、玻璃門、門扇厚度、內外門間距）。
    3. 根據客戶需求（功能、預算、品牌、外型）推薦合適款式。
    4. 預約安裝時間。
- **限制**:
    - 門扇厚度、內外門間距是重要評估依據。
    - 玻璃門可能無法安裝普通電子鎖，需考慮磁吸門鎖或其他解決方案。
    - 防火門及部分特殊門扇可能限制電子鎖款式。
    - 安裝電子鎖通常會重新鑽孔或挖洞，但會確保舊鎖裝回後可遮蔽施工痕跡。
    - 代工安裝客戶自備電子鎖，僅提供安裝服務，不負責後續保固、機台問題及使用教學。

### 開鎖服務
- **特徵**: 針對傳統鎖或電子鎖無法開啟的狀況。
- **流程要點**:
    1. 客戶說明鎖的狀況及類型。
    2. 評估開鎖方式（非破壞性或破壞性）。
    3. 預約開鎖時間。
- **限制**:
    - 傳統鎖故障打不開，可能需破壞性開鎖。
    - 電子鎖沒電可使用9V電池或USB緊急供電，或使用備用鑰匙。

## 規格與選項

### 鎖具類型
- **傳統鎖**:
    - 喇叭鎖 (圓形轉開式)
    - 水平把手鎖 (L型下壓式)
    - 輔助鎖 (上方插鑰匙的鎖)
    - 連體鎖 (把手與鎖體一體)
    - 抽屜鎖
    - 信箱鎖
    - 葫蘆鎖芯 (僅更換鎖芯)
    - 反扣鎖/鏈條鎖 (加裝於內門)
- **電子鎖**:
    - 電子把手 (取代原有把手，自動空轉上鎖，可保留上方傳統鎖)
    - 電子輔助鎖 (安裝於門上方，保留原有把手，功能較基本)
    - 推拉式電子鎖 (整組更換，通常可遮蔽原有孔洞)
    - 把手式電子鎖 (整組更換，部分款式可能需加購遮飾板)

### 電子鎖功能
- **基本功能**: 密碼、卡片、指紋、鑰匙。
- **進階功能**: 藍芽、遠端連線（需加購模組）。
- **品牌**:
    - **Milre美樂**: 設定簡單、CP值高、指紋辨識靈敏，適合長輩及孩童。
    - **Philips飛利浦**: 外型質感佳、專利全自動鎖體、C級鎖芯，部分型號標配藍芽或遠端。
    - **dormakaba多瑪凱拔**: 德國/瑞士百年品牌，品質要求高，大氣沉穩外觀。
    - **小島鎖TX**: 功能最齊全，包含指紋、密碼、卡片、鑰匙、人臉辨識、掌靜脈、完整遠端功能。

### 遮飾板
- **金屬製**: 用於Milre，一片(具體費用請洽真人客服)，兩片(具體費用請洽真人客服)。
- **壓克力製**: 用於Waferlock，一片(具體費用請洽真人客服)，兩片(具體費用請洽真人客服)。
- **鐵圓板**: 一片(具體費用請洽真人客服)。
- **備註**: 遮飾板種類依廠商規格不同，無法共用。是否需要使用需現場拆鎖後評估。

### 鎖具顏色
- **傳統鎖**: 銀色、黑色、金色、古銅色 (依款式而異，部分特規鎖顏色選擇少)。
- **電子鎖**: 黑色、銀色 (依款式而異)。

## 作業流程

1. **客戶詢問**: 客戶透過LINE提出需求。
2. **資訊提供**: 客戶需提供門鎖及門扇照片，並依指示測量相關尺寸（門厚、鎖體長寬、鎖芯距離、內外門間距等）。
3. **評估與報價**: 技師根據客戶提供的資訊評估可行性、推薦款式，並提供報價。
4. **預約安裝**: 客戶確認報價後，預約安裝時間。
5. **料件準備**: 技師調貨或準備所需料件。
6. **現場施工**: 技師依約前往現場進行安裝或維修。
7. **驗收與付款**: 施工完成後，客戶現場驗收並付款（現金或轉帳）。

## 時程

- **傳統鎖更換/維修**:
    - 一般更換: 1小時以內。
    - 特殊叫貨: 3個工作天。
- **電子鎖安裝**:
    - 安裝時間: 約1小時。
    - 教學時間: 約30分鐘。
- **印章製作**:
    - 一般印章: 最快隔日可取貨。
    - 連續章: 2個工作天。
    - 特殊印章/大量訂製: 依廠商回覆時間而定。

## 派工 / 到店 / 自取判斷

- **派工觸發**:
    - 門鎖故障無法自行處理。
    - 需更換/安裝門鎖或電子鎖。
    - 需現場評估、測量、報價。
    - 跨區服務需額外評估，並可能收取車馬費。
- **到店觸發**:
    - 遺失鑰匙需配鎖 (需將鎖拆回店內)。
    - 刻印章 (可現場討論款式、字體)。
    - 拷貝磁扣/磁貼 (需攜帶原卡片)。
    - 購買鎖具材料 (不含安裝)。
- **自取觸發**:
    - 已完成的印章。
    - 已叫貨的鎖具材料。

## 不接受的服務

- **電子鎖代工安裝**: 不受理客戶自備電子鎖的後續保固、機台問題及使用教學。
- **跨區代工安裝**: 若客戶自備鎖具，因現場狀況多變，跨區代工安裝風險高，除非客戶願意支付車馬費且接受無法安裝的可能。
- **未提供足夠資訊的報價**: 無法在未提供照片、尺寸等關鍵資訊的情況下提供精準報價。
- **議價技師工資**: 技師工資為固定費用，不接受議價。
- **急件服務**: 人力有限，無法承接急件。

## 常見誤解 / 客戶常忽略的細節

- **鎖具尺寸的重要性**: 門鎖規格眾多，即使是1公分的誤差也可能導致無法安裝。務必依照指示提供精準測量數據。
- **日規/特規鎖的限制**: 客戶常以為所有鎖具都可通用或有大量替代品，但日規、進口防盜鎖或鋁門窗特規鎖選擇較少，可能需接受外觀差異或現場修改。
- **電子鎖的安裝條件**: 門扇厚度、內外門間距、門框材質等都會影響電子鎖的安裝可行性及款式選擇。
- **電子鎖的鑰匙功能**: 客戶常擔心電子鎖沒電無法開啟，但大部分電子鎖都配有備用鑰匙，且可透過9V電池或USB緊急供電。
- **電子鎖的售後服務**: 客戶自備電子鎖進行代工安裝，後續的保固和維修問題需自行聯繫原廠或賣家。
- **傳統鎖的「自動鎖」**: 客戶常誤以為關門即上鎖的鎖是自動鎖，但多數傳統鎖關門後仍需手動反鎖，部分可能是把手空轉功能。
- **印章製作的字體與尺寸**: 小尺寸印章若選擇複雜字體，蓋印效果可能模糊，建議選擇較細的字體。連續章殼的顏色選擇有限。
- **磁扣拷貝**: 磁扣有不同規格（如IC），需確認客戶磁扣類型是否與店家提供的磁貼相符。
- **門鎖維修與更換的區別**: 把手斷裂可能僅需更換把手，但若內部卡榫損壞則需整組更換。
- **施工聲響**: 安裝門鎖（特別是電子鎖）可能產生鑽孔聲響，若在社區內施工，建議事先向管委會報備。
