# 3E 小島快鎖品牌通用資訊

> 此文件收錄 3E 小島快鎖跨型號的通用流程與品牌共通知識。當客戶**已知品牌為 3E（小島快鎖）但型號未確認**時，可作為主要參考；若客戶後續提供具體型號（F(T7) / TX），請改載入 `3E/{Model}` 取得型號專屬步驟。

## 品牌國別

3E（小島快鎖）為**台灣**品牌。

## 品牌與系列概述

3E 小島快鎖目前主要型號為 **F(T7)**（年度銷售冠軍／主力推拉式）與 **TX**（「大內高手」系列觸控螢幕＋雙貓眼鏡頭）：
- **F(T7)**：推拉式智慧電子鎖，**直立式 / 橫式兩種安裝方向**（拆裝方式不同，需先確認）。IP55 防水、4 顆 3 號鹼性電池（AA）。
- **TX**：觸控螢幕＋雙貓眼鏡頭設計，支援 3D 人臉辨識、AI 掌靜脈、指紋、IC 卡（含悠遊卡 / 一卡通）、密碼、APP 遠端、OTP / 限時密碼。

## APP / Wi-Fi 通用設定

### Wi-Fi 限制
- **只支援 2.4G Wi-Fi**（5G 無法連線）。
- 手機在配對前必須**先連結家中 2.4G Wi-Fi**；APP 中輸入的 Wi-Fi 密碼必須完全正確（密碼錯誤會無法連線）。

### 通用配對流程框架
1. 從 iOS App Store / Google Play 下載 3E 對應 APP。
2. 喚醒門鎖面板，進入管理員驗證（依型號略有差異）。
3. 進入網路設定模式：
   - F(T7)：輸入【8】、【#】驗證管理員。
   - TX：按【*】、【#】輸入管理員密碼後，依語音按【5】進入網路設置。
4. 在 APP 點右上【+】或【新增裝置】 → 輸入家中 2.4G Wi-Fi 密碼 → 等待連線。
5. 門鎖語音「設置成功」/「操作成功」 + 底部亮綠燈 → APP 顯示綁定完成。

> ⚠️ 詳細按鍵流程依型號略有差異，確認型號後請載入 `3E/{Model}` 取得正確按鍵步驟。

## 跨型號設計重點

- **緊急供電**：全系列均有 **Type-C 緊急供電孔**（位於外側下方隱藏蓋體下，與機械鑰匙孔同一蓋）。沒電開不了門時可用行動電源接 Type-C 暫時供電，或用機械鑰匙開門。
- **受口盒對位（自動上鎖關鍵）**：機器上的三角形感應器必須壓入受口盒至少一半，才能觸發自動上鎖。若關門後不會自動上鎖、或一關門就嗶嗶警報，多半是受口盒對位不準（過鬆需加墊片，特殊規格門框需另購配件）。
- **安裝方向（限 F(T7)）**：直立式與橫式在「線材繞行方向」「室內機安裝順序」上有差異——客戶詢問安裝相關問題時，需先確認自家機器是哪一種方向。

## 通用故障警示

- **一關門就警報叫**：通常是受口盒對位不準導致關鎖失敗 → 檢查門扇關到底位置 / 受口盒高度。
- **室內按鈕無法解鎖**：常見於電池電量不足或內機線路鬆動。
- **APP 找不到裝置**：手機 Wi-Fi 是否為 2.4G？門鎖是否仍在連網模式？密碼是否輸對？
- **換電池後仍立刻沒電 / 反覆警報**：可能電池接觸不良或主板異常 → 派工。

> 詳細故障排除請依型號載入對應 `3E/{Model}` 文件，本文件僅提供品牌共通指引。

## 通用操作邏輯（型號未確認時的高階流程）

> 來源：歸納 F(T7) 與 TX 兩型號的共通模式。**按鍵編號依型號略有不同**，本段提供高階流程；確認型號後請載入 `3E/{Model}` 取得精確按鍵。

### 共通三步驟（所有設定的核心模式）
1. **喚醒螢幕／面板**
   - F(T7)：觸碰螢幕喚醒
   - TX：手掌靠近螢幕喚醒（顯示數字鍵盤）
2. **進入管理員模式**（驗證管理者）
   - F(T7)：輸入【1】、【#】 → 預設密碼【123456】、【#】（首次使用必須改）→ 修改後用新管理員密碼
   - TX：按【*】、【#】 → 輸入管理員密碼 +【#】
3. **選擇功能模式**（依語音提示）
   - 新增使用者：F(T7) 走「用戶設置」分支；TX 按【1】
   - 刪除使用者：TX 按【3】
   - 系統設置：F(T7) 按【2】；TX 按【4】

### 通用新增使用者流程
> 共通邏輯：進入管理員模式 → 進入「新增使用者」分支 → 選擇辨識方式（指紋／密碼／卡片／人臉／掌靜脈）→ 採集／輸入 → 完成提示。

各辨識方式採集要點：
- **指紋**：將同一根手指放置感應區，依語音「請移開，再放一次」重複 4~5 次直到綠燈／成功提示
- **密碼**：輸入新密碼 +【#】，依語音再次輸入相同密碼確認 +【#】
- **卡片**：將 RFID／悠遊卡／一卡通靠近數字鍵盤中央或 CARD 感應區
- **人臉**（限 TX）：注視鏡頭，與螢幕保持「一個手臂的距離」直到圓圈轉綠
- **掌靜脈**（限 TX）：手掌對準鏡頭，距離 15~30 公分

### 通用刪除流程（限 TX 已知；F(T7) 走相同邏輯但按鍵分支不同）
1. 進入管理員模式
2. 進入「刪除使用者」分支
3. 依語音提示選擇刪除方式（編號刪除最快，記得編號即可）

### 通用 APP / Wi-Fi 配對總結
- 詳細步驟見上方「APP / Wi-Fi 通用設定」段
- 共通限制：**只支援 2.4G Wi-Fi**；手機配對前需先連 2.4G；密碼必須完全正確
- 配對失敗：先在 APP 解除綁定後再重綁

## 通用緊急開門 SOP（沒電 / 鎖死）

所有 3E 型號的緊急開門設計**完全共通**：

### 機械鑰匙開門
1. 打開外側下方圓形隱藏蓋（F(T7) 直接下壓；TX 下壓下緣讓蓋體上方彈出）
2. 露出**鑰匙孔**（與 Type-C 緊急供電孔同蓋）
3. 將實體鑰匙插入並**順時針轉到底**解鎖
4. 反向轉到底上鎖
5. 取出鑰匙、蓋回蓋板

### 行動電源緊急供電
1. 打開同一個圓形蓋，露出 **Type-C 緊急供電孔**
2. 插入行動電源 Type-C 充電線
3. 螢幕亮起 → 語音「正在更新本地時間」→「操作成功」
4. 用已註冊的指紋／密碼／卡片正常解鎖
5. 進到室內後**務必立刻更換電池**

## 通用故障排除

### 一關門就警報（關鎖失敗）
- 源自鎖栓在自動上鎖時撞到受口片或門框
- 確認方式：開著門狀態下按一下室內按鈕，觀察鎖栓伸縮是否順暢
- 開著門上下鎖正常但一關門警報 → **受口盒未對齊或感應器壓入深度不足**，需重新調整受口盒位置或加墊片
- 受口盒設計要求：機器上三角形感應器必須**壓入受口盒至少一半**才能觸發上鎖

### 防撬警報誤響（限 F(T7) 已知，TX 走相同邏輯）
- 室外機紅色防撬開關必須貼合門板平面才不會觸發
- 安裝面有縫隙或膠墊未壓緊 → 持續誤觸發，需重新安裝室外機

### 室內按鈕無法解鎖
- 室內按鈕設計為「按壓 0.5~1 秒」才會作動（避免寵物 / 幼童誤觸）
- **連續短按或長按不放皆不會開鎖**，請以中等時長單次按壓
- 仍無法開鎖 → 改用室內手動旋鈕（先按壓再旋轉）

### 換電池後仍立刻沒電 / 反覆警報
- F(T7) 必須使用 **4 顆全新 3 號鹼性電池（AA）**；不可混用新舊或非鹼性
- TX 內建可充電電池（從室內貓眼蓋拆出充電）
- 換正確電池仍復發 → **派工檢查 IC 板**

### APP 找不到裝置 / 連線失敗
- 確認手機已連到家中 **2.4G Wi-Fi**（不是 5G）
- 門鎖端重新進入網路配置模式
- 配對途中失敗 → 先在 APP **解除綁定後再重綁**

## 派工條件（必派技師）

以下情境用通用 SOP 無法解決，須派技師到府：

- ❌ 已換正確電池仍持續低電量警報或無反應 → 派工檢查 IC 板
- ❌ 鎖栓**開著門狀態就異常**（伸不出、縮不回、卡頓）→ 派工
- ❌ 受口盒位置／感應器深度需調整、特殊規格門框需另購配件 → 派工
- ❌ 防撬警報持續誤響、室外機需重新安裝 → 派工
- ❌ 行動電源從 Type-C 緊急供電孔仍無反應 → 派工
- ❌ APP 重新配對失敗、解除綁定後仍搜尋不到設備 → 派工檢查模組
- ❌ 客戶**遺失管理員密碼且無備用辨識方式可用** → 派工協助執行恢復出廠設定（重置後機器需全部重新設定）
- ❌ 主軸需重新裁切、線材需重接、室內貓眼蓋插不回 → 派工
