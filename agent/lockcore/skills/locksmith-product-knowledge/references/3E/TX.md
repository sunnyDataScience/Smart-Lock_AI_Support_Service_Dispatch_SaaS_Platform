# 3E TX

## 產品概述

3E 小島快鎖 TX（「大內高手」系列）為含觸控螢幕＋雙貓眼鏡頭設計的智慧電子鎖。支援多種解鎖方式：3D 人臉辨識、AI 掌靜脈、指紋、IC 感應卡（含悠遊卡 / 一卡通整合）、密碼、APP 遠端、一次性密碼（OTP）、限時密碼，以及實體鑰匙與 Type-C 緊急供電。具備室內與室外貓眼鏡頭可切換顯示、室內按壓式開門鈕（防寵物 / 幼童誤觸）、室內手動旋鈕與暗鎖。

## 操作步驟

### 喚醒螢幕（手掌喚醒）
1. 將手掌靠近門鎖螢幕。
2. 螢幕亮起，顯示數字鍵盤。

### 進入管理員模式
1. 喚醒螢幕。
2. 依序按【*】、【#】，門鎖提示「請輸入管理員密碼」。
3. 輸入管理員密碼後按【#】，圓圈亮綠燈表示驗證成功。

### 新增普通用戶
1. 進入管理員模式。
2. 按【1】（添加普通用戶）。
3. 依序設定該用戶的辨識方式：
   - 按【1】添加人臉。
   - 按【2】添加掌靜脈。
   - 按【3】添加指紋／卡片／密碼。

### 新增人臉辨識
1. 進入管理員模式 → 按【1】（添加普通用戶）→ 按【1】（添加人臉）。
2. 注視鏡頭，與螢幕保持「一個手臂的距離」。
3. 圓圈轉綠 → 顯示「註冊成功」。

### 新增掌靜脈
1. 進入管理員模式 → 按【1】→ 按【2】。
2. 將手掌對準鏡頭，距離 15~30 公分。
3. 圓圈轉綠 → 顯示「添加成功」。

### 新增指紋
1. 進入管理員模式 → 按【1】→ 按【3】（添加指紋／卡片／密碼）。
2. 將手指放置感應處，重複「抬起放下」直到綠燈亮起。

### 新增密碼
1. 進入管理員模式 → 按【1】→ 按【3】。
2. 輸入使用者密碼後按【#】。
3. 再次輸入相同密碼後按【#】→ 綠燈亮起 →「註冊成功」。

### 新增卡片
1. 進入管理員模式 → 按【1】→ 按【3】（卡片屬同一新增分支）。
2. 將卡片放在感應區（數字鍵盤中央）。
3. 綠燈亮起 →「註冊成功」。

### 刪除用戶
1. 進入管理員模式 → 按【3】（刪除用戶）。
2. 依語音提示選擇刪除方式：
   - 編號刪除：按【1】（記得編號最快）。
   - 指紋刪除：按【2】後感應該指紋。
   - 密碼刪除：按【3】。
   - 卡片刪除：按【4】後感應該卡片。
   - 人臉刪除：按【5】。
   - 掌靜脈刪除：按【6】。

### 系統設置（出廠設定／音量／語言／時間）
1. 進入管理員模式 → 按【4】（系統設置）。
2. 依語音提示選擇：
   - 開門功能：按【1】。
   - 防撬檢測：按【2】。
   - 恢復出廠設定：按【3】。
   - 語音音量：按【4】。
   - 語言設定：按【5】。
   - 時間設定：按【6】。

> 恢復出廠後所有用戶與辨識方式皆會清除。

### APP 綁定（網路配對）
1. 喚醒螢幕，按【*】、【#】 → 輸入管理員密碼 → 按【#】。
2. 依語音提示按【5】（網路設置） + 按【#】，門鎖顯示「網路配置中」。
3. 同步在手機 APP 點【新增裝置】（手機需先連結家中 2.4G Wi-Fi 並開啟藍牙），APP 自動搜尋到 TX。
4. 在 APP 輸入家中 Wi-Fi 密碼 → 等待連結。
5. 門鎖語音「設置成功」 → APP 顯示綁定完成。
6. 按【*】退出設定。

### 室內外貓眼鏡頭顯示切換
1. 按下門鎖螢幕下方的感應鈕。
2. 螢幕顯示「室外」即時畫面（含時間戳記）。
3. 雙按感應鈕關閉畫面。

### 室內貓眼蓋拆裝（拿出電池充電）
1. 將室內貓眼蓋向上推取下。
2. 取下電池進行充電。
3. 充飽後放回電池，將貓眼蓋向下蓋回。

### 室內上鎖／解鎖
- **室內按鈕解鎖**：按壓室內開門鈕 0.5~1 秒（避免寵物 / 幼童誤觸；連續短按或長按不放都不會開）。
- **手動旋鈕解鎖／上鎖**：先按壓再旋轉，旋轉方向決定上鎖或解鎖。
- **室內暗鎖**：轉動室內側下方的暗鎖旋鈕，鎖舌伸出。

### 鑰匙開門（沒電 / 緊急）
1. 觸碰外側下方的圓形蓋，下壓下緣，蓋體上方彈出後完全打開。
2. 蓋下露出 Type-C 緊急供電孔（左）與鑰匙孔（右）。
3. 將折疊鑰匙插入鑰匙孔。
4. 將鑰匙轉到底（順時針）解鎖。
5. 反方向轉到底上鎖。
6. 取出鑰匙後將孔蓋蓋回。

### 行動電源緊急供電
1. 將圓形蓋打開（同上）。
2. 將行動電源 Type-C 線插入緊急供電孔（位於機器下方）。
3. 螢幕亮起、語音「正在更新本地時間」「操作成功」。
4. 用已註冊的指紋／密碼／卡片等正常解鎖。
5. 進到室內後務必更換電池。

### 臨時密碼（APP 生成）
1. APP 主畫面點【臨時密碼】。
2. 選擇密碼類型：
   - 【限時】：設定生效時間 / 失效時間（生效後 24 小時內須至少使用一次，否則失效）。
   - 【單次】：有效期 6 小時，僅可使用一次。
   - 【清空】：在鎖上輸入後將刪除所有已使用過的限時密碼（24 小時內輸入有效）。
3. 設定密碼名稱（可選） → 系統自動產生 10 位數字臨時密碼。
4. 點【複製】按鈕 → 將密碼分享給訪客。

## 故障排除

### 通用症狀分流
3E 在 bronze 資料中**沒有專屬的故障排除文字稿**，請同時參考 `_common/troubleshoot` 進行通用症狀分流（鎖舌卡住／受口片偏斜／電池異常／APP 無法配對等）。下述為 TX 已知特定狀況的補充。

### 一關門就警報（關鎖失敗）
- 與所有自動上鎖型電子鎖相同，警報源自鎖栓在伸出時撞到受口片或門框。
- 確認方式：開著門用室內按壓鈕讓鎖栓伸縮一次，觀察是否順暢。
- 若開著門上下鎖正常但一關門警報 → 受口片偏斜或門框內有異物，需調整受口片或加墊片。
- 若開著門就上鎖失敗 → 鎖體與門體未對齊，需技師處理。

### 室內按鈕無法解鎖
- 室內按鈕設計為「按壓 0.5~1 秒」才會作動，避免寵物或幼童誤觸。
- 連續短按或長按不放皆不會開鎖，請以中等時長單次按壓。
- 若仍無法開鎖，改用室內手動旋鈕（先按壓再旋轉）。

### 螢幕／APP 不連線
- 確認手機已連結家中 2.4G 網路（不是 5G）。
- 重新進入管理員模式 → 按【5】重新配對。
- 若配對途中失敗，請先把當前 APP 中已綁定的同一台 TX 解除綁定後再重綁。

### 派工條件
- ❌ 已換新電池仍持續低電量警報或無反應 → 派工檢查 IC 板。
- ❌ 鎖栓開著門狀態就異常（伸不出、縮不回、卡頓）→ 派工。
- ❌ 受口片需調整、門框需重對 → 派工。
- ❌ 行動電源從 Type-C 緊急供電孔仍無反應 → 派工。
- ❌ APP 重新配對失敗、解除綁定後仍搜尋不到設備 → 派工檢查模組。
- ❌ 客戶遺失管理員密碼且無管理員辨識方式可用 → 派工協助執行恢復出廠設定。
- ❌ 室內貓眼蓋插不回、線材鬆脫無法接好 → 派工更換或調整。
