```
{序號}_{對話起始日}_{對話結束日}_{客戶暱稱}.csv
```

- **序號**：1 ~ 1942
- **日期格式**：`YYYYMMDD`
- **客戶暱稱**：LINE 顯示名稱（含個資，不納入 git）

## CSV 欄位結構

每個 CSV 檔案的前 4 行為 header：

```
帳號名稱,鎖市鎖印社｜LOCKsMART
時區,'+09:00
下載時間,YYYY/MM/DD HH:MM
傳送者類型,傳送者名稱,傳送日期,傳送時間,內容
```

從第 5 行起為訊息資料：

| 欄位 | 說明 | 範例 |
|------|------|------|
| 傳送者類型 | `Account`（店家）或 `User`（客戶） | `Account` |
| 傳送者名稱 | 系統功能名稱 或 客戶暱稱 | `自動回應訊息` |
| 傳送日期 | `YYYY/MM/DD` | `2024/08/20` |
| 傳送時間 | `HH:MM:SS` | `21:20:43` |
| 內容 | 訊息文字內容 | 文字 / 貼圖 / 圖片連結 |
