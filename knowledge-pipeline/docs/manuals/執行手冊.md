## 4. Silver → Skill（技能文件產出）

三步驟流程，所有資料源共用同一組腳本：

### Step 1：分類

將 Silver 文件分配到對應的 SKILL.md 技能。

```bash
# 全部資料源
python pipeline/silver_to_skill/classify_documents.py --verbose

# 只處理特定資料源
python pipeline/silver_to_skill/classify_documents.py --source video --verbose
python pipeline/silver_to_skill/classify_documents.py --source youtube --verbose
python pipeline/silver_to_skill/classify_documents.py --source line_chat --verbose
python pipeline/silver_to_skill/classify_documents.py --source website --verbose
python pipeline/silver_to_skill/classify_documents.py --source gdrive --verbose
```

產出：`storage/skill_drafts/classification.json`

### Step 2：產出草稿

根據分類結果，LLM 合併新知識到既有 SKILL.md 或建立新技能。

```bash
# 全部 skill
python pipeline/silver_to_skill/generate_drafts.py --verbose

# 只處理特定 skill
python pipeline/silver_to_skill/generate_drafts.py --skill ts-door-stuck --verbose

# 調整新 skill 最低 chunk 門檻（預設 3）
python pipeline/silver_to_skill/generate_drafts.py --min-chunks 5 --verbose
```

產出：`storage/skill_drafts/{skill-name}/SKILL.md.draft` + `diff.txt`

### Step 3：審核寫入

```bash
# 預覽所有草稿的 diff
python pipeline/silver_to_skill/approve_drafts.py --dry-run

# 預覽特定 skill
python pipeline/silver_to_skill/approve_drafts.py --skill ts-door-stuck --dry-run

# 詳細模式（顯示完整 diff 內容）
python pipeline/silver_to_skill/approve_drafts.py --dry-run --verbose

# 確認寫入（會自動備份既有 SKILL.md）
python pipeline/silver_to_skill/approve_drafts.py --confirm
```

寫入目標：`agent/skills/data/{skill-name}/SKILL.md`

## 常用旗標速查

| 旗標 | 適用腳本 | 說明 |
|------|---------|------|
| `--verbose` | 全部 | 顯示詳細處理進度 |
| `--file <名稱>` | raw_to_bronze, bronze_to_silver | 只處理單一檔案 |
| `--force` | raw_to_bronze, bronze_to_silver | 強制覆寫已存在的輸出 |
| `--source <名稱>` | classify_documents | 只分類特定資料源 |
| `--skill <名稱>` | generate_drafts, approve_drafts | 只處理特定 skill |
| `--min-chunks N` | generate_drafts | 新 skill 最低 chunk 門檻 |
| `--dry-run` | approve_drafts | 預覽 diff，不寫入 |
| `--confirm` | approve_drafts | 確認寫入（必須明確指定） |

## config.toml 參考

各 pipeline 的 LLM 設定：

```toml
[pipelines.video]
llm_provider = "vertexai"
llm_model = "gemini-2.5-flash"
temperature = 0.3

[pipelines.video_asr]
model_type = "medium"
fp16 = false

[pipelines.line_chat]
llm_provider = "vertexai"
llm_model = "gemini-2.5-flash"
temperature = 0.3

[pipelines.youtube_vision]
llm_provider = "vertexai"
llm_model = "gemini-2.5-flash"
temperature = 0.1

[pipelines.youtube_silver]
llm_provider = "vertexai"
llm_model = "gemini-2.5-flash"
temperature = 0.3

[pipelines.website]
llm_provider = "vertexai"
llm_model = "gemini-2.5-flash"
temperature = 0.3

[pipelines.silver_to_skill]
llm_provider = "vertexai"
llm_model = "gemini-2.5-flash"
temperature = 0.2
skills_dir = "../agent/skills/data"
drafts_dir = "storage/skill_drafts"
```
