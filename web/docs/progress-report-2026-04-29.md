## 5. 已知限制與未上線項

> **這些不是 bug，是設計上需依賴後續模組才能上線的功能。**前端版面已預留，後端 endpoint 部分保留 placeholder。

| 項目 | 阻礙原因 | 預估排程 |
| :--- | :--- | :--- |
| 派工即時推播（WebSocket） | 待派工 AI 推薦引擎接入 | Phase 6 後段 |
| 客戶風險 / 滿意度 / NPS / FTFR 等指標 | 各需獨立資料來源 | Phase 7 後段 |
| 雙方證據檔案上傳 | 需設計檔案儲存路徑 | Phase 7 後段 |
| 保固詳情頁與證據縮圖 | 同上 | Phase 7 後段 |
| 庫存補貨 / 異動紀錄 | 待 inventory_transactions 端點 | 待排程 |
| 報表期間切片 / 樞紐 / 匯出 | 待後端 metrics 擴充 | Phase 7 |
| 結算批次標記已付 / 結算詳情 modal | 待後端 endpoint | Phase 7 |
| 退款雙簽流程 | MVP 簡化為單步推進 | Phase 7 後段 |
