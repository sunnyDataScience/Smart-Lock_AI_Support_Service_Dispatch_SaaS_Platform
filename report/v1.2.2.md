# 進度報告 v1.2.2：修復 system.md 大括號 KeyError 與舊 skill 索引噪音

- **版本**: v1.2.2（前版：v1.2.1 → 本版升級類型：PATCH）
- **Commit**: 200c431
- **分支**: agent-improve
- **作者**: Imding1211
- **影響模組**: agent/prompts/system.md、agent/agent.py

## 變更摘要 (WHAT)

兩個 v1.2.1 後遺症修復：

1. **system.md 大括號**：`{Brand}/{Model}`、`{topic}`、`{brand}` 等示例被 `core/config.load_prompt` 的 `template.format()` 當成 placeholder，啟動時 `KeyError: 'Brand'`。全改為雙花括號 escape。
2. **舊 skill 索引噪音**：`agent.py` 啟動仍呼叫 `load_skills()` 印 67 行 `[skills] 索引: ...`。`load_skill` 工具已停用，索引無意義。改為 `set_skills([])` 清空，保留註解方便恢復。

## 背景與動機 (WHY)

使用者實際啟動 server 才暴露這兩個問題。第一個是 blocker（無法啟動），第二個是用戶回饋（噪音 log）。

## 影響評估 (IMPACT)

- 破壞性變更：無
- 後續動作：使用者重啟 server 即可

## 驗證方式

啟動 `uvicorn app:app --reload --port 8000` 應看到 `[agent] 載入 36 份產品資訊文件` 但**不再有** `[skills] 索引: ...` 67 行，且不再 `KeyError: 'Brand'`。
