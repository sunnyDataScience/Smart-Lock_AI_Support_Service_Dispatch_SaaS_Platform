## 背景與動機 (WHY)

- 原 setup-guide.md 是 10+ 個手動命令，新人 / AI 助手代為操作容易踩 schema 順序、`--link` 參數、port mapping 等坑
- 系統 98% 完成需要 demo F2 LINE Flex RSVP 等 agent 流程，但 agent 啟動 onboarding 完全沒寫
- 會議 demo / 招待業主 / 新工程師入職都需要「打開就能用」的零思考啟動方式

## 影響評估 (IMPACT)

- 破壞性變更：無；既有手動步驟全部保留在 §1–§5
- 啟動體驗：10+ 命令 → 3 行（git clone + cd + up.sh）
- 首次啟動約 5-8 分鐘（docker pull + npm install + pip install），之後啟約 15-30 秒（idempotent 跳過已完成步驟）
- agent 缺 VERTEX_PROJECT_ID 不會搞死 web/api（fail soft，腳本繼續完成可完成的部分）
