## 變更摘要 (WHAT)

- 新增 `/tech-login` (T0)：mobile-first 全螢幕登入，呼叫 `POST /api/v1/technicians/login`，成功跳轉 `/pool`
- 新增 `/account` (T4)：profile header 漸層卡 + online toggle + 收入概覽佔位 + 績效 3 卡 + 個人資料 + 設定列表（含登出）

## 背景與動機 (WHY)

技師端 PWA 缺登入入口與帳戶頁，導致底部導航第三 Tab（帳戶）點不開、也無法走完登入 → 接單 → 完工 → 登出的完整 flow。本次補齊技師端骨架最後兩頁。

## 影響評估 (IMPACT)

- 無破壞性：純新增頁面 + 新 helper，不影響既有 `/login`
- 技師端骨架四頁完成：T0 登入 / T1 案件池 / T2-T3 工單列表+詳情 / T4 帳戶
- MVP 刻意省略：SMS OTP（V2.0）、收入結算 API（後端待補）、PATCH availability（後端僅 GET）、編輯個人資料、排班管理、LINE Login
