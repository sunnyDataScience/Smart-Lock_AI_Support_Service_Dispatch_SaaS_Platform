## 2. Token、回覆時間紀錄（取代 Opik）✅

新增 PostgreSQL 表 `llm_usage_log`，5 個 LLM 呼叫點全面串接，可一站式查詢成本、延遲與 Q/A 內容，作為 Opik 不可用後的觀測替代。

**涵蓋呼叫點（call_site）**

| call_site | 說明 |
| :--- | :--- |
| `react_agent_step` | ReAct 主推論每一步 |
| `memory_compression` | 對話記憶壓縮 |
| `output_validator` | 輸出守門員 |
| `profile_extraction` | 使用者資訊抽取 |
| `quality_judge` | LLM-as-Judge 評分 |

**紀錄欄位**

- token：`input_tokens` / `output_tokens` / `total_tokens`
- 延遲：`latency_ms`
- 成功與否：`success` / `error_type`
- **使用者問題原文** `user_question`、**AI 回覆原文** `ai_reply`（最近補上）
- 模型版本、call_site、user_id、turn_id、metadata JSONB

**查詢工具**

```bash
cd agent
python scripts/view_llm_usage.py                  # 近 24h 概覽 + 最近明細（含 Q/A）
python scripts/view_llm_usage.py --by-call-site   # 按呼叫情境聚合成本
python scripts/view_llm_usage.py --by-day         # 趨勢
python scripts/view_llm_usage.py --slow --threshold 5000  # 慢呼叫排查
```
