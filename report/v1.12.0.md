#### 場景 A：未設 REALTIME_BASE_URL
1. `/conversations/<id>` 右側看到面板顯示「未配置」灰點

#### 場景 B：echo SSE server
建立簡易 SSE 模擬：
```bash
# 用 Node 一行 server
node -e "
const http = require('http');
http.createServer((req, res) => {
  res.writeHead(200, {
    'Content-Type': 'text/event-stream',
    'Cache-Control': 'no-cache',
    'Access-Control-Allow-Origin': '*',
  });
  let i = 0;
  const id = setInterval(() => {
    res.write('event: diagnostic.reasoning.step\n');
    res.write('data: ' + JSON.stringify({
      step_index: Math.floor(i / 5),
      content_delta: '...token' + i,
      is_final: i === 14,
    }) + '\n\n');
    i++;
    if (i > 14) clearInterval(id);
  }, 300);
  req.on('close', () => clearInterval(id));
}).listen(8000);
"
# .env.local 設 NEXT_PUBLIC_REALTIME_BASE_URL=http://localhost:8000
# 重啟 dev server，開 /conversations/<任一id> → 展開「AI 診斷推理」
```
