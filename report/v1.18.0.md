## 驗證方式

### 自動化
- ✅ migration 已套用（online_state column + technician_schedule_requests table）
- ✅ 後端 `from main import app` 載入成功，5 個新 operationId 註冊
- ✅ 前端 `npx tsc --noEmit` exit 0
- ✅ `npx next build` 成功

### 手動驗證

```bash
# 啟動後端
cd api && uvicorn main:app --reload --port 8001

# 啟動前端
cd web && npm run dev
# 登入 demo-tech@example.com / techpass123
```

| 操作 | 預期 |
|:---|:---|
| 進 `/account/schedule` | 載入當月每日工單數紅點 + 已核准休假/備勤背景色 |
| 月份切換 | 重新 GET /schedule?month=YYYY-MM |
| 申請休假填表送出 | POST /leave-request 200 + 列表頂端插入 |
| 申請備勤填表送出 | POST /standby-request 200 + 列表插入 |
| 取消 pending 申請 | DELETE /schedule/request/{id} 200 + 移除 |
| 取消 approved 申請 | 409 STATE_CONFLICT |
| 在線 toggle 切離線 | PATCH /availability {online_state: "offline"} 200 |
| 切回在線 | PATCH /availability {online_state: "available"} 200 |

### Curl 測試
```bash
TOKEN="<從 /technicians/login 取得>"
TENANT="00000000-0000-0000-0000-000000000001"

# 取得本月排班
curl http://localhost:8001/api/v1/technicians/me/schedule?month=2026-05 \
  -H "Authorization: Bearer $TOKEN" -H "X-Tenant-ID: $TENANT"

# 申請休假
curl -X POST http://localhost:8001/api/v1/technicians/me/schedule/leave-request \
  -H "Authorization: Bearer $TOKEN" -H "X-Tenant-ID: $TENANT" \
  -H "Content-Type: application/json" \
  -d '{"start_date":"2026-05-10","end_date":"2026-05-12","reason":"家庭事務"}'

# 切離線
curl -X PATCH http://localhost:8001/api/v1/technicians/me/availability \
  -H "Authorization: Bearer $TOKEN" -H "X-Tenant-ID: $TENANT" \
  -H "Content-Type: application/json" \
  -d '{"online_state":"offline"}'
```
