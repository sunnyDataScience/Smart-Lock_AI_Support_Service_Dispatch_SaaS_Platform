## 變更摘要 (WHAT)

- 新增 `llm_usage_log` 表（雙向同步 DDL：`postgres_impl.build_postgres_storage()` + `SQL/Schema_v2_extensions.sql`），啟動時自動建立 + 3 個查詢索引；實作 `log_llm_call()` 與向後相容的 `log_llm_interaction()` wrapper（postgres + sqlite 雙實作）
- 新增 `agent/harness/llm_metrics.py` 共用模組（`extract_usage` / `log_simple` / `schedule_log` / `set_storage`）；5 個 LLM 呼叫點接入紀錄：`react_agent_step`、`memory_compression`、`output_validator`、`profile_extraction`、`quality_judge`
- 新增查詢腳本 `scripts/view_llm_usage.py` + `agent/scripts/view_llm_usage.py`（`--by-call-site` / `--by-day` / `--slow` / `--user-id` / `--since`）

## 背景與動機 (WHY)

Opik LLM observability 服務目前無法使用，但團隊仍需追蹤每次 LLM 呼叫的：
- Token 使用量（成本控管）
- 回覆延遲 latency_ms（效能監控）
- 模型版本與呼叫情境（問題追溯）

原本 `postgres_impl.py:117-127` 的 `log_llm_interaction()` 是空殼 `pass`，`debounce.py:494` 的呼叫實際完全沒寫入；既有 `audit_log` 表也沒有 token 欄位。本次以最小侵入方式補齊這條觀測能力，未來可再接 web dashboard 或 cost 計算。

## 影響評估 (IMPACT)

- **破壞性變更**: 無。`log_llm_interaction()` 介面保留為相容 wrapper，呼叫端無需改動
- **DB schema**: 新增 `llm_usage_log` 表，`CREATE TABLE IF NOT EXISTS` 啟動自動建立，**不需手動 migration**
- **效能**: 所有 DB 寫入用 `asyncio.create_task` 火放即忘 + `try/except` 吞錯，**不阻塞使用者回覆關鍵路徑**（預期 `[Timing]` 段變化 < 5ms）
- **PII**: `metadata` JSONB 欄位禁存訊息原文，僅存結構化欄位（step_index / tool_calls / thread_id）
- **連帶整併**: 此 commit 一併入庫了既有未提交的 `quality_check.py` 215 行 refactor、`UAT_REPORT.md`、移除已棄用的 `simulate_e2e.py`、CLAUDE.md 模組地圖更新

## 驗證方式

1. 啟動驗證 schema 建立：
   ```bash
   cd agent && uvicorn app:app --reload --port 8000   # 觀察 [Audit DB] 連線成功 + 無 DDL 錯誤
   psql $POSTGRES_URI -c "\d llm_usage_log"
   ```
2. 觸發各 call_site 並驗證寫入：
   ```bash
   curl "http://localhost:8000/chat?q=門打不開我手機0912345678&user_id=test-token-1"
   psql $POSTGRES_URI -c "SELECT call_site, COUNT(*), SUM(total_tokens), AVG(latency_ms)::int FROM llm_usage_log GROUP BY call_site;"
   ```
3. CLI 報表：
   ```bash
   python scripts/view_llm_usage.py --by-call-site --since 1h
   python scripts/view_llm_usage.py --slow --threshold 5000
   ```
4. 失敗路徑：模擬 `_llm.ainvoke()` raise → 確認寫入 `success=false`、`error_type=<ExceptionClass>`
5. 語法 / import 驗證已通過（10 個檔案）
