## 變更摘要 (WHAT)

- 在 `agent/product_info/Dormakaba/` 16 份 `{Model}.md` 中（AS701 / AS850 / AS901 / DP850 / FA9000 / FSL800 / GL220 / ML550 / ML660 / ML770 / MP750 / RL320 / RL360 / RL360V / RL599 / Rose），於「## 操作步驟」與「## 故障排除」之間統一插入「## Dormakaba WiFi 設定」章節。
- 章節內容：前置準備（dormakaba DDL APP 下載、註冊、2.4G WiFi 限制）→ 三步驟 WiFi 配對（APP 掃 QR / 鎖端按管理者密碼 # 7 連線 dormakaba 網路 / APP 完成綁定）→ WiFi 功能表（遠端解鎖 / 遠端密鑰 / 分享管理權限）→ 常見問題 → 型號差異備註（RL599 採近場藍牙）。

## 背景與動機 (WHY)

LINE 線上對話中客戶頻繁詢問 Dormakaba WiFi 設定（如何用 APP 遠端開鎖、如何設定遠端密鑰、如何分享給家人），但原 mega-doc 各型號內**沒有 WiFi 章節**，AI 只能含糊作答或推到派工。本次新增覆蓋此空白。

## 驗證方式

- 部署後，在 LINE Bot 測試：
  1. 先告知品牌型號（如 Dormakaba RL360）→ 詢問「請問怎麼設定 WiFi」 → 預期 AI 載入 `Dormakaba/RL360`，依新章節回答（APP、QR 碼、管理者密碼 # 7 等）。
  2. 詢問「dormakaba 怎麼遠端開鎖」 → 預期 AI 載入該型號文件，引用 WiFi 功能表中的「遠端解鎖」段。
  3. 詢問「家人也要用 APP 怎麼辦」 → 預期 AI 引用「分享管理權限」段，提醒對方需先註冊 APP。
- 結構檢查：`grep -c "## Dormakaba WiFi 設定" agent/product_info/Dormakaba/*.md` 應全部回傳 1。
