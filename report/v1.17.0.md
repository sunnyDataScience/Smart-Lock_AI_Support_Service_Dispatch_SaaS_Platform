## 變更摘要 (WHAT)

- **後端**：新增 4 個 endpoints + service 函式：
  - `recordScopeChange` / `recordMaterialRequest` / `recordDelay` / `recordDoorCheck`
  - 共用 `_append_subflow_event` 助手：驗 status ∈ {assigned, accepted, in_progress} → prepend 標籤到 `service_report`
- **OpenAPI** 補上 4 個 path 含 inline schema + 409/422 響應
- **TS types** 重新產生（4 個新 operationId）
- **前端** 4 頁移除 setTimeout mock，改真實 `api.post` 呼叫；移除 amber banner

## 背景與動機 (WHY)

v1.10.0 前端做完 5 個 subflow 頁面後，T5/T6/T7/T8 後端仍是 spec 定義但 OpenAPI 未含；前端只能 mock。本次補齊後端 + 串實前端，讓現場 4 個 subflow 動作能真實寫入後端。

## 影響評估 (IMPACT)

- 後端：91 → **95 endpoints**
- 前端：T5/T6/T7/T8 從 mock → 真實後端寫入
- 限制：`service_report` append 模式不適合大量事件查詢/統計，後續若需要可遷移至 `work_order_events` 表
- 媒體上傳 endpoint 仍待補（T8 photos 目前傳 placeholder 檔名字串）

## 驗證方式

### 自動化
- ✅ 後端 `from main import app` 可載入，101 條路由
- ✅ 4 個新 operationId 已註冊：
  - `POST /api/v1/work-orders/{id}/scope-change` (recordScopeChange)
  - `POST /api/v1/work-orders/{id}/material-request` (recordMaterialRequest)
  - `POST /api/v1/work-orders/{id}/delay` (recordDelay)
  - `POST /api/v1/work-orders/{id}/door-check` (recordDoorCheck)
- ✅ 前端 `npx tsc --noEmit` exit 0
- ✅ `npx next build` 成功

### 手動驗證

```bash
# 啟動後端
cd api && uvicorn main:app --reload --port 8001

# 啟動前端
cd web && npm run dev
# 登入 demo-tech@example.com / techpass123 → 進入任一進行中工單
```

| Subflow | 操作 | 預期 |
|:---|:---|:---|
| T5 範圍變更 | 填事由 + 工項 → 送出 | 200 + service_report 多一行 `[SCOPE_CHANGE ...]` |
| T6 缺料 | 填缺件 → 送出 | 200 + 多一行 `[MATERIAL_REQUEST ...]` |
| T7 延遲 | 選時長 + 原因 → 送出 | 200 + 多一行 `[DELAY ...]` |
| T7 延遲 0 分 | 嘗試送出 | 422 VALIDATION_ERROR |
| T8 門面檢核 | 拍照 + checklist → 送出 | 200 + 多一行 `[DOOR_CHECK ...]` 後跳簽章 |
| 任一 subflow（terminal 狀態） | 送出 | 409 STATE_CONFLICT |

### Curl 測試
```bash
# 取得 access_token 後：
curl -X POST http://localhost:8001/api/v1/work-orders/<wo_id>/delay \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -H "X-Tenant-ID: 00000000-0000-0000-0000-000000000001" \
  -H "Idempotency-Key: $(uuidgen)" \
  -d '{"delay_minutes":30,"reason":"塞車 / 路況","notify":"customer_only"}'
```
