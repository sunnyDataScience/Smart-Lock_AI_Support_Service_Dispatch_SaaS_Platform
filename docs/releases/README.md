# Releases

This directory contains release notes for each version of the Smart Lock AI Support & Service Dispatch SaaS Platform.

**Format:** One markdown file per version (`v<MAJOR>.<MINOR>.<PATCH>.md`).

**History:** Migrated from repository root `report/` per ADR-0024 §3 S3 (Phase 2', 2026-05-11). Previous path references in `.github/workflows/db-conn-lint.yml` have been updated.

## Latest

See the highest-numbered `v*.md` file in this directory for the most recent release notes.

## Conventions

- File names use semantic versioning: `v1.22.1.md` for v1.22.1
- Each release note describes what shipped, why, and any migration notes
- Releases are append-only — never edit a published release note retroactively (use a new patch version instead)
