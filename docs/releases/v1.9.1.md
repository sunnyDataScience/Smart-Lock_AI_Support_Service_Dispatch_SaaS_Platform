## 變更摘要 (WHAT)

- **修 AuthGuard 路由保護 bug**：
  - `PUBLIC_PATHS` 加 `/tech-login`
  - 新增 `TECH_ROUTE_PREFIXES`（`/pool` `/my-orders` `/account` `/tech-login`）
  - 未登入：技師路由 → `/tech-login`，其他 → `/login`
  - 已登入訪問 `/tech-login` → `/pool`；訪問 `/login` → `/dashboard`
- 新增 `web/src/app/tech-login/layout.tsx`（與 `/login` layout 對稱）
- 大改 `web/docs/login-testing-guide.md`：拆 A/B 段、加技師種子帳號、加端對端 Flow 1 驗證、加 mobile 檢視提示、加常見問題排查

## 背景與動機 (WHY)

新增技師端 `/tech-login` 後發現原 AuthGuard 的 `PUBLIC_PATHS` 只有 `/login`，導致：
1. 未登入訪問 `/tech-login` 會被當私有路由 → 重導回 admin `/login`（破壞技師登入流程）
2. 未登入訪問 `/pool`、`/my-orders`、`/account` 全被導到 admin 入口，違反技師 PWA 設計

文件層面，QA 拿到新版前端不知道怎麼測技師端，需要更新指引。

## 影響評估 (IMPACT)

- 修 bug：路由保護現在正確區分 admin/tech，向下相容（`/login` 行為不變）
- 文件對齊新增的技師端入口，QA 可直接照表測
- 無破壞性
