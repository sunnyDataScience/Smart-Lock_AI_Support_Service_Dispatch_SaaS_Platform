## 影響評估 (IMPACT)

- 限制：amount 上下限與計費路徑（補償/扣款的會計分錄）尚未做

### 手動端對端

```bash
cd api && uvicorn main:app --reload --port 8001
cd web && npm run dev
```

| 步驟 | 預期 |
|:---|:---|
| 進 `/admin/disputes` 點任一 filed/under_review/mediation 案件 | 描述塊下方出現「仲裁決定」3 按鈕 |
| 點「解決」→ modal 填結果（≥5 字）+ 金額 | 提交 200 → 列表重抓，狀態變 resolved |
| 已 resolved/escalated 案件 | 不顯示按鈕 |
| 兩個 admin tab 同時開 `/admin/disputes` | A 提交決定後 B 即時收到 WS 重抓 |
| 422 / 409 錯誤 | modal 內紅色 banner 顯示 ApiError |

### Curl
```bash
curl -X POST http://localhost:8001/api/v1/disputes/<id>/decision \
  -H "Authorization: Bearer $TOKEN" -H "X-Tenant-ID: $TENANT" \
  -H "Idempotency-Key: $(uuidgen)" -H "Content-Type: application/json" \
  -d '{"decision":"resolve","resolution":"經審查證據後同意補償","resolution_amount":500}'
```
