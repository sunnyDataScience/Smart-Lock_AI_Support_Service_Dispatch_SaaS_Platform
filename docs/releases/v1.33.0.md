| 場景 | 預期 |
|:---|:---|
| 工單卡在 `created` 超過 30 分鐘 | dispatch_delay 推送 → /admin/dashboard 顯示紅色卡片 |
| 點 dashboard SLA banner 「處理」CTA | 跳轉 `/admin/dispatch-manual?work_order_id=...` |
| 客戶傳訊息後客服 30 分鐘未回 | response_overdue 推送 |
| 報價工單 24 小時未確認 | quote_expiring 推送 |
| 同 alert 重複 scan | dedup，只推一次 |
| 工單狀態變化解除告警 | 從 _alerted 移除 |
