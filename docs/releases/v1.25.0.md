```bash

cd api && uvicorn main:app --reload --port 8001
# 前端
cd web && npm run dev
```

| 操作 | 預期 |
|:---|:---|
| 技師接單 → 進詳情 → 點「門面檢核」 | 進入 door-check 頁面 |
| 點「拍照 / 選擇圖片」 | 開啟 file picker（手機觸發 camera）|
| 選圖後 | 顯示「上傳中…」→ 縮圖網格 + X 移除按鈕 |
| 必填 6 項 + 前後各 1 張 → 送出 | POST /door-check 帶 photos_before/after URL → 跳簽章 |
| 後端 `data/media/{tenant}/{YYYY-MM}/` 目錄 | 含實際檔案 |
| 直接 GET `/api/v1/media/{id}` | 回傳檔案內容（需帶 Bearer + X-Tenant-ID） |

### Curl

```bash
# 上傳
curl -X POST http://localhost:8001/api/v1/media \
  -H "Authorization: Bearer $TOKEN" -H "X-Tenant-ID: $TENANT" \
  -F "file=@photo.jpg" -F "purpose=door_check_before" \
  -F "work_order_id=<wo_id>"

# 下載
curl http://localhost:8001/api/v1/media/<media_id> \
  -H "Authorization: Bearer $TOKEN" -H "X-Tenant-ID: $TENANT" \
  -o downloaded.jpg

# 列出工單相關 media
curl http://localhost:8001/api/v1/work-orders/<wo_id>/media \
  -H "Authorization: Bearer $TOKEN" -H "X-Tenant-ID: $TENANT"
```
