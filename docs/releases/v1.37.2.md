## 變更摘要 (WHAT)

- `columns` 6 個 config 全部加 `shrink-0`（固定寬欄）或 `min-w-0`（flex-1 欄）
- 6 個 row `<div>` 同步加 `shrink-0` / `min-w-0`

## 背景與動機 (WHY)

`/admin/disputes` 列表 header 與 row 在欄位寬度上不一致，視覺上跑版。Tailwind 的 `w-[140px]` 等固定寬度在 flex 容器中預設 `flex-shrink: 1`，當：
- 父寬不足，或
- row 內容（mono UUID 8 字、badge）比 header 文字寬

→ row 固定寬欄會撐到 content min-width 不縮，但 header 文字短會被壓得更小 → 同欄寬度不一致 → 跑版。
