# 測試員指引：派單 → 技師接單 → 品牌後台狀態變化（UAT-0720-08）

> 給外部測試人員（Irene）的操作對照，回答 0720 issue list 兩問：
> 「工單 where to 接單？」「師傅已接單，在哪裡看？」

## 一、技師端在哪接單（tech-portal，師傅站）

兩條路徑，擇一：

1. **案件池搶單**：師傅站側欄「**案件池**」→ 點進某張工單**詳情頁**（業主 2026-07-11 裁決：不可一鍵接單，必須先進詳情看清楚）→ 底部「**接受工單**」→ 二次確認視窗按確認。
   - 接單**前**看不到客戶姓名/電話（隱私最小揭露），接單後才在「我的工單」完整呈現。
2. **後台指派**：品牌後台「指派技師」派給特定師傅 → 師傅在 LINE 收到派單推播 → 進師傅站「**我的工單**」接受。

接單成功後工單狀態 `assigned → accepted`，系統寫入接單時間（`accepted_at`），客戶 LINE 收到「✅ 技師已接單」推播。

## 二、品牌後台在哪看「師傅已接單」（brand-portal）

工單詳情頁（工單管理 → 工單列表 → 點單號）三個位置：

| 位置 | 看什麼 |
|---|---|
| **頂部 SLA 時間軸** | 「接受」節點亮起＋節點下方顯示**接單時間**（MM/DD HH:mm）※ 0722 輪次 A 新增，需部署後生效 |
| **事件時間軸（工單動態）** | 新增「**技師接單**」事件列，含技師代號前 8 碼＋時間 ※ 同上 0722 新增 |
| **右側技師面板** | 已指派技師的姓名／評分／電話（接單前後皆顯示指派對象） |

## 三、驗收步驟建議（一條龍）

1. 品牌後台開一張工單（或問題卡轉工單）→ 指派技師（或留在案件池）。
2. 技師帳號登入師傅站 → 案件池/我的工單 → 接受工單（走二次確認）。
3. 回品牌後台工單詳情 → 確認 SLA「接受」節點有時間、事件時間軸有「技師接單」列。
4. 客戶 LINE 應收到「技師已接單」推播（工單號一致）。

> 注意：SLA 時間軸的接單時間是 0722 `fix/uat-0720-round-a`（CR-0178）新增，**雲端要重佈 api＋brand-portal 後才看得到**；重佈前只有節點亮、無時間小字。
