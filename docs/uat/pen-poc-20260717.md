## 3. 架構修正(對會議 §11.1 的重要更正)

會議原話:「直接從後台用 FastAPI 或 JavaScript **硬寫進資料庫**」——**此路不通**:

> `.pen` 是**加密檔案格式**,不是資料庫;唯一程式化入口就是 **Pencil MCP**。

正確架構(比原想像更簡單,幾乎零開發):

```
Markdown(source of truth,git 管理)
   │  一支「md→pen 渲染 Skill」(轉換規則,即 §1 的隱含規則正式化)
   ▼
Claude Code + Pencil MCP(現成,本 repo 已在用)
   │  batch_design C/U/D、batch_get R
   ▼
Pen page(渲染層)← Irene / Sunny 在 UI 上看與編
```

- 管理者視角:永遠從 Pen UI 看進度(本 POC 的 board 即樣板)
- 工程視角:全部叫 agent 掃 Markdown → 同步進 Pen,不用手動排版
- **不需要** FastAPI 中介、不需要碰任何資料庫
