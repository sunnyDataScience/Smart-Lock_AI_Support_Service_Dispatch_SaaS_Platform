## 案例 1：師傅現場加價爭議

| 項目 | 內容 |
|------|------|
| 案件編號 | DISP-2026-001 |
| 日期 | 2026-01-15 |
| 工種 | 電子鎖安裝（新裝） |
| 品牌型號 | Dormakaba AS901 |
| 爭議類型 | 報價糾紛 |

**事件經過：**
客戶預約安裝 Dormakaba AS901，系統報價工資 1,500 元 + 車馬費 300 元。師傅到場後告知客戶門扇為非標準厚度，需額外加工，現場口頭報價加收 2,000 元。客戶認為費用不合理並投訴。

**處理方式：**
1. 客服立即凍結交易，調出系統標準報價
2. 技術主管確認門扇確實需要加工，標準加工費為 800 元
3. 與客戶說明實際加工費用，以 800 元結算
4. 師傅記警告一次，扣除評分

**處理結果：** 客戶接受標準加工費，完成安裝。師傅降級觀察。

**滿意度：** 客戶 — 普通 ／ 師傅 — 不滿

## 案例 4：施工造成門板損傷

| 項目 | 內容 |
|------|------|
| 案件編號 | DISP-2026-004 |
| 日期 | 2026-02-20 |
| 工種 | 電子鎖安裝（換鎖） |
| 品牌型號 | AiLock 七合一旗艦款 |
| 爭議類型 | 施工損害 |

**事件經過：**
更換電子鎖需切割韓規側板，施工中砂輪機高溫導致門板油漆起泡。客戶表示事前未被告知會有此風險，要求賠償門板重新烤漆費用。

**處理方式：**
1. 確認師傅施工前未依規範告知客戶切割風險
2. 技術主管到場勘查，確認損傷範圍約 5cm × 3cm
3. 公司承擔門板局部補漆費用 3,500 元
4. 師傅記缺失一次（未執行告知義務）

**處理結果：** 公司賠償補漆費用，師傅接受處分。

**滿意度：** 客戶 — 滿意 ／ 師傅 — 接受

## 案例 5：客戶取消派工費用爭議

| 項目 | 內容 |
|------|------|
| 案件編號 | DISP-2026-005 |
| 日期 | 2026-03-05 |
| 工種 | 電子鎖維修 |
| 品牌型號 | Milre 美樂 6500F |
| 爭議類型 | 取消費用爭議 |

**事件經過：**
客戶報修後派工，師傅出發途中客戶來電表示自行解決問題（更換電池後恢復正常），要求取消派工。師傅已出車 20 分鐘，要求客戶支付車馬費 300 元。客戶拒絕，認為師傅尚未到場不應收費。

**處理方式：**
1. 客服確認師傅已出車，依規定可收取出車費
2. 向客戶說明取消政策：師傅出發後取消需支付基本車馬費
3. 考量客戶為首次使用服務，本次免收車馬費
4. 師傅獲得公司補貼車馬費 300 元

**處理結果：** 客戶免付，公司內部吸收成本。後續於取消政策中加註更明確的說明。

**滿意度：** 客戶 — 滿意 ／ 師傅 — 接受
