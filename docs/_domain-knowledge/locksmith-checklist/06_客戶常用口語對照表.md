# 客戶常用口語對照表

> ⚠️ 本文件為 AI 生成之模擬資料，僅供系統開發測試用途，不代表實際產品規格。

---

| # | 客戶口語說法 | 標準故障分類 | 補充說明 |
|---|------------|------------|---------|
| 1 | 鎖卡住了 | 鎖舌卡死 / 門扇卡澀 | 需進一步確認是鎖體還是門扇問題 |
| 2 | 門打不開 | 開門故障（多種可能） | 需確認是室內還是室外、推門還是拉門 |
| 3 | 門關不起來 | 關鎖失敗 / 鎖栓無法伸出 | 檢查受口片對位 |
| 4 | 鎖一直叫 | 未關門警報 / 關鎖失敗警報 | 需確認叫聲模式（長鳴 vs 短嗶） |
| 5 | 密碼按了沒反應 | 面板無回應 / 電池耗盡 | 先確認面板是否亮起 |
| 6 | 指紋感應不到 | 指紋辨識失敗 | 可能手指濕、髒或指紋磨損 |
| 7 | 鎖沒電了 | 電池耗盡 | 引導緊急供電或使用鑰匙 |
| 8 | 電子鎖壞掉了 | 待診斷（泛稱） | 需進一步問診確認具體症狀 |
| 9 | 鎖一直嗶嗶叫 | 低電量警告 / 防盜警報 | 需確認嗶聲頻率與次數 |
| 10 | 被鎖在外面 | 無法開門（緊急） | 優先處理，確認是否有鑰匙或備用方式 |
| 11 | 鎖自己打開了 | 異常解鎖 / 鎖舌縮回 | 可能門扇反弓或感應器誤觸 |
| 12 | 把手轉不動 | 把手機構卡死 / 離合器故障 | 確認是解鎖前還是解鎖後轉不動 |
| 13 | 感應卡刷不過 | 卡片驗證失敗 | 確認卡片是否已註冊、是否為正確卡片 |
| 14 | APP 連不上 | Wi-Fi 模組斷線 | 確認路由器頻段與電子鎖距離 |
| 15 | 螢幕不亮 | 面板無回應 / 電池耗盡 | 先確認電池，再確認螢幕排線 |
| 16 | 鎖會漏電 | 異常耗電 | 非真正漏電，確認電池品牌與 Wi-Fi 設定 |
| 17 | 臉辨識不到 | 人臉辨識失敗 | 可能光線不足或防回頭機制啟動 |
| 18 | 鎖很大聲 | 馬達異音 / 鎖栓撞框 | 確認是正常馬達聲還是異常撞擊聲 |
| 19 | 門會自己開 | 門扇反弓 (Rebound) | 非鎖具問題，需調整門扇或鉸鏈 |
| 20 | 設定跑掉了 | 系統重置 / 設定遺失 | 可能因電池拔除過久或主機板異常 |
| 21 | 鎖裝歪了 | 安裝品質問題 | 確認是鎖體歪還是門扇下沉 |
| 22 | 密碼被改了 | 權限異常 / 管理者誤操作 | 確認管理者密碼是否仍有效 |
| 23 | 鎖進不去設定 | 管理者權限問題 | 區分管理者密碼與一般開門密碼 |
| 24 | 門縫很大 | 門扇下沉 / 鉸鏈鬆脫 | 非鎖具問題，需調整門扇 |
| 25 | 鎖裝好還是關不了 | 安裝後關鎖失敗 | 檢查受口片與鎖栓對位 |
