> **對口窗口:** 甲方營運（負責技師管理的人）
> **協作者:** 產品經理
> **最晚交付日:** Phase 2 W3
> **用途:** 定義技師的技能矩陣、服務區域與系統操作規範，讓派工引擎能正確匹配技師

---

## 為什麼這份很重要

派工系統的核心邏輯是：**什麼問題 → 派什麼技師 → 去什麼地方**。
沒有技師的技能與區域資料，派工就只能隨機指派，效率跟客戶打電話叫人沒兩樣。

### 3. 技師 Web App 操作指南（0.5.3）

**檔案名稱建議:** `technician_app_guide.md`

技師使用系統的操作流程說明（V2.0 派工功能上線後使用）：

#### A. 接單流程

| 步驟 | 操作 | 說明 |
| :--- | :--- | :--- |
| 1 | 收到 LINE 派工通知 | 包含客戶問題摘要、地址、預估難度 |
| 2 | 確認接單 | 點擊「接受」或「拒絕」（拒絕需註明原因） |
| 3 | 查看工單詳情 | 在 Web App 中查看完整工單資訊 |
| 4 | 導航到場 | 一鍵開啟 Google Maps 導航 |
| 5 | 到場打卡 | GPS 定位確認到達 |

#### B. 維修回報流程

| 步驟 | 操作 | 說明 |
| :--- | :--- | :--- |
| 1 | 拍照記錄 | 維修前/維修後拍照上傳 |
| 2 | 填寫維修內容 | 實際故障原因、更換零件、處理方式 |
| 3 | 費用確認 | 系統自動計算費用，技師確認 |
| 4 | 客戶簽收 | 客戶確認維修完成 |
| 5 | 完工回報 | 提交工單，系統自動歸檔 |

#### C. 需要確認的操作細節

- 技師需要帶什麼設備？（手機就夠？需要平板？）
- 沒有網路的地方怎麼辦？（離線模式？）
- 技師自己帶零件還是公司統一配發？
- 維修報告的必填欄位有哪些？

### 4. 品質標準與考核（0.5.4）

**檔案名稱建議:** `quality_standards.md`

| 考核項目 | 標準 | 計算方式 |
| :--- | :--- | :--- |
| 接單回應時間 | 30 分鐘內回應 | 從派工通知到接單確認的時間 |
| 準時到場率 | >= 90% | 在約定時間內到場的比例 |
| 一次修復率 | >= 85% | 一次到場就修好的比例（不需二次上門） |
| 客戶評分 | >= 4.0 / 5.0 | 客戶完工後的評價平均分 |
| 維修回報及時率 | 完工後 2 小時內 | 提交完工回報的時間 |
| 照片完整率 | 100% | 每次維修必須有前後對照照片 |

#### 需要確認的問題

- 以上標準是否符合你們的期望？
- 考核不達標的後果是什麼？（提醒？暫停派工？）
- 有沒有獎勵機制？（高評分加派優先？獎金？）

## 20260411 會議已確認事項

> 來源：`docs/_meeting-minutes/20260411會議記錄.md` + `20260411逐字稿.txt`

### 已確認的費用標準

| 項目 | 金額 | 說明 |
|------|------|------|
| 師傅出勤費 | 固定 $1,000 | 不分品牌，行情價 |
| 偏遠地區加價 | 上限 $500 | 依偏遠地區報價表執行 |
| 工資（DRAM 更換、拆門等） | 固定行情價 | 各品牌差異不大 |
| IC 板/鎖匣等零件 | 各品牌不同 | 由公司端對接品牌商後填報 |

### 已確認的改時間通知機制（過渡期）

- **雙軌制**：系統紀錄變更 + 客服人工通知師傅（電話或 LINE）
- **原因**：師傅開車時無法即時查看系統通知，需客服主動聯繫確保師傅知悉行程變更
- **未來目標**：工單系統加入「即時跳出通知」功能，取代人工通知

### 已確認的系統溝通功能

- 工單系統內設有**對話視窗**，供客服（小編）與師傅即時溝通
- 師傅的聯繫方式：手機電話 + LINE

### 已確認的派工流程

```
客服整理影片 → 真人評估故障 → 確認所需零件
  → 報價單（含零件 + 工資 + 車馬費）
  → 客戶確認要修 → 安排師傅 → 派工
```

- **關鍵原則**：客戶確認維修意願後才派工，純比價客戶不進入派工程序

### 待確認事項

- 在職技師的技能矩陣與服務區域資料
- 緊急案件（被鎖門外）的特殊派工 SOP
- 假日/晚上值班機制與加班費

### 已實作的「電話可解決 vs 需派工」判斷邏輯

|------|-----------|

### 已實作的安裝評估流程

#### 新門安裝（2 種方式）

- **方式 A**：門廠預裝歐規傳統連體鎖 → 預開孔位 → 電子鎖廠更換
- **方式 B**：門廠提供開孔服務 → 提供詳細開孔圖 → 廠商派員安裝

#### 既有門更換

- 需客戶提供：正面照片 + 鎖匣照片 + 側板寬度長度
- 評估：側板規格相容性（歐規/美規/義大利/日規/韓規）
- Chainlock 做法：確認現有側板 → 提供相符側板 → 避免砂輪機切割

#### 新成屋/預售屋

- 預先提供側板規格 → 提供相應側板 → 安排安裝

### 已實作的安裝流程（6 步驟）

1. **諮詢** → 了解需求
2. **門扇評估** → 照片評估或現場勘查
3. **選擇方案** → 預算/外觀/功能
4. **決定與支付訂金**
5. **安排安裝時間**（建議早上 10:30 或下午 1:30，遵守社區噪音管制）
6. **完工教學** → 管理者設定、用戶新增、緊急供電操作教學
