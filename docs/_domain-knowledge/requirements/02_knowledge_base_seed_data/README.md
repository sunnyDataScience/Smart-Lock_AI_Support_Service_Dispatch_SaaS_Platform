# 02 — 知識庫種子資料

> **對口窗口:** 甲方 + PM
> **最晚交付日:** Phase 1 W3
> **用途:** 作為 AI 智能客服知識庫的初始資料，讓系統上線時就有足夠的案例和手冊可供搜尋

---

## 為什麼這份很重要

AI 客服的回覆品質 = 知識庫的品質。
如果知識庫是空的，AI 只能回答「我不知道」，然後全部轉人工。
種子資料越多、品質越高，系統上線後的 L1 命中率就越高。

---

## 你需要準備什麼

### 1. 歷史維修案例（0.2.1）

**檔案名稱建議:** `historical_cases.xlsx`

請提供至少 **200 筆**歷史維修案例，格式如下：

| 欄位 | 說明 | 範例 |
| :--- | :--- | :--- |
| 案例編號 | 流水編號 | CASE-001 |
| 報修日期 | 客戶報修的日期 | 2025-11-15 |
| 品牌 | 電子鎖品牌 | Samsung |
| 型號 | 具體型號 | SHP-DP609 |
| 鎖種類型 | 指紋/密碼/卡片/人臉/複合式 | 指紋 + 密碼 |
| 問題描述 | 客戶描述的症狀（越口語越好） | 「指紋一直嗶嗶叫辨識不過」 |
| 問題分類 | 電池/WiFi/密碼/機械/安裝/其他 | 指紋辨識 |
| 診斷過程 | 你問了什麼、怎麼判斷的 | 先確認電池電量正常 → 請客戶清潔指紋感應器 → 問題解決 |
| 解決步驟 | 最終的解決方法，按步驟列出 | 1. 用酒精棉片擦拭感應器 2. 重新登錄指紋 3. 測試三次確認正常 |
| 解決結果 | 遠端解決 / 到場維修 / 換鎖 / 轉原廠 | 遠端解決（LINE 指導） |
| 解決時間 | 從接案到結案的時間 | 15 分鐘 |
| 備註 | 特殊狀況說明 | 該型號常見問題，雨季更頻繁 |

#### 案例收集提示

- **優先收集最常見的問題**：電池沒電、指紋辨識失敗、密碼錯誤鎖定、WiFi 斷線等
- **口語化很重要**：客戶原始用詞比專業術語更有價值（AI 需要學會理解口語）
- **失敗案例也要**：沒能遠端解決、最後需要到場的案例，有助於 AI 判斷何時應該轉人工
- **不需要完美格式**：有 LINE 對話紀錄截圖也可以，我們會協助整理

> **最低要求：200 筆**。500 筆以上效果更好。案例越多，AI 的 L1 命中率越高。

### 2. 產品手冊 PDF（0.2.2）

**資料夾建議:** `product_manuals/`

請提供所有品牌/型號的產品手冊 PDF：

| 文件類型 | 說明 | 優先級 |
| :--- | :--- | :--- |

例如：`Samsung_SHP-DP609_使用者手冊.pdf`

> **至少需要**：目前維修量前 10 大型號的使用者手冊與故障排除手冊。

## 現行系統已實作內容

> 來源：`agent/skills/data/` 中 27 個 SKILL.md（系統實際運行的 SOP）

### 知識庫現況說明

系統目前的知識庫並非以「歷史案例」形式存在，而是以 **27 個 SKILL.md SOP** 作為核心知識源。Agent 透過 `load_skill(name)` 動態載入對應 SOP，根據 SOP 內容回覆客戶。每個 SKILL.md 即為經過驗證的標準回覆模板，可視為已結構化的 FAQ 答案。

### 已實作的案例分類體系（0.2.4 已完成）

系統實際採用的三層分類如下：

#### 一級分類：APP 操作（`app/` — 12 個 skill）

| Skill 名稱 | 對應問題類型 |
|-----------|------------|
| app-guide | APP 設定與操作指南（總入口，關鍵字路由） |
| app-pairing | APP 初始配對、WiFi/藍牙連線 |
| app-user-mgmt | 用戶管理（指紋/人臉/掌靜脈/卡片/密碼 5 種方式） |
| app-remote | 遠端開鎖、開鎖紀錄查詢 |
| app-temp-pwd | 臨時密碼設定（7 碼格式 1XXXXXX） |
| app-camera | 即時影像監控與語音對講（AI99 限定） |
| app-family | 家庭成員管理與權限角色 |
| app-unbind | 設備解除綁定（換手機/轉讓） |
| app-settings | 系統設定（音量/語言/童鎖/常開/雙重認證/恢復出廠） |
| app-battery | 電池更換與緊急充電 |
| app-voice-msg | 語音留言錄製與播放 |
| app-cache | 清理 APP 緩存 |

#### 一級分類：通用查詢（`general/` — 4 個 skill）

| Skill 名稱 | 對應問題類型 |
|-----------|------------|
| product-knowledge | 產品知識庫（品牌型號、電池規範、WiFi、鎖體構造、手冊連結） |
| dispatch-guide | 安裝與派工判斷（電話可解決 vs 需派工、安裝評估、報價邏輯） |
| store-info | 店家基本資訊（營業時間、地址、服務項目、服務區域） |
| update-profile | 客戶資料更新（地址/電話/品牌/型號/姓名） |

#### 一級分類：系統故障排除（`system/` — 11 個 skill）

| Skill 名稱 | 對應問題類型 |
|-----------|------------|
| troubleshoot | 故障排除總入口（症狀分流至 8 個子 skill） |

| ts-alarm | 異常警報聲響（品牌專屬信號解讀） |
| ts-verification | 驗證失敗與錯誤碼（嚴重度 3） |
| ts-lock-tongue | 鎖舌與受口片問題 |
| ts-door-rebound | 門扇反弓（非電子鎖故障） |
| ts-power-drain | 異常耗電（電池品牌/WiFi/充電規格） |
| ts-dual-auth | 雙重認證誤觸 |
| system-settings | 系統設定指南（Chainlock/Chatlock 通用） |
| ss-dormakaba | Dormakaba 專屬系統設定與註冊模式 |
