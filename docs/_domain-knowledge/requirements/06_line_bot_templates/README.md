# 06 — LINE Bot 對話模板與介面設計

> **對口窗口:** IT / 開發團隊
> **協作者:** 甲方營運（確認用語）
> **最晚交付日:** Phase 1 W4
> **用途:** 定義 LINE Bot 的對話範本、Flex Message 模板、Rich Menu 設計與錯誤處理回覆

---

## 為什麼這份很重要

LINE Bot 是客戶接觸系統的第一個介面。
對話範本決定了 AI 問診的語氣、節奏和流程。
介面設計決定了客戶的操作體驗——能不能一看就知道怎麼報修。

## 你需要準備什麼

### 1. 對話範本（0.6.1）

**檔案名稱建議:** `conversation_templates.md`

#### A. 歡迎訊息

客戶首次加入 LINE OA 時的歡迎訊息：

```
你好！歡迎使用 [品牌名] 電子鎖智能客服 🔐

我可以幫你：
• 🔧 報修 — 電子鎖故障排除
• 📋 查詢 — 維修進度查詢
• ❓ 常見問題 — 快速找答案

請問需要什麼協助呢？
```

> **請確認語氣是否合適**，是否需要加入品牌名稱或其他資訊。

#### B. AI 問診對話流程

```
[客戶] 我的電子鎖壞了

[AI] 了解，我來幫你排除問題。請問：
1. 你的電子鎖是什麼品牌和型號？
   （品牌通常在鎖的正面，型號在鎖的側邊或背面貼紙）

[客戶] Samsung 的，型號我不確定

[AI] 沒關係！請問你的鎖是用什麼方式開門的？
□ 指紋
□ 密碼
□ 卡片
□ 人臉辨識
□ 手機 App
□ 鑰匙
（可以多選）

[客戶] 指紋跟密碼

[AI] 好的。請問目前遇到什麼狀況？
□ 指紋辨識失敗
□ 密碼輸入沒反應
□ 鎖一直嗶嗶叫
□ 完全沒有反應（黑屏）
□ 門打不開
□ 門關不上
□ 其他（請描述）

[客戶] 指紋辨識失敗

[AI] 了解。讓我幫你排查一下...
（進入故障診斷流程）
```

#### C. 解決方案回覆範本

```
[AI 找到解決方案時]
根據你描述的狀況，可能是指紋感應器需要清潔。

請試試以下步驟：
1️⃣ 用乾淨的軟布輕輕擦拭指紋感應區
2️⃣ 確認手指乾燥後重新按壓
3️⃣ 如果還是失敗，試試其他已登錄的手指

📖 參考來源：Samsung SHP-DP609 使用手冊 P.25

請問這樣有解決你的問題嗎？
□ 已解決，謝謝！
□ 還是不行
□ 我想找人工客服
```

#### D. 轉人工回覆範本

```
[需要轉人工時]
好的，我已經把你的問題記錄下來，正在為你轉接人工客服。

📋 你的問題摘要：
• 品牌：Samsung
• 問題：指紋辨識失敗
• 已嘗試：清潔感應器（未解決）

目前客服人員會盡快回覆你，請稍候。
⏰ 服務時間：週一至週六 09:00-18:00
```

#### E. 派工確認範本（V2.0）

```
[建立派工單時]
已為你安排到場維修服務：

🔧 維修資訊
• 案件編號：WO-20260401-001

```

#### F. 非營業時間自動回覆

```
感謝你的訊息！目前非服務時段。

⏰ 服務時間：週一至週六 09:00-18:00

我會先記錄你的問題，客服人員會在下個工作日優先回覆你。

如果是緊急狀況（完全無法進門），請撥打緊急專線：
📞 0800-XXX-XXX
```

> **請確認營業時間、緊急專線是否正確**。

### 2. Flex Message 模板（0.6.2）

**檔案名稱建議:** `flex_message_designs/`

LINE Flex Message 是可自訂版面的豐富訊息格式。以下場景需要設計：

| 場景 | 內容 | 互動元素 |
| :--- | :--- | :--- |
| 問題分類選擇 | 電池/指紋/密碼/WiFi/機械/其他 | 按鈕（Quick Reply） |
| 解決方案卡片 | 步驟說明 + 參考手冊頁碼 | 「已解決」/「未解決」按鈕 |
| 派工單摘要 | 案件資訊、技師、時間、費用 | 「確認」/「修改」/「取消」按鈕 |
| 維修完成回饋 | 感謝訊息 + 評分邀請 | 1-5 星評分按鈕 |
| 維修報價單 | 項目明細、總價 | 「同意報價」/「再考慮」按鈕 |

### 3. Rich Menu 設計（0.6.3）

**檔案名稱建議:** `rich_menu_design.md`

LINE 底部常駐選單，建議配置：

| 位置 | 功能 | 圖示 | 點擊動作 |
| :--- | :--- | :--- | :--- |
| 左上 | 報修 | 🔧 | 觸發報修問診流程 |
| 右上 | 查進度 | 📋 | 查詢維修案件狀態 |
| 左下 | 常見問題 | ❓ | 展開 FAQ 選單 |
| 右下 | 聯繫客服 | 👤 | 直接轉人工客服 |

> **請提供品牌色系與 LOGO**，設計團隊會製作符合品牌風格的 Rich Menu 圖片。

### 4. 錯誤處理與邊界回覆（0.6.4）

**檔案名稱建議:** `error_responses.md`

| 情境 | 回覆範本 |
| :--- | :--- |
| AI 無法理解客戶訊息 | 「不好意思，我沒有完全理解你的意思。可以用其他方式描述你的問題嗎？或者直接選擇下方選項。」 |
| 客戶傳送圖片 | 「收到你的照片了！不過目前我還無法辨識圖片，請用文字描述一下你遇到的狀況。」 |
| 客戶傳送語音 | 「收到你的語音訊息！但目前我只能處理文字。請用打字的方式告訴我你的問題。」 |
| 系統暫時異常 | 「抱歉，系統目前忙碌中，請稍後再試。如果問題持續，請撥打客服專線：0800-XXX-XXX」 |
| 客戶問非維修問題 | 「我是電子鎖維修專屬客服，這個問題我可能幫不上忙。如需電子鎖相關協助，請隨時告訴我！」 |
| 客戶情緒不佳 | 「非常抱歉造成你的不便，我理解你的心情。讓我為你轉接專人處理，請稍候。」 |
