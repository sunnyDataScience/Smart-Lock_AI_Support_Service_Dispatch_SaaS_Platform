# 09 — 計價規則定義

> **對口窗口:** 甲方 + PM
> **最晚交付日:** Phase 5 W19
> **用途:** 建立報價引擎的核心規則，讓系統能根據品牌、鎖型、工項自動產生一致的報價

---

## 為什麼這份很重要

報價引擎是消費者「要不要派工」的關鍵決策依據。報價不透明或不一致，消費者不接受派工；結算規則不清楚，技師不信任平台。沒有結構化的計價規則，報價引擎就是空殼。

## 0.6.1 標準報價矩陣

**檔案名稱:** `pricing_matrix.xlsx`

**格式:** 品牌 × 鎖型 × 工項 三維報價表


| 品牌      | 鎖型          | 工項   | 基礎工資 | 標準材料費 | 總價  |
| ------- | ----------- | ---- | ---- | ----- | --- |
| Samsung | DP609 指紋鎖   | 安裝   | $__  | $__   | $__ |
| Samsung | DP609 指紋鎖   | 更換面板 | $__  | $__   | $__ |
| Yale    | YDM7116 密碼鎖 | 安裝   | $__  | $__   | $__ |
| Yale    | YDM7116 密碼鎖 | 換電池座 | $__  | $__   | $__ |
| Gateman | WF-20 推拉鎖   | 安裝   | $__  | $__   | $__ |
| ...     | ...         | ...  | ...  | ...   | ... |


**要求：**

- 至少涵蓋 **5 個品牌 × 3 種鎖型 × 5 種工項 = 75 個組合**
- 每個組合的工資與材料費**分開列示**
- 包含所有目前在服務的品牌/型號

**常見工項參考：**

- 新品安裝（含基本配線）
- 維修（電路板/馬達/鎖舌更換）
- 換電池/電池座
- 更換面板
- 密碼/指紋重設（需到場）
- 門扇加工（挖孔/擴孔）

## 0.6.2 特殊加價規則

**檔案名稱:** `surcharge_rules.xlsx`


| 規則名稱 | 觸發條件        | 加價方式 | 金額/比例   | 可疊加 |
| ---- | ----------- | ---- | ------- | --- |
| 夜間加價 | 22:00–06:00 | 百分比  | +30%    | 是   |
| 假日加價 | 國定假日 / 週日   | 百分比  | +50%    | 是   |
| 遠程加價 | 距離 > 30km   | 固定金額 | +$500   | 是   |
| 高樓加價 | > 5F 且無電梯   | 每層固定 | +$200/層 | 是   |
| 急件加價 | 要求 4 小時內到場  | 百分比  | +__%    | 是   |
| 門扇加工 | 需現場挖孔/擴孔    | 固定金額 | +$__    | 是   |


**要求：**

- 至少定義 **3 條加價規則**
- 每條規則包含：觸發條件（系統可判斷）、加價方式（固定/百分比）、是否可與其他規則疊加
- 多條規則同時觸發時的**優先順序**

**需要確認的問題：**

1. 夜間/假日的定義是否與勞基法一致？
2. 遠程距離起算點是公司地址還是技師所在地？
3. 急件的定義？（4 小時？2 小時？當天？）

## 0.6.3 結算與墊款規則

**檔案名稱:** `settlement_rules.md`

**需要定義的項目：**

### A. 技師墊款流程

- 技師在什麼情況下需要墊付？（材料費？交通費？）
- 墊付後如何申請核銷？（完工報告附發票照片？）
- 審核標準是什麼？（金額上限？需要主管核准？）

### B. 結算週期

- 月結還是雙週結？
- 結算日是每月幾號？
- 從完工到入帳的天數？

### C. 結算明細

- 結算報表需要包含哪些欄位？
- 是否需要符合特定會計軟體匯入格式？（如鼎新、SAP）
- 憑證格式需求？（借方/貸方科目？）

### D. 爭議處理

- 技師對報價/結算有異議時的處理流程？
- 消費者拒付或部分支付時的處理規則？

---

## 允收標準

- 報價矩陣涵蓋 ≥ 75 個品牌×鎖型×工項組合
- 每個組合的工資與材料費分開列示
- ≥ 3 條特殊加價規則，含觸發條件與加價方式
- 多規則疊加的優先順序已定義
- 結算週期與墊款核銷流程經甲方與技師代表共同確認
- 結算報表格式經甲方會計確認
