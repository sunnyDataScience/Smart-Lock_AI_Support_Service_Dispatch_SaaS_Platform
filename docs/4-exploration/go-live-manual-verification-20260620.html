C · 安全閘可達性（已驗證的假綠／缺口）

C1. partner scope 沒接線 阻擋上線
確認：fix 函式無 endpoint 呼叫 → vendor 看全品牌 bug 仍活。用綁 partner A 的 vendor 帳號讀 statement，帶 partner B 或不帶參數，看是否回全 tenant 資料。
風險：vendor 看到競品/其他夥伴對帳金額，商業機密外洩。
C2. RBAC 角色指派路徑不可達 阻擋上線
確認：role_assignment_service 0 router → 確認生產角色怎麼改（是否有人直接 psql 繞過 SoD）。
風險：單一管理員可自行提權（含自己），無第二人覆核。內部舞弊核心缺口。
C3. 撤權後 session／token 失效 阻擋上線
確認：CHANGELOG 自承未實作。兩瀏覽器登同帳號 → A 降權 → B 舊 session 打高權 API 看是否仍 200。你裁決上線前補 token 撤銷或簽風險接受。
風險：離職/停權員工在 token TTL 內仍可越權存取客戶資料。
C4. SOP publish 家族覆核 gate（合約 4.4d 紅線）阻擋上線
確認：sop_draft_service.adopt_draft 只查 status='approved'，沒查 family_reviews 覆核。建草稿→admin 核→不做家族覆核→直接 adopt 會成功（應失敗）。
風險：合約紅線（違反=合約終止）。未覆核高風險 SOP 進 AI 知識庫被引用。
C5. config 治理無 RBAC 阻擋上線
確認：saas.config_namespace.owner_role_codes 19/19 全空 → 任何登入者可改 payment_gate/discount_policy/completion_policy。用低權帳號試改 payment_gate 看能否成功。你裁決每 namespace 填哪些角色。
風險：無權者可關 payment_gate（免付款即派工）、放寬折扣、降低完工閘。
