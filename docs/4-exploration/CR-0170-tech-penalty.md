# CR-0170 — 師傅懲罰機制(第一階段)

- **日期**:2026-07-17
- **來源**:20260715 會議 §六 / Action #8(清單 #13);業主:「第一階段加入師傅懲罰
  (遲到、違約自動停權)」,**法務細節找 Iron 問**
- **狀態**:🛑 **骨架待料**——CIA 已出、可疊的基礎已盤點,但**規則值(容忍度、
  自動停權門檻、申訴窗口)必須等 Iron 法務條款回來才填**,現在硬填是編造。
- **CIA 提醒**:Domain model(師傅生命週期)+ User flow(自動停權+申訴)+
  DB schema(違規紀錄表)三面向命中。

---

## §1 Summary

累積師傅的違規事件(遲到、放鴿子、評價過低),達門檻自動觸發停權;停權**必配
申訴/人工覆核**(誤殺師傅比漏罰貴)。第一階段先做「紀錄+規則引擎+自動停權+
申訴」骨架,規則閾值走 config(不寫死,對齊 M18 受保護層慣例)。

## §2 現況可疊的基礎(code 查證,2026-07-17)

**好消息:停權/終止的執行層已完整,只缺「自動觸發」與「違規累積」兩塊。**

1. **lifecycle suspend/terminate 已完備**(`technician_lifecycle_service`):
   含孤兒工單防護(名下有進行中工單軟阻擋、主管 force 越過,CR-0164 E)——
   自動停權**直接呼叫既有 suspend**,不用新造停權邏輯。
2. **評價已有**:`technicians.rating` / `level`。
3. **違約事件源已有**:`exception_service` 的 `no_show`(放鴿子)/`customer_absent`
   等異常類型;工單 `scheduled_at`(排程時間)可與到場時間比對算遲到。
4. **缺**:①「違規紀錄」累積表 ②規則引擎(事件→計分→門檻→觸發)③申訴流程
   ④遲到判定所需的「實際到場時間」欄位(目前 door_check 事件無標準到場戳記)。

## §3 變更設計(骨架,規則值待 Iron)

```
違規事件源(現有):no_show 異常 / 評價低分 / (待補)遲到判定
   │ ① 寫 technician_violations(型別+嚴重度+關聯工單+時間)
   ▼
規則引擎(config 驅動,閾值不寫死)
   │ ② 累積計分 / 滾動窗口(如「90 天內 no_show ≥ N 次」)達門檻
   ▼
自動停權(呼叫既有 lifecycle.suspend)+ 通知師傅
   │ ③ 同時開「申訴案」(TTL 內師傅可提異議)
   ▼
人工覆核(平台維運):維持停權 / 撤銷(誤判)/ 升級終止
```

- **資料面**(技師權威庫 migration,待裁決後):
  - `technician_violations`(type、severity、work_order_id?、note、created_at、
    source=`auto`/`manual`)
  - `technician_penalty_appeals`(violation 關聯、status、師傅陳述、覆核人、決議)
  - 遲到判定:door_check 或工單加「實際到場戳記」(§8 HD-4)
- **規則 config**:走 M18 受保護層(admin-only),閾值/窗口/嚴重度權重全 config,
  **不寫死**——Iron 條款回來後填值即上線,免改 code。
- **停權執行**:復用 `lifecycle.suspend`(含孤兒工單防護)。
- **紅線**:自動停權**一律可申訴**;停權≠終止(終止仍需人工);師傅在途工單
  先改派再停(既有防護)。

## §4 影響範圍

- tech api(違規紀錄+規則引擎+申訴)、平台維運(覆核 UI)、師傅站(申訴入口+
  違規紀錄檢視)、M18 config(規則參數)、migration(兩表+到場戳記)

## §5 風險

| 風險 | 對策 |
|---|---|
| **誤殺師傅**(遲到判定依賴資料品質) | 自動停權必配申訴+人工覆核;第一階段門檻**從寬**,觀察期只記錄不自動停 |
| 遲到判定資料不足 | door_check 無標準到場戳記 → 需先補(HD-4);補齊前遲到規則不啟用 |
| 法務合規(違約條款) | **本 CR 阻塞在 Iron 法務**——條款定義違約要件、停權法律依據、申訴權利 |

## §6 測試計畫

pytest:計分/門檻觸發/申訴狀態機/停權復用 lifecycle;E2E:造違規→達門檻→
自動停權+申訴案→覆核撤銷/維持。
