### 手動驗證

```bash
# 啟動 api/web，登入 admin@example.com / changeme123
# 進 /admin/schedule-requests
```

| 操作 | 預期 |
|:---|:---|
| 切「待審核」tab | 顯示 pending 申請 |
| 點「核准」 | 開 modal 填備註（選填）→ 確認 → 申請消失（tab 過濾掉）|
| 切「已核准」tab | 看到剛審批的申請（含 resolved_at）|
| 對非 pending 申請 | 不顯示按鈕，顯示 resolved_at |

### Curl

```bash
TOKEN="<admin token>"
TENANT="00000000-0000-0000-0000-000000000001"

curl http://localhost:8001/api/v1/admin/schedule-requests?status=pending \
  -H "Authorization: Bearer $TOKEN" -H "X-Tenant-ID: $TENANT"

curl -X POST http://localhost:8001/api/v1/admin/schedule-requests/<id>/approve \
  -H "Authorization: Bearer $TOKEN" -H "X-Tenant-ID: $TENANT" \
  -H "Content-Type: application/json" -d '{"note":"批准"}'
```
