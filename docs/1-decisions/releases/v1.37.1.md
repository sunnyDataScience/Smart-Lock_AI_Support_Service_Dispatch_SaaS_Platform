## 變更摘要 (WHAT)

- `start-api.sh`：新增「自動偵測 image 是否過期」邏輯（比對 image 建立時間 vs api/ 最新檔案 mtime），修 macOS `date -j` 8h 時區偏移

## 背景與動機 (WHY)

實戰中踩到兩個一鍵腳本的坑：
1. API container 是一週前的舊 image，前端打到不存在的新 endpoint 就噴 `UNKNOWN (404): HTTP 404`，但使用者沒人會主動加 `REBUILD_API=1`
2. 使用者第一次跑後，團隊新增的 seed 檔（如 `inventory_items.sql`）永遠不會被灌，前端 inventory 頁全空白

## 影響評估 (IMPACT)

- 無破壞性變更
- 解掉 setup-guide 最容易踩的兩個坑（rebuild 與 seed 漂移）

## 驗證方式

- 重跑 `./scripts/setup/start-api.sh` → `✓ Image smart-lock-api:local 已 up-to-date`
