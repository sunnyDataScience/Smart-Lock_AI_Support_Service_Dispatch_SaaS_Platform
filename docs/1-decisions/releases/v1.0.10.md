## 變更摘要 (WHAT)

1. `git mv scripts/view_llm_usage.py agent/scripts/view_llm_usage.py`，與 `view_logs.py` / `view_facts.py` / `view_context.py` 等 debug script 同位置。

## 背景與動機 (WHY)

v1.0.7 ~ v1.0.9 期間 `scripts/view_llm_usage.py`（root）持續演進，但 `agent/scripts/` 仍留著 03239c6 那版舊副本。使用者習慣在 `agent/` 目錄執行所有 debug script（CLAUDE.md 既定慣例），執行 `python scripts/view_llm_usage.py` 時 shell 解析到了 `agent/scripts/` 的舊版，因此看不到 v1.0.7 補上的 user_question / ai_reply 欄位。

最簡解法：把 root 版搬過去取代舊副本，讓「在 agent/ 跑 scripts/xxx.py」成為單一真實來源，與其他 4 支 view_*.py 對齊。
