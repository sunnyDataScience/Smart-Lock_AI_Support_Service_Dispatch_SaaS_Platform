    autonumber
    participant Customer as Customer

    LINE->>Webhook: POST /webhook (HMAC-SHA256)
    Webhook->>Webhook: Verify signature

    Webhook->>Debounce: add_message_to_buffer()
    Note over Debounce: Wait 1.5s for follow-up
    alt Follow-up within 1.5s
        Customer->>LINE: Additional message

        Webhook->>Debounce: append to buffer
    end

    Webhook->>LineAPI: show_loading_animation()
    Webhook->>Graph: run_langgraph(question, thread_id)

buildFlow 2: L3 Escalation to Dispatch (V2.0)
sequenceDiagram
    autonumber
    participant AI as AI System
    participant Dispatch as Dispatch Engine
    participant PG as PostgreSQL
    participant Pricing as Pricing Engine
    participant Technician as Technician
    participant TechApp as Tech Web App
    participant Maps as Google Maps
    participant LineAPI as LINE API
    AI->>AI: L1 Miss then L2 Fail then L3 Escalate
    AI->>PG: Create WorkOrder (status: created)
    AI->>LineAPI: Notify customer
    Dispatch->>PG: Query ProblemCard
    Dispatch->>PG: Query matching technicians
    Dispatch->>Maps: Calculate distances
    Maps-->>Dispatch: Distance matrix
    Dispatch->>Dispatch: Weighted scoring
    Dispatch->>PG: Update WorkOrder (assigned)
    Dispatch->>TechApp: Push notification
    alt Technician Accepts
        Technician->>TechApp: Accept work order
        TechApp->>PG: Update WorkOrder (in_progress)
        TechApp->>Maps: Navigate to customer
        Note over Technician: On-site repair...
        Technician->>TechApp: Completion report
        TechApp->>Pricing: Auto-calculate
        Pricing-->>TechApp: Quote details
        TechApp->>PG: Create Invoice
        TechApp->>LineAPI: Notify customer
    else Reject / Timeout
        TechApp->>Dispatch: Re-match next technician
    end
