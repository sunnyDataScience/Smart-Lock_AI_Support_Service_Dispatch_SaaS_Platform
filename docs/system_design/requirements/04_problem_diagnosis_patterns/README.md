# 04 — 電子鎖故障診斷模式

> **對口窗口:** 甲方資深技師（有豐富維修經驗的人）
> **協作者:** 產品經理
> **最晚交付日:** Phase 2 W3
> **用途:** 建立 AI 診斷引擎的核心知識，讓系統能根據症狀自動判斷故障原因並建議解決方案

---

## 為什麼這份很重要

AI 問診的準確度 = 故障模式資料庫的完整度。
你腦中有一套「聽到什麼症狀 → 可能是什麼問題 → 怎麼確認 → 怎麼修」的決策樹。
這份文件就是把這棵樹畫出來，讓 AI 也學會這套判斷邏輯。

---

### 2. 診斷決策樹（0.4.2）

**檔案名稱建議:** `diagnosis_decision_trees.md` 或流程圖

針對 Top 10 最常見故障，請畫出診斷決策樹：

#### 範例：指紋辨識失敗決策樹

```
客戶：指紋辨識失敗
  │
  ├─ Q1: 是所有手指都失敗，還是特定手指？
  │   ├─ 所有手指 → Q2
  │   └─ 特定手指 → 建議重新登錄該手指指紋
  │
  ├─ Q2: 螢幕有沒有顯示任何訊息或閃燈？
  │   ├─ 低電量圖示 → 請先更換電池
  │   ├─ 錯誤代碼 → 查對應錯誤碼表
  │   └─ 無顯示 → Q3
  │
  ├─ Q3: 請用乾布擦拭指紋感應器後再試
  │   ├─ 成功 → 結案（感應器髒污）
  │   └─ 仍失敗 → Q4
  │
  └─ Q4: 請嘗試用密碼或卡片開鎖
      ├─ 其他方式正常 → 感應器可能故障，建議到場檢修
      └─ 其他方式也失敗 → 主板可能故障，建議到場檢修
```

> **不需要畫完美的圖**。用文字描述「你怎麼問、怎麼判斷」就好，我們會轉成系統可用的格式。

### 4. 季節性與環境故障（0.4.4）

**檔案名稱建議:** `seasonal_environmental_issues.md`

| 季節/環境 | 好發故障 | 原因 | 預防建議 |
| :--- | :--- | :--- | :--- |
| 梅雨季（5-6 月） | 指紋辨識失靈、電路受潮 | 濕度過高 | 定期擦拭、安裝防雨罩 |
| 夏季（7-8 月） | 電池膨脹、觸控螢幕過熱 | 高溫日照 | 避免陽光直射、使用耐高溫電池 |
| 冬季（12-2 月） | 觸控面板反應慢、電池效能降低 | 低溫 | 使用鹼性電池、保持門鎖乾燥 |
| 海邊/高鹽分環境 | 金屬部件鏽蝕、電子元件腐蝕 | 鹽分侵蝕 | 選用防鏽型號、定期保養 |
| 社區大樓門口 | 被風雨直接吹淋 | 缺乏遮蔽 | 加裝防雨罩、選用室外型號 |
